      05B
      영역별 평가 직후

      일반교과 영역별 수행평가 점수 입력

      일반교과 수행평가 점수를 영역 하나씩 골라 입력하는 방식이다. [교과담임-성적-정기시험/수행선행작업-수행평가영역관리]에서 등급과 구간으로 기준을 설정한 영역은 {등급변환}이 생성된다. 학적변동으로 점수가 없는 학생은 '영역별학적변동' 내용을 선택한다.

      언제?
      학기중, 반영비율/만점관리에서 수행평가 영역·반영비율·영역만점 입력을 마친 뒤 해당 영역 평가가 끝나면.
      누가?
      교과담당교사
      어디서?
      [교과담임-성적-수행평가-수행평가성적관리]
      무엇을
      어떻게?
      '학년도', '학기' 확인 후 '학년', '과목', '영역', '강의실'을 선택하고 {조회}하여 학생별 수행평가 점수를 입력 → 학적변동으로 점수가 없는 학생의 경우 '영역별학적변동' 내용 선택 후 {저장}함.
      왜?
      학생이 영역별로 받은 평가 결과를 나이스 성적에 반영해 학기말 성적산출의 근거로 남기려고.

      실무 메모

      • 수행평가 결시자는 최대한 추후 평가 기회를 부여하고 결시자의 처리 기준은 교과협의회를 거쳐 평가계획에 반영함.
      • [교과담임-성적-정기시험/수행선행작업-수행평가영역관리]에서 등급과 구간으로 기준을 설정한 영역의 경우 [교과담임-성적-수행평가-수행평가성적관리]에서 {등급변환}이 생성되며, '영역'별로 등급점수 또는 구간점수를 입력 후 {저장} 시 등급 기준 값 또는 구간 기준 값으로 변환되어 저장됨.

      06B
      영역 평가가 모두 끝난 뒤권장 경로

      일반교과 전체 영역 수행평가 점수 입력

      여러 영역 점수를 한 화면에서 입력하고 싶을 때 쓰는 방식이다. '영역(전체)'로 조회해도 일부 영역이나 일부 점수만 {저장}할 수 있다. 학생 수가 많으면 {일괄파일업로드}의 {엑셀다운로드}를 활용해 한 번에 올릴 수 있다.

      언제?
      학기중, 반영비율/만점관리 입력이 끝나고 영역별 평가가 진행된 뒤.
      누가?
      교과담당교사
      어디서?
      [교과담임-성적-수행평가-수행평가성적관리], [교과담임-성적-수행평가조회/통계-수행평가조회-강의실별일람표조회 전체영역]
      무엇을
      어떻게?
      '학년도', '학기' 확인 후 '학년', '과목', '영역(전체)', '강의실'을 선택하고 {조회}하여 학생별 수행평가 영역 점수 입력 → 학적변동으로 점수가 없는 학생의 경우 '학적변동' 내용 선택 후 {저장}함.
      왜?
      여러 영역 점수를 한 화면에서 채워 넣어 누락된 영역 없이 수행평가 입력을 마무리하려고.

      실무 메모

      • '영역 전체'로 {조회}하여 입력하는 경우에도 일부 영역이나 일부 점수만 {저장}할 수 있음.
      • 학생이 전출 시에는 나이스 등에 전출일 현재까지의 각종 자료를 입력·확인 후 전입교로 전송함(이때, 입력의 근거가 되는 증빙서류는 원적교에서 보관함).
      • {일괄파일업로드}에서 {엑셀다운로드}를 활용하면 전체 학생점수를 파일에 작성하여 한 번에 업로드 가능함(전출 등의 학적변동자가 있는 강의실도 업로드 가능함).

      입력 결과 확인 요령

      • [교과담임-성적-수행평가조회/통계-수행평가조회-강의실별일람표조회 전체영역]에서 {조회} 후 '강의실별 일람표 조회 전체영역' 창에서 다운로드한 파일로 필터기능을 활용하여 수행평가 영역별 점수만 나타나는지 확인 가능함(평균, 전입생 점수 등 평가(채점) 기준에 없는 점수가 나타날 수 있음).
      • 셀 범위 선택 후 [데이터-필터] 클릭(한셀: [데이터-자동필터] 클릭) → 영역명의 버튼을 클릭하여 점수 확인.

      07C
      능력단위별 평가 직후전문교과 능력단위 편성 과목 한정

      전문교과 능력단위별 수행평가 점수 입력

      능력단위를 편성한 과목에만 해당한다. 2022 개정 교육과정을 적용받는 2026학년도 1･2학년 전문교과 전공실무과목 또는 전공일반과목, 2015 개정 교육과정을 적용받는 2026학년도 3학년 전문교과Ⅱ 실무과목 또는 기초과목의 능력단위별(예 : ‘*재무분석’, ‘*사업결합회계’)로 평가한 점수를 입력한다. 현장실습생이 없거나 현장실습생이 소속교에서 평가를 완료한 경우의 절차다.

      언제?
      학기중, 능력단위별 수행평가를 실시한 뒤
      누가?
      교과담당교사
      어디서?
      [교과담임-성적-수행평가-수행평가성적관리]
      무엇을
      어떻게?
      [교과담임-성적-수행평가-수행평가성적관리]에서 ‘학년도’, ‘학기’ 확인 → ‘계열/학년/학과’, ‘과목’, ‘영역’, ‘강의실’을 선택 → {조회} → 학생별 수행평가 점수를 입력 → 학적변동으로 점수가 없는 학생의 경우 ‘영역별학적변동’ 내용 선택 → {저장}
      왜?
      능력단위별로 나뉘어 평가한 실무 성취를 과목 성적에 정확히 반영하려고.

      실무 메모

      • 현장실습생이 소속교에서 평가를 완료한 영역의 경우 해당 영역에 평가받은 점수를 인정하여 입력하고 ‘결시명칭’ 또는 ‘현장실습인정점’은 선택하지 않음.
      • 2022 개정 교육과정을 적용받는 2026학년도 1･2학년 전공일반과목, 2015 개정 교육과정을 적용받는 2026학년도 3학년 기초과목의 경우 능력단위와 연계하여 운영할 수 있으며, [교육과정-편제및과목개설관리-편제및과목개설관리]에서 능력단위를 등록함.
      • [교과담임-성적-정기시험/수행선행작업-수행평가영역관리]에서 ‘능력단위반영비율(%)’의 합은 100%이어야 함.

      01A
      OMR 리딩 직후OMR 시트(카드) 사용 시

      수행평가 성적파일 업로드·이관

      영어듣기평가나 전문교과 Ⅱ의 능력단위별 수행평가 성적처리를 위해 OMR 시트(카드)를 사용하는 경우에만 해당한다. 리딩으로 만들어진 파일을 나이스로 올려야 이후의 정답·배점 관리와 채점이 가능하다.

      언제?
      학기중, OMR 시트(카드) 리딩을 마친 뒤
      누가?
      교과담당교사
      어디서?
      [성적-정기시험/수행선행작업-성적파일올리기]
      무엇을
      어떻게?
      [성적-정기시험/수행선행작업-성적파일올리기]에서 '학년도', '학기', '과정' 확인 → '학년', '정기시험/수행', '고사/영역'을 선택 → {파일추가} → '열기' 창에서 대상 파일 클릭 후 {열기} → {파일업로드/이관}함.
      왜?
      OMR로 읽어 들인 마킹 결과를 나이스 성적 자료로 옮겨, 손으로 옮겨 적지 않고 수행평가 채점을 진행하려고.

      실무 메모

      • 수행평가는 정답/배점, 학생답안, 학생점수/배점 파일을 올릴 수 있음.

      03A
      OMR 리딩 직후OMR 시트(카드) 사용 시

      수행평가 학생 답(OMR 마킹) 확인

      OMR 시트(카드)로 수행평가를 처리하는 과목에서 리딩 결과가 제대로 들어왔는지 눈으로 확인하는 업무다. 학생답안은 수정할 수 없으므로 이상이 있으면 파일 단계로 돌아가 다시 처리해야 한다.

      언제?
      학기중, 성적파일 업로드·이관을 마친 뒤
      누가?
      교과담당교사
      어디서?
      [교과담임-성적-수행평가-수행평가학생답관리]
      무엇을
      어떻게?
      [교과담임-성적-수행평가-수행평가학생답관리]에서 '학년도', '학기' 확인 → '학년', '과목', '영역', '강의실'을 선택 → {조회} → 학생 클릭 후 OMR 시트(카드) 마킹 내용 확인함.
      왜?
      채점 전에 리딩된 마킹 상태를 학생별로 눈으로 검증해, 잘못된 답안으로 성적이 산출되는 일을 막으려고.

      실무 메모

      • 리딩한 학생의 OMR 시트(카드)를 확인할 수 있으며, 학생답안은 수정할 수 없음.

      02A
      학생답안 채점 전OMR 시트(카드) 사용 시

      언제?
      학기중, 수행평가 성적파일 업로드·이관을 마친 뒤
      누가?
      교과담당교사
      어디서?
      [교과담임-성적-수행평가-수행평가정답/배점관리]
      무엇을
      어떻게?
      [교과담임-성적-수행평가-수행평가정답/배점관리]에서 '학년도', '학기' 확인 → '학년', '과목', '영역'을 선택 → {조회} → {선택형} 탭에서 문항별 '배점'과 '정답'을 입력 → {저장} → {마감}함.
      왜?
      채점의 기준이 되는 정답과 배점을 확정해, 학생 마킹을 기계가 옳게 채점하도록 하려고.

      04A
      정답·배점 마감 직후OMR 시트(카드) 사용 시

      교과담당교사
      어디서?
      [교과담임-성적-수행평가-수행평가채점]

      학기말, 교과담당교사가 [교과담임-성적-수행평가-수행평가성적관리]에서 이상 유무 확인 후 {전체영역마감}을 완료한 뒤
      누가?
      성적처리업무담당자
      어디서?
      [성적-수행평가-수행평가마감관리]
      무엇을
      어떻게?
      [성적-수행평가-수행평가마감관리]에서 '학년도', '학기' 확인 후 '학년', '과목'을 선택하고 {조회}함 → 모든 '강의실/편성반'의 '강의실별마감여부'를 확인하고 {마감정보저장}하여 {확인} 후 {승인요청}함.
      왜?
      학년 단위로 빠진 강의실 없이 수행평가 점수를 확정해 학기말 성적산출의 근거를 잠그기 위해서.

      실무 메모

      • {전과목조회}하면 '수행평가 전과목 마감조회' 창에서 과목별 마감 여부를 한 번에 확인할 수 있음.
      • [성적-수행평가-수행평가마감관리]에서 과목별로 '강의실별마감여부'를 확인하여 {마감정보저장}하면 해당 과목의 수행평가 마감이 완료되며, 교과담당교사는 [교과담임-성적-수행평가-수행평가성적관리]에서 점수를 수정할 수 없음.
      • [성적-정기시험/수행선행작업-수행평가영역관리]에서 '성취기준'을 등록하면 [성적-수행평가-수행평가마감관리]의 '성취기준'에 해당 내용이 나타남.
      • 학년별로 모든 과목의 수행평가 강의실별 마감과 {마감정보저장}이 완료되어야 해당 학년별로 {승인요청}할 수 있음.
