    01A
    연중 수시특정 교과에 해당하지 않는 독서활동

    개인별 독서활동상황 기록

    학생 한 명씩 독서활동상황을 확인하며 입력할 때 쓰는 화면이다. 특정 교과에 해당하지 않는 독서활동은 학급담임교사가 공통으로 입력한다. 입력 전에 이전 독서활동상황을 열어 같은 도서가 아닌지 확인하는 절차가 함께 들어 있다.

    언제?
    연중 수시, 학생의 독서활동을 확인한 시점마다.
    누가?
    학급담임교사
    어디서?
    [학급담임-학생생활-독서활동상황-독서활동상황기록]
    무엇을
    어떻게?
    [학급담임-학생생활-독서활동상황-독서활동상황기록]의 {개인별} 탭에서 '학년도', '학기', '학년', '반'을 확인하고 {조회} 후 해당 학생을 클릭 → {독서활동상황조회}하여 '독서활동상황 조회' 창에서 이전 독서활동상황을 확인하고 {닫기} → 이전 독서활동상황과 동일한 도서가 아닌 경우 '독서활동상황' 내용 입력 후 {저장}.
    왜?
    같은 도서가 되풀이 기록되는 일 없이, 학생의 독서 이력이 학기별로 쌓이게 하려고.

    입력 주체와 '과목 또는 영역'

    • 독서활동은 교과목별로 해당 교과 관련 독서활동을 교과담당교사가 입력하되, 특정 교과에 해당하지 않을 경우 학급담임교사가 공통으로 입력할 수 있음.
    • '과목 또는 영역'란에는 교과담당교사가 입력하는 경우 해당 '교과명'이, 학급담임교사가 입력하는 경우 '공통'이 자동으로 입력됨.

    학기 구분 입력

    • 독서활동 내용 입력은 학기를 구분하여 입력하며 '(1학기)', '(2학기)'는 나이스에서 학기별로 입력 시 자동으로 입력됨.
    • 2학기에 1학기의 독서 입력을 원하는 경우 조회조건에서 학기를 '1'로 바꾸어 조회하여 입력함.

    타임라인으로 돌아가기

    04B
    연중 수시교과담당교사 전용 경로

    과목별 독서활동 등록

    해당 학기에 개설된 과목과 관련된 독서활동은 교과담당교사가 자기 과목의 강의실 단위로 직접 입력한다. 이전독서활동상황 조회 창에서 이전 독서활동과 중복되지 않음을 먼저 확인한 뒤 입력한다. 특정 교과에 해당하지 않는 독서활동은 이 화면이 아니라 학급담임교사가 공통으로 입력한다.

    언제?
    연중 수시, 학기별로 구분하여 입력하며 학기말까지 마무리함.
    누가?
    교과담당교사
    어디서?
    [교과담임-성적-성적처리-과목별독서활동]
    무엇을
    어떻게?
    ‘학년도’, ‘학기’ 확인 후 ‘학년’, ‘과목’, ‘강의실’을 선택하고 {조회} → 해당 학생 ‘성명’ 또는 ‘학적변동구분’을 클릭하여 ‘이전독서활동상황 조회’ 창에서 이전독서활동과 중복되지 않음을 확인하고 {닫기} → ‘독서활동상황’ 내용을 입력하고 {저장}.
    왜?
    학생이 읽은 책을 담당 교과의 학습과 연결해 남겨, 같은 도서가 학기마다 되풀이 기록되지 않게 하려고.

    실무 메모

    • 독서활동은 교과목별로 해당 교과 관련 독서활동을 교과담당교사가 입력하되, 특정 교과에 해당하지 않을 경우 학급담임교사가 공통으로 입력할 수 있음.
    • ‘과목 또는 영역’란에는 교과담당교사가 입력하는 경우 해당 ‘교과명’이, 학급담임교사가 입력하는 경우 ‘공통’이 자동으로 입력됨.
    • 독서활동 내용 입력은 학기를 구분하여 입력하며 ‘(1학기)’, ‘(2학기)’는 나이스에서 학기별로 입력 시 자동으로 입력됨.
    • 2학기에 1학기의 독서 입력을 원하는 경우 조회조건에서 학기를 ‘1’로 바꾸어 조회하여 입력함.

    지우려 할 때

    • 내용을 지우고 {저장}하면 ‘독서활동상황은 필수입니다’라는 내용이 나타나므로 이 화면에서는 지울 수 없음.
    • 삭제는 [학생생활-독서활동상황-독서활동상황기록]에서 해당 영역을 선택하여 {삭제} 해야 함.

    02A
    학기말

    반별 독서활동상황기록 등록

    학급 학생 전체의 독서활동상황을 한 화면에서 보며 입력할 때 쓴다. 조회 조건에 '독서활동 영역'이 들어가므로 어느 영역에 기록할지 먼저 정해야 한다. 개인별 탭과 같은 메뉴이지만 여러 학생을 이어서 입력할 때 손이 덜 간다.

    언제?
    학기말, 학급 학생의 독서활동을 모아 정리하는 시점.
    누가?
    학급담임교사
    어디서?
    [학급담임-학생생활-독서활동상황-독서활동상황기록]
    무엇을
    어떻게?
    [학급담임-학생생활-독서활동상황-독서활동상황기록]의 {반별} 탭에서 '학년도', '학기', '학년', '반', '독서활동 영역'을 확인하고 {조회} → '독서활동상황' 내용을 입력하여 {저장}.
    왜?
    학급 전체의 독서활동 기록 상태를 한눈에 놓고 빠진 학생 없이 채우려고.

    실무 메모

    • '과목 또는 영역'란에는 학급담임교사가 입력하는 경우 '공통'이 자동으로 입력됨.
    • 독서활동 내용 입력은 학기를 구분하여 입력하며 '(1학기)', '(2학기)'는 나이스에서 학기별로 입력 시 자동으로 입력됨.

    03A
    학기말여러 학생 같은 도서일 때

    반별 화면에서 같은 도서명 일괄입력

    학급의 여러 학생이 같은 책을 읽어 도서명이 겹칠 때 쓴다. {덮어쓰기}를 선택하면 기존 '독서활동상황기록'이 모두 삭제되므로 재차 확인하여 사용해야 한다. {반별} 탭의 {일괄입력} 기능이다.

    언제?
    학기말, 반별 독서활동상황을 조회한 뒤 같은 도서명을 여러 학생에게 넣어야 할 때.
    누가?
    학급담임교사
    어디서?
    [학급담임-학생생활-독서활동상황-독서활동상황기록]
    무엇을
    어떻게?
    [학급담임-학생생활-독서활동상황-독서활동상황기록]의 {반별} 탭에서 '학년도', '학기', '학년', '반', '독서활동 영역'을 확인하고 {조회} → {일괄입력}을 이용하여 여러 명의 학생에게 같은 도서명을 입력 → {이어쓰기} 또는 {덮어쓰기}를 선택 → {저장}.
    왜?
    학급 공통 도서를 학생마다 다시 타이핑하지 않고 한 번에 남기려고.

    이어쓰기와 덮어쓰기

    • {반별} 입력의 경우 {일괄입력}을 이용하여 여러 명의 학생에게 같은 도서명을 일괄 입력할 수 있음.
    • {이어쓰기}는 기존의 입력된 독서활동상황에 이어서 입력됨.
    • {덮어쓰기}는 기존의 입력된 독서활동상황을 삭제하고 새로운 독서활동상황만 입력됨.
    • {덮어쓰기} 선택시 기존 '독서활동상황기록'이 모두 삭제되므로 재차 확인하여 사용해야함.

    05C
    잘못 등록한 것을 확인한 즉시학급담임 화면에서만 삭제 가능

    잘못 등록한 독서활동상황 삭제

    독서활동상황 내용을 입력하지 않아야 할 학생에게 실수로 등록한 경우에 해당한다. 입력 화면에서 내용을 지우고 {저장}하면 '독서활동상황은 필수입니다'라는 안내가 나타나 지워지지 않는다. 내용을 비우는 방식이 아니라 해당 영역을 선택해 삭제하는 방식으로 처리한다.

    언제?
    연중 / 학기말, 독서활동상황을 이미 등록한 뒤 잘못 등록한 것을 확인한 시점
    누가?
    학급담임교사, 교과담당교사
    어디서?
    [학생생활-독서활동상황-독서활동상황기록]
    무엇을
    어떻게?
    [학생생활-독서활동상황-독서활동상황기록]에서 해당 영역을 선택 → {삭제}함.
    왜?
    입력하지 않아야 할 학생의 기록이 학기 자료에 남아 그대로 반영되는 것을 막으려고.

    실무 메모

    • 내용을 지우고 {저장}하면 '독서활동상황은 필수입니다'라는 안내가 나타나므로, 내용을 비우는 방법으로는 삭제되지 않음.
    • 삭제는 [학생생활-독서활동상황-독서활동상황기록]에서 해당 영역을 선택한 뒤 {삭제}하는 방식으로만 처리함.
