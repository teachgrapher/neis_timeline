    03A
    고사기간 중메뉴 권한 필요

    문항정보표 기존사용자 변경

    고사기간 중 문항정보표에 대한 '기존사용자'를 변경해야 할 경우에만 해당한다. '시행일자'의 '종료일'까지는 최초 등록한 교과담당교사만 문항정보표를 작성·열람·수정·출력할 수 있으므로, 담당 교사가 바뀌면 사용자를 변경해야 한다. 이 메뉴에 대한 권한이 필요하다.

    언제?
    고사기간 중, 문항정보표를 최초 등록한 교과담당교사가 계속 관리할 수 없게 된 때.
    누가?
    성적처리업무담당자
    어디서?
    [성적-지필평가-문항정보표사용자관리]
    무엇을
    어떻게?
    [성적-지필평가-문항정보표사용자관리]에서 문항정보표에 대한 '기존사용자'를 변경함.
    왜?
    담당 교사가 바뀌어도 고사기간 중에 문항정보표가 잠겨 채점이 멈추는 일을 막으려고.

    실무 메모

    • [성적-지필/수행선행작업-지필평가고사관리]의 '시행일자'에 등록한 '종료일'까지 문항정보표의 작성/열람/수정/출력은 최초 등록한 교과담당교사만 관리할 수 있음.
    • 교과담당교사가 2인 이상인 경우 최초 등록한 교과담당교사만 접근이 가능하나, '시행일자' 종료 이후부터는 해당 학년의 교과목 권한이 있는 사용자 모두 문항정보표의 작성/열람/수정/출력이 가능함.
    • 고사기간 중 '기존사용자'를 변경해야 할 경우 [성적-지필평가-문항정보표사용자관리]에서 사용자를 변경함(해당 메뉴에 대한 권한이 필요함).

    01A
    고사 직후추정 분할점수 산출 과목

    문항정보표 작성·마감 — 성취기준을 가져오는 과목

    과목별 평가 계획에 따라 추정 분할점수를 산출하는 과목이 해당한다. 이 경우 [교과담임-성적-지필/수행선행작업-성취평가기준관리]에서 성취기준이 먼저 등록되어 있어야 하며, 문항정보표에 '내용영역', '성취기준', '난이도'를 모두 입력해야 한다. 세 항목 중 하나라도 비어 있으면 마감할 수 없다.

    언제?
    고사 종료 후 학생의 OMR 시트(카드)를 리딩하여 [성적-지필/수행선행작업-성적파일올리기]에서 파일을 이관한 뒤.
    누가?
    교과담당교사
    어디서?
    [교과담임-성적-지필평가-문항정보표관리], [교과담임-성적-지필/수행선행작업-성취평가기준관리-성취기준관리]
    무엇을
    어떻게?
    [교과담임-성적-지필평가-문항정보표관리]에서 '학년도', '학기' 확인 후 '고사', '학년', '과목' 선택하고 {조회} → {선택형(진위형, 배합형, 선다형)}, {서답형(완성형, 단답형, 서술형, 논술형)} 탭에서 문항별 '내용영역', '난이도', '배점', '정답' 입력 → '성취기준'의 '등록'을 클릭하여 '문항정보표-성취기준자료 가져오기' 창에서 성취기준 선택 후 {선택} → {저장} → {마감}.
    왜?
    내용영역·성취기준·난이도·배점 정보를 남겨 두어야 추정 분할점수를 산출할 근거가 생기고, 학생 성적을 성취수준으로 해석할 수 있다.

    실무 메모 — 성취기준과 마감 조건

    • 문항정보표의 '내용영역', '성취기준', '난이도'의 경우 입력 시 모두 입력해야 {마감}할 수 있음.
    • '성취기준'을 '등록'하기 위해서는 [교과담임-성적-지필/수행선행작업-성취평가기준관리-성취기준관리]에서 학기별 성취기준을 먼저 등록해야 하며, '성취기준'은 500Byte 이내에서 최대 6개까지 선택하여 등록할 수 있음.
    • '성취기준'을 등록하지 않으면 '성취기준'란에는 '등록'이라고 나타나고, 등록하면 '등록'이 등록한 성취기준 개수로 변경됨.
    • {마감} 시 '과목점수'의 합계가 [교과담임-성적-지필/수행선행작업-반영비율/만점관리]에서 등록한 만점과 일치하지 않으면 오류 메시지가 나타남.
    • 문항정보표의 {마감} 이후 [교과담임-성적-분할점수-분할점수관리-지필평가추정분할점수산출관리]에서 과목별 평가 계획에 따라 추정 분할점수를 산출할 수 있음(문항정보표에 '내용영역', '성취기준', '난이도' 등을 모두 입력하는 경우에 해당함).

    실무 메모 — 권한과 재채점

    • [성적-지필/수행선행작업-지필평가고사관리]의 '시행일자'에 등록한 '종료일'까지 문항정보표의 작성/열람/수정/출력은 최초 등록한 교과담당교사만 관리할 수 있음. 교과담당교사가 2인 이상인 경우에도 최초 등록한 교사만 접근이 가능하나, '시행일자' 종료 이후부터는 해당 학년의 교과목 권한이 있는 사용자 모두 작성/열람/수정/출력이 가능함.
    • [교과담임-성적-지필평가-지필평가채점]에서 채점 이후 문항정보표를 수정하는 경우 기존 채점 결과(서답형 점수 포함) 및 정오표가 삭제되므로 다시 채점을 해야 함. 단, 서답형 파일만 수정하는 경우는 문항정보표 수정으로 인식되지 않아 기존 채점 결과가 유지됨.
    • 재채점 시 [교과담임-성적-지필평가-지필평가채점]에서 '직전성적관리 서답형'을 선택 후 채점을 하면 기존 입력된 서답형 점수가 복구됨.

    02A
    고사 직후추정 분할점수를 산출하지 않는 과목서답형 100% 과목 포함

    정답·배점만 입력하는 과목의 문항정보표 처리

    추정 분할점수를 산출하지 않는 과목은 '내용영역', '성취기준', '난이도' 없이 '정답'과 '배점'만 입력해 처리한다. 서답형 100% 과목의 경우 '과목점수'에서 '서답형 만점/배점합'에 100점을 등록한다. 만점 오류를 미리 걸러내려면 선택형·서답형 만점을 먼저 {과목점수저장}한 뒤 문항별 배점을 입력해 '배점합'과 비교한다.

    언제?
    고사 종료 후 학생의 OMR 시트(카드)를 리딩하여 [성적-지필/수행선행작업-성적파일올리기]에서 파일을 이관한 뒤.
    누가?
    교과담당교사
    어디서?
    [교과담임-성적-지필평가-문항정보표관리], [교과담임-성적-지필/수행선행작업-반영비율/만점관리]
    무엇을
    어떻게?
    [교과담임-성적-지필평가-문항정보표관리]에서 '학년도', '학기' 확인 후 '고사', '학년', '과목' 선택하고 {조회} → 선택형, 서답형의 만점을 입력 후 {과목점수저장} → {선택형(진위형, 배합형, 선다형)}, {서답형(완성형, 단답형, 서술형, 논술형)} 탭에서 문항별 '배점', '정답' 입력 → {저장} → {마감}.
    왜?
    OMR로 리딩한 학생 답을 정답·배점과 맞춰 자동 채점할 수 있게 하려고.

    실무 메모 — 만점과 저장

    • {과목점수저장}은 선택형, 서답형의 만점을 입력 후 {과목점수저장}하고 문항별 배점을 입력하면 선택형, 서답형의 만점이 '배점합'에서 자동 계산되어 표시되므로 비교가 가능하여 만점오류 예방이 가능함.
    • {마감} 시 '과목점수'의 합계가 [교과담임-성적-지필/수행선행작업-반영비율/만점관리]에서 등록한 만점과 일치하지 않으면 오류 메시지가 나타남.
    • {저장}은 중간 저장 기능으로 {조회}하면 생성되는 {정답배점출력}이 가능함.
    • 서답형 100% 과목의 경우 '과목점수'에서 '서답형 만점/배점합'에 100점을 등록함. 해당 과목은 [교과담임-성적-지필평가-지필평가성적관리]에서 강의실별 {마감} 후 [교과담임-성적-지필평가조회-학생별 학생답정오표조회]에서 '서답형점수', '과목점수'가 조회됨.

    실무 메모 — 수정·삭제·복사

    • 수정하고자 하는 문항을 선택하고 {행값지우기}하면 해당 문항의 입력 내용을 삭제할 수 있음.
    • {삭제}하면 대상으로 '문항정보표'와 '지필평가 정답/배점'을 선택하고 삭제유형으로 '전체', '선택형', '서답형'을 선택하여 삭제할 수 있음.
    • 문항정보표의 {마감} 이후 {출력}, {검증}, {채점}이 가능하며, {타학과복사}가 활성화되어 타학과에 문항정보표를 복사할 수 있음. 단, 교과목 코드와 학점이 동일해야 하며, 다른 사용자가 정답/배점 또는 문항정보표를 이미 등록했거나 마감했다면 타과복사할 수 없음.
    • 지필고사 채점 이후 문항정보표의 내용(과목만점, 정답/배점 등)이 변경되는 경우 채점 정보 및 기존 입력되었던 성적이 삭제되니 반드시 재채점 해야 함.

    성적파일 이관 직후서답형 출제 과목

    언제?
    학생의 OMR 시트(카드)를 리딩하여 [성적-지필/수행선행작업-성적파일올리기]에서 파일을 이관한 뒤, 채점 전.
    누가?
    교과담당교사
    어디서?
    [교과담임-성적-지필평가-지필평가학생답관리]
    무엇을
    어떻게?
    [교과담임-성적-지필평가-지필평가학생답관리]에서 '학년도', '학기' 확인 후 '고사', '학년', '과목', '강의실'을 선택하고 {조회} → 학생 '성명'을 선택하여 OMR 시트(카드) 마킹 내용 확인 → '서답형점수/문항별점수합' 점수 입력하여 {저장}.
    왜?
    리딩 과정에서 답안카드가 누락되거나 잘못 읽히지 않았는지 채점 전에 학생별로 눈으로 확인하려고.
