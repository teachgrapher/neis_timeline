    01A
    학년초반별등록 최초 1회

    반별등록 인적사항 생성

    학년초에 학급담임교사가 자기 반 건강기록부를 처음 열 때 하는 일입니다. 반별등록에서 학생명렬표가 조회되지 않으면 처음 사용 시 {인적사항생성} 절차를 수행해야 합니다. 이 작업을 마쳐야 이후 신체발달·신체능력·건강검진 입력 화면에 학생이 뜹니다.

    언제?
    학년초, 학급 편성이 끝난 뒤
    누가?
    학급담임교사, 보건담당자
    어디서?
    [학급담임-보건-건강기록부관리-반별등록]
    무엇을
    어떻게?
    ‘학년도’, ‘계열/학년/학기’, ‘반’ 확인 후 {조회} → {인적사항생성} 클릭 → {확인} 후 {확인} 하여 완료함.
    왜?
    학기 초에 편성된 학급 정보를 건강기록부에 얹어, 담임이 명렬표로 반 학생 건강자료를 한 번에 입력할 수 있게 하려고.

    실무 메모

    • 반별등록에서 학생명렬표가 조회되지 않을 경우 처음 사용 시 {인적사항생성} 탭을 클릭하여 인적사항생성 절차를 수행해야 함.
    • 학기중 전입생의 경우 전입이후 개별등록으로 학급 담임교사를 등록함.
    • 4세대 나이스에서는 건강기록부 마감 시에도 인적사항 생성을 실시함.

    타임라인으로 돌아가기

    06B
    학년초반별등록으로 대체 가능

    학생찾기와 인적사항 등록

    개인별 등록은 학급 명렬표가 아니라 학생 한 명을 찾아 들어가는 방식입니다. 학기중 전입생처럼 반별등록 명렬표에 잡히지 않는 학생은 이 경로로 처리합니다. 모든 개인별 등록 작업은 {학생찾기}로 학생을 특정한 뒤에야 각 탭이 열립니다.

    언제?
    학년초, 학기중 전입 등 학적 변동이 생긴 뒤
    누가?
    보건담당자, 학급담임교사
    어디서?
    [보건-건강기록부관리-개인별등록]
    무엇을
    어떻게?
    ‘학년도’를 확인 후 {학생찾기} 하여 ‘학년도’, ‘재학여부’ 확인 후 ‘학년’을 선택 → 등록할 학생 ‘성명’을 입력하고 {조회} → {학생목록}에서 조회된 학생의 인적사항을 {확인} 후 {조회} → {인적사항} 탭을 선택하고 {행추가}에서 ‘학교명’, ‘반’, ‘번호’, ‘담임성명’을 확인하고 {저장} 함.
    왜?
    학생 한 명의 건강기록부에 소속 학급과 담임을 붙여 두어야 이후 검사 기록이 올바른 학생·학급 이름으로 남기 때문입니다.

    실무 메모

    • 학기중 전입생의 경우 전입이후 개별등록으로 학급 담임교사를 등록함.
    • ‘반별 등록’은 ‘개인별 등록’과는 달리 {학생찾기}를 통하지 않고 학기 초에 편성된 학급 정보로 {인적사항}, {신체발달}, {신체능력}, {건강검진}을 입력할 때 활용되며, 입력요령은 ‘개인별 등록’과 같음.

    타임라인으로 돌아가기

    03A
    신체발달 검사 실시 후PAPS 자료불러오기 또는 직접 입력

    반별 신체발달 입력

    학교교육과정 운영계획에 따라 반 전체가 동일한 일정으로 신체발달 검사를 실시했을 때 쓰는 경로입니다. ‘반별 등록’은 {학생찾기}를 통하지 않고 학기 초에 편성된 학급 정보로 입력하며, 입력요령은 ‘개인별 등록’과 같습니다. PAPS 자료를 불러와 자동 반영된 값을 쓰거나 키·몸무게를 직접 넣을 수 있습니다.

    언제?
    학기중, 신체발달 검사를 실시하고 인적사항생성을 마친 뒤
    누가?
    학급담임교사, 보건담당자
    어디서?
    [보건-건강기록부관리-반별등록]
    무엇을
    어떻게?
    ‘학년도’, ‘학년’, ‘반’ 을 확인하여 {조회} → 학생 선택 후 {신체발달} 탭을 클릭하여 ‘키(cm)’, ‘몸무게(kg)’ 를 입력하고 ‘검사일자’ 를 선택하여 {저장} → 또는 {PAPS자료불러오기} 탭을 이용하여 자동 반영된 자료를 확인하고 {저장} 함.
    왜?
    학급이 같은 날 같은 기관에서 받은 검사 결과를 명렬표에서 한 번에 옮겨 담아, 학생을 한 명씩 찾는 수고를 없애려고.

    반별 등록의 쓰임새

    • ‘반별 등록’은 ‘개인별 등록’과는 달리 {학생찾기}를 통하지 않고 학기 초에 편성된 학급 정보로 {인적사항}, {신체발달}, {신체능력}, {건강검진}을 입력할 시에 학교교육과정 운영계획에 따라 동일하게 실시된 ‘검사일정’, ‘검사기관’을 학급에 적용할 때 활용되며, 입력요령은 ‘개인별 등록’과 같음.
    • 반별등록에서는 인적생성 후, 학급 명렬표의 학생을 선택하여 저장할 수 있음.

    입력값 처리

    • {PAPS자료불러오기}를 실시하지 않고 ‘키(cm)’, ‘몸무게(kg)’를 입력하면 비만도의 체질량지수, BMI는 자동계산되어 반영되고 ‘검사일자’를 입력 가능함.
    • 신체능력도 같은 방식으로 반별등록에서 인적생성 후 학급 명렬표의 학생을 선택하여 측정값을 저장할 수 있음.

    타임라인으로 돌아가기

    08B
    PAPS 측정 이후PAPS 불러오기 또는 직접 입력

    개인별 신체발달 입력(PAPS 자료불러오기 또는 직접 입력)

    키와 몸무게를 학생별로 남기는 작업으로, PAPS에 측정값이 있으면 불러오고 없으면 직접 입력합니다. {PAPS자료불러오기}를 하지 않고 ‘키(cm)’, ‘몸무게(kg)’를 입력하면 비만도의 체질량지수, BMI는 자동계산되어 반영됩니다.

    언제?
    학기중, 신체발달 검사를 실시한 뒤
    누가?
    보건담당자
    어디서?
    [보건-건강기록부관리-개인별등록]
    무엇을
    어떻게?
    ‘학년도’와 {학생찾기}로 검색한 학생의 {성명}을 확인하고 {조회} → {신체발달} 탭을 선택하고 {PAPS자료불러오기} 하여 {확인} 후 {확인} 하고 자동 반영된 자료를 확인 후 {저장} 함.
    왜?
    체육 측정에서 이미 잰 키·몸무게를 다시 재입력하지 않고 건강기록부로 옮겨, 학생의 성장 기록을 한곳에서 관리하려는 것입니다.

    직접 입력할 때

    • {신체발달} 탭에서 {PAPS자료불러오기}를 실시하지 않고 ‘학생찾기’로 {조회}하여 ‘키(cm)’, ‘몸무게(kg)’를 입력하면 비만도의 체질량지수, BMI는 자동계산되어 반영되고 ‘검사일자’를 입력 가능함.
    • 절차는 {신체발달} 탭 선택 → ‘키(cm)’, ‘몸무게(kg)’ 입력 → ‘검사일자’ 선택하여 {저장} 함.

    학년별 입력 탭과 반별등록 경로

    • 1학년은 건강검진 대상자로 {건강검진}에 입력하고, 2·3학년 학생은 {별도검사} 항목에 별도 검사내용을 입력함.
    • 반별등록에서는 인적생성 후, 학급 명렬표의 학생을 선택하여 저장할 수 있음. [학급담임-보건-건강기록부관리-반별등록]에서 {신체발달} 탭 선택 → 명렬표의 학생 선택 → ‘키(cm)’, ‘몸무게(kg)’ 입력 → ‘검사일자’ 선택하여 {저장} 함.

    09B
    PAPS 측정 이후PAPS 불러오기 또는 측정값 입력

    개인별 신체능력 입력(PAPS 자료불러오기 또는 측정값 입력)

    PAPS에서 측정한 체력 평가 결과를 학생별 건강기록부로 옮기는 작업입니다. {PAPS자료불러오기}를 하면 ‘심폐지구력’, ‘유연성’, ‘근력·근지구력’, ‘순발력’, ‘체지방’이 자동 반영되므로 값만 확인하고 저장합니다.

    언제?
    학기중, PAPS 체력 측정이 끝난 뒤
    누가?
    보건담당자
    어디서?
    [보건-건강기록부관리-개인별등록]
    무엇을
    어떻게?
    ‘학년도’와 {학생찾기}로 검색한 학생의 {성명}을 확인하고 {조회} → {신체능력} 탭에서 {PAPS자료불러오기}를 클릭하여 PAPS 자료 가져오기 {확인} 후 {확인} 하고 신체능력(‘심폐지구력’, ‘유연성’, ‘근력·근지구력’, ‘순발력’, ‘체지방’)의 자동 반영을 확인하여 {저장} 함.
    왜?
    체력 측정 결과가 건강기록부에 남아야 학생의 건강 상태를 신체발달과 함께 종합해 볼 수 있기 때문입니다.

    직접 입력과 반별등록 경로

    • {신체능력} 탭에서 {PAPS자료불러오기}를 실시하지 않고 ‘학생찾기’로 {조회}하여 ‘심폐지구력’, ‘유연성’, ‘근력·근지구력’, ‘순발력’, ‘비만’의 평가 종목의 측정값을 입력하여 저장함. 경로는 [건강기록부관리-개인별등록] → {신체능력}.
    • 반별 등록에서는 인적생성 후, 학급 명렬표의 학생을 선택하여 측정값을 저장할 수 있음. 경로는 [건강기록부관리-반별등록].

    07B
    예방접종 내역 확인 후

    취학 후 예방접종 등록과 수정·삭제

    취학 후에 실시한 예방접종 내역을 학생별로 남기는 작업입니다. 잘못 입력한 내역은 같은 탭에서 조회해 고칠 수 있습니다. 단, 질병관리본부 연계 자료는 수정은 불가능하고 삭제 기능만 가능합니다.

    언제?
    학기중, 예방접종 내역이 확인된 뒤
    누가?
    보건담당자
    어디서?
    [보건-건강기록부관리-개인별등록]
    무엇을
    어떻게?
    ‘학년도’와 {학생찾기}로 검색한 학생의 {성명}을 확인하고 {조회} → {취학후예방접종} 탭을 선택하고 {행추가}에서 ‘접종명’, ‘접종일자’를 선택하고 {저장} 함.
    왜?
    감염병 예방접종 이력을 건강기록부에 남겨 학생별 접종 여부를 언제든 확인할 수 있게 하려는 것입니다.

    잘못 입력한 접종내역을 고칠 때

    • [보건-건강기록부관리-개인별등록]에서 [취학후예방접종]을 선택하면 해당학년도에서 실시한 예방접종내역이 조회되어 수정 또는 삭제를 할 수 있음.
    • 단, 질병관리본부 연계 자료는 수정은 불가능하고 삭제 기능만 가능합니다.

    05A
    건강검진 실시 후1학년 한정전체 학생 일괄적용

    항목별등록으로 건강검진·구강검진 일괄 입력(1학년)

    건강기록부마감에서 학년 전체 인적사항 생성

    건강기록부 마감을 시작하는 첫 단계입니다. 학기 초 학적사항(전입, 전출, 유예 등) 변동이 있었던 학교는 이 작업으로 학교생활기록부의 인적사항을 건강기록부에 반영합니다. 4세대 나이스에서는 인적사항 생성을 건강기록부 마감 시에 실시합니다.

    언제?
    마감 시점, 학기 초 학적사항(전입, 전출, 유예 등) 변동이 정리된 뒤
    누가?
    보건담당자
    어디서?
    [보건-건강기록부관리-건강기록부마감]
    무엇을
    어떻게?
    ‘학년도’, ‘학년’을 확인하여 {조회} → 전체 학급을 대상으로 인적사항을 생성하고자 할 경우 ‘학년’ 옆에 선택 → {인적사항생성}
    왜?
    학적 변동으로 달라진 학급·번호·담임 정보를 건강기록부에 맞춰 두어 마감한 자료가 실제 재학 상태와 어긋나지 않게 하려고.

    실무 메모

    • 학기 초, 학적사항(전입, 전출, 유예 등) 변동 시 {인적사항생성}에서 ‘학년·반’ 조회하여 학교생활기록부에 기록된 인적사항을 건강기록부와 연계하였으나, 4세대 나이스에서는 건강기록부 마감 시 인적사항 생성을 실시함.

    15D
    마감 시점

    학급별 자료검증과 마감

    인적사항 생성을 마친 학년의 학급을 하나씩 검증해 마감하는 단계입니다. 학급의 모든 학생이 ‘건강검진’, ‘신체능력’, ‘신체발달’이 등록된 경우에만 반별등록에 [마감] 탭이 활성화됩니다. 필수 항목을 제공할 수 없는 학생이 있으면 반별등록에서 ‘자료검증대상제외’ 처리를 먼저 해 두어야 합니다.

    언제?
    마감 시점, 건강기록부마감에서 인적사항 생성을 완료하고 반별등록의 자료 입력과 자료검증대상제외 처리가 끝난 뒤
    누가?
    보건담당자, 학급담임교사
    어디서?
    [보건-건강기록부관리-건강기록부마감], [보건-건강기록부관리-반별등록]
    무엇을
    어떻게?
    ‘학년도’, ‘학년’을 확인하여 {조회} → 학급별 선택 → {자료검증}에서 [보건-건강기록부관리-반별등록]에서 등록된 자료검증대상제외를 확인 → {마감}
    왜?
    검진을 받지 못한 학생 때문에 학급 마감이 막히는 일을 사전에 걸러내 학년 전체 마감으로 넘어갈 수 있게 하려고.

    실무 메모

    • [보건-건강기록부관리-반별등록]에서 학급의 모든 학생이 ‘건강검진’, ‘신체능력’, ‘신체발달’이 등록된 경우에만 {자료검증}과 {미리보기} 탭 사이에 [마감] 탭이 활성화됨.
    • 자료검증 필수 항목을 제공할 수 없는 특수한 상황이 있을 경우에는 ‘자료검증대상제외’ 처리를 해야 반별 마감을 할 수 있음.

    16D
    전체마감 완료 후

    전체마감 확인 후 승인요청

    학년의 모든 학급 마감이 끝난 뒤 마지막으로 결재를 올리는 단계입니다. ‘인적사항생성’, ‘반별마감’과 학년별 학급의 ‘전체마감’이 모두 완료되어야 승인요청을 할 수 있습니다.

    언제?
    마감 시점, ‘인적사항생성’과 학급별 ‘반별마감’을 모두 끝내 학년별 ‘전체마감’이 된 뒤
    누가?
    보건담당자
    어디서?
    [보건-건강기록부관리-건강기록부마감]
    무엇을
    어떻게?
    ‘학년도’, ‘학년’을 확인하여 {조회} → ‘인적사항생성’, ‘반별마감’과 학년별 학급의 ‘전체마감’을 완료 → {승인요청}
    왜?
    학년 단위로 확정된 건강기록부를 결재 절차에 올려 더 이상 임의로 바뀌지 않는 공식 기록으로 남기려고.

    실무 메모

    • {마감}은 [보건-건강기록부관리-반별등록]에서 함. 학급의 모든 학생이 ‘건강검진’, ‘신체능력’, ‘신체발달’이 등록된 경우에만 {자료검증}과 {미리보기} 탭 사이에 [마감] 탭이 활성화됨.
    • 마감 이후 잘못된 내용을 고쳐야 할 때는 [보건-건강기록부관리-정정대장등록] 절차를 따름.

    17E
    정정 사유 발생 시반별 조회구분

    정정대장 반별 일괄 등록

    이미 등록·마감된 건강기록부 내용에 오류가 발견된 재학생이 있을 때 씁니다. 같은 학급에서 여러 학생을 한 번에 등록할 수 있으므로 조회구분을 '반별'로 선택한 뒤 시작합니다. 이 단계는 정정 사실을 대장에 올리는 것까지이며 승인요청은 아직 되지 않습니다.

    언제?
    학기중, 등록된 건강기록부 자료에서 오류가 확인된 시점.
    누가?
    보건담당자
    어디서?
    [보건-건강기록부관리-정정대장등록]
    무엇을
    어떻게?
    조회구분을 '반별'로 선택한 후 '학년도', '과정', '계열/학년/학과', '반'을 확인하고 {조회} → {등록} 후 '건강기록부 정정대장 등록' 창에서 '일괄등록'을 선택 → '학생목록' 번호 옆에 선택한 후 '항목', '오류내용', '정정내용', '정정사유'를 입력하고 {저장}함.
    왜?
    건강기록부에 남은 잘못된 기록을 근거와 함께 고쳐, 나중에 누가 왜 무엇을 바꿨는지 확인할 수 있게 하려고.

    실무 메모

    • 학교생활기록부 정정대장등록에서는 '심의일자'를 선택하고 결재완료일이 '정정일자'로 자동 반영되지만, 건강기록부 정정대장 등록에서는 {학생목록}에서 대상학생을 선택하면 '정정일자'가 자동 반영됩니다.

    18E
    일괄등록 저장 직후승인요청 선행

    개인별 세부 정정내역 저장

    업무 17에서 반별 일괄등록을 저장한 학생에 대해 실제로 바뀌는 값을 학생별로 적어 넣는 단계입니다. {승인요청}은 개인별 세부 정정내역을 기재하고 {저장}한 목록에 대해서만 가능하므로 일괄등록만 해 두고 넘어가면 상신이 되지 않습니다. 정정 항목이 '별도검사'라면 '검진일자', '검진기관'처럼 실제 값을 다시 입력합니다.

    언제?
    학기중, 정정대장 반별 일괄등록을 저장한 뒤.
    누가?
    보건담당자
    어디서?
    [보건-건강기록부관리-정정대장등록]
    무엇을
    어떻게?
    조회구분을 '반별'로 선택한 후 '학년도', '과정', '계열/학년/학과', '반'을 확인하고 {조회}하여 '성명'을 선택하고 정정대장 목록의 성명을 클릭하면 해당 학생의 '정정대장 내역'과 세부 정정사항을 입력할 수 있는 화면으로 변경됨 → '별도검사'에서 입력오류 내용을 선택하고 하단에 '검진일자', '검진기관'에서 정정사항을 입력하여 {저장}하면 정정 전 내용 '원본' 하단에 '수정'되어 표시됨.
    왜?
    고칠 값을 학생별로 확정해 승인 결재에 올릴 수 있는 상태로 만들려고.

    실무 메모

    • 건강기록부 정정대장 등록은 반별로 { 건강기록부 정정등록대장 } 창에서 {일괄등록}은 가능하지만, {승인요청}을 하기 위해서는 개인별 세부 정정내역을 기재하고 {저장}한 목록에 대해서만 {승인요청}이 가능함.

    세부 정정내역 저장 후결재 필요

    정정대장 승인요청과 완결자료반영

    개인별 세부 정정내역까지 저장한 자료를 결재에 올려 건강기록부에 실제로 반영하는 마지막 단계입니다. 결재가 완료된 뒤 {완결자료반영}을 해야 정정 내용이 건강기록부에 반영됩니다. 상신 전에는 결재선과 결재자를 지정해야 합니다.

    언제?
    학기중, 개인별 세부 정정내역을 저장한 뒤.
    누가?
    보건담당자
    어디서?
    [보건-건강기록부관리-정정대장등록]
    무엇을
    어떻게?
    조회구분을 '반별'로 선택한 후 '학년도', '과정', '계열/학년/학과', '반'을 확인하고 {조회} → 상신할 내용을 선택한 후 {승인요청}하여 '기안문서상신창'에서 {개인결재선}, {결재자지정}과 '내용'을 입력하여 {상신}하고 결재가 완료되면 {완결자료반영}함.
    왜?
    정정 내용을 결재로 공식화하고 건강기록부 원본에 반영해 기록과 대장이 서로 맞도록 하려고.

    반영이 안 될 때

    • 학교생활기록부 정정대장등록에서의 완결자료반영과는 달리 건강기록부 정정대장은 일괄등록이 가능하기에 {승인요청}, {완결자료반영} 단계에서 선택이 누락된 자료가 있는지 확인해 봅니다.

    졸업생 정정 사유 발생 시졸업생 한정

    졸업생 정정대장 등록

    이미 졸업한 학생의 건강기록부를 고쳐야 할 때만 쓰는 메뉴입니다. 재학생과 달리 조회구분의 '반별' 선택 기능이 없어 {학생찾기}로 대상 학생을 찾아야 합니다. 찾은 뒤의 절차는 재학생과 같아 개인별 세부 정정내역 저장, 승인요청, 완결자료반영을 차례로 거칩니다.

    언제?
    졸업 후, 졸업생 건강기록부의 오류가 확인된 시점.
    누가?
    보건담당자
    어디서?
    [보건-건강기록부관리-졸업생정정대장등록]
    무엇을
    어떻게?
    '졸업학년도'를 입력하고 {학생찾기} → '고등학교 학생찾기' 창에서 학년을 '전체'로 확인하고 '성명'을 입력하고 {조회}된 학생목록에서 해당 학생을 선택하여 {확인}함.
    왜?
    졸업 후 발견된 건강기록부 오류도 근거를 남겨 바로잡아, 학교가 보관하는 기록의 신뢰를 지키려고.

    실무 메모
