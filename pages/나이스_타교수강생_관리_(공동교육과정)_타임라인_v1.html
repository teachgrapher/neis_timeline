    01A
    학기초, 수강생 등록 전학년 단위 관리

    공동교육과정 타교수강생 반 정보 등록

    온라인·오프라인 공동교육과정 운영교(거점교)와 공동교육과정 거점센터에서만 하는 업무이다. 참여교 수강생을 등록하려면 먼저 그 학생을 담을 반이 있어야 하므로, 공동교육과정이 무학년인 경우 수강하는 학년수만큼 학년별로 반정보를 등록해야 함.

    언제?
    학기초, 참여교 수강생이 소속교에서 학적이 구성된 뒤 수강생 등록 전
    누가?
    공동교육과정 업무담당자
    어디서?
    [학적-타교수강생관리(공동교육과정)-타교수강생 반 정보관리]
    무엇을
    어떻게?
    ‘학년도’ 확인 후 ‘학년’을 선택하고 {조회} → {행추가} 후 ‘반 정보’에서 ‘학년도’ 확인 후 ‘학년’을 선택하고 ‘반명’, ‘정렬순서’, ‘성적반 코드’ 입력 후 {저장}
    왜?
    참여교에서 온 학생을 거점교 안에서 학년·반·번호로 자리 잡게 해, 이후 출결·성적·시간표가 붙을 틀을 먼저 만들어 두려고.

    실무 메모

    • 타교수강생 반정보 관리는 학년 단위로 관리하며, 공동교육과정이 무학년인 경우 수강하는 학년수만큼 학년별로 반정보를 등록해야 함.
    • 학과가 설치된 고등학교의 ‘반 정보’에서 ‘계열’을 ‘일반계’로 선택하는 경우 ‘학과’는 공란으로 선택할 수 없으며, 공업계, 상업계 등의 계열을 선택하면 거점교에 개설된 ‘학과’를 선택할 수 있음.
    • ‘반명’은 한글 또는 숫자로 입력할 수 있음.
    • ‘성적반코드’는 [성적-지필/수행선행작업-OMR용코드관리]의 {과목코드관리} 탭에서 지필평가 과목코드 등록 시 사용하는 코드이며, 일반적으로 반코드와 같게 두 자리로 설정함.

    02A
    학기초, 반정보 등록 직후학기 단위 등록

    공동교육과정 참여교 수강생 개별 등록

    거점교에서 참여교 학생 한 명씩을 찾아 타교수강생으로 올리는 업무이다. 학기 단위로 공동교육과정 참여교 수강생을 등록함. ‘공동교육과정 학생정보’는 반 정보관리에서 등록해 둔 값만 고를 수 있으므로 업무 01이 끝나 있어야 한다.

    언제?
    학기초, 타교수강생 반 정보 등록을 마친 뒤 학기 단위로
    누가?
    공동교육과정 업무담당자
    어디서?
    [학적-타교수강생관리(공동교육과정)-타교수강생관리(공동교육과정)-등록]
    무엇을
    어떻게?
    ‘학년도’, ‘원적교’, ‘성명(공란)’ 확인 후 {조회} → {등록}을 클릭해 나타나는 ‘타교수강생(공동교육과정) 등록’ 창에서 {학생찾기} 하여 ‘시작일자’와 ‘종료일자’ 확인 또는 선택 후 ‘교육구분’, ‘기관명’, ‘수강상태’를 확인하고 필요시 ‘전공’과 ‘비고’를 입력 → ‘원적교 학생정보’에서 타교수강생의 ‘학교명’, ‘학생부 자료 전송 학기’, ‘과정’, ‘학년’, ‘반’, ‘번호’ 확인 → ‘공동교육과정 학생정보’에서 ‘학년’, ‘반’ 선택하고 ‘번호(자동으로 마지막 번호가 표기됨)’ 입력 후 {저장}하고 ‘타교수강생 목록’에서 확인
    왜?
    참여교 학적에 있는 학생을 거점교 명부에 연결해, 출결·성적·기록 자료가 그 학생의 소속교로 되돌아갈 통로를 만들려고.

    입력값 관련

    • 학기 단위로 공동교육과정 참여교 수강생을 등록함.
    • ‘시작일자’와 ‘종료일자’는 거점교 교무학기 시작일과 종료일이 자동으로 설정됨.
    • ‘공동교육과정 학생정보’는 [타교수강생반정보관리]에서 등록한 ‘계열’, ‘학과’, ‘학년’, ‘반’ 정보만 설정할 수 있음. 일반고등학교에서는 ‘학년’, ‘반’ 정보만 설정할 수 있음.
    • 학과가 설치된 고등학교의 ‘공동교육과정 학생정보’에서 ‘계열’을 ‘일반계’로 선택하는 경우 ‘학과’는 공란으로 선택할 수 없으며, 공업계, 상업계 등의 계열을 선택하면 거점교에 개설된 ‘학과’를 선택할 수 있음.

    학생찾기와 상태 변화

    • 공동교육과정 참여교 수강생 등록 시 ‘확인 미요청’과 ‘미반영’의 숫자가 1씩 증가함.
    • ‘타교수강생(공동교육과정) 등록’ 창에서 {학생찾기} 클릭 시 ‘학교찾기’와 ‘학생찾기’를 순서대로 수행하여 참여교 수강생을 검색하여 반영함.
    • ‘학생찾기’ 시 참여교 교무학기 설정 학기를 가져옴.
    • ‘학생부 자료 전송 학기’는 거점교에서 자료전송 시 참여교의 자료수신 학기임.

    03A
    학기초, 등록 대상이 많을 때개별 등록으로 대체 가능

    참여교 수강생 일괄등록 · 수강생조회로 등록

    등록할 참여교 수강생이 많을 때 개별 등록 대신 쓰는 방법이다. 엑셀 서식으로 한 번에 올리거나, 나이스플러스로 수강신청한 학생 명단을 그대로 가져올 수 있다. {엑셀내려받기} 시 파일명은 ‘타교수강생 일괄등록 템플릿.xlsx’로 정해져 있음.

    언제?
    학기초, 타교수강생 반 정보 등록을 마친 뒤 수강생 등록 단계에서
    누가?
    공동교육과정 업무담당자
    어디서?
    [학적-타교수강생관리(공동교육과정)-타교수강생관리(공동교육과정)-등록]
    무엇을
    어떻게?
    {일괄등록}으로 참여교 수강생을 엑셀 파일로 작성하여 업로드 → {엑셀내려받기}로 ‘타교수강생 일괄등록 템플릿.xlsx’를 받아 엑셀 프로그램으로 열기하여 ‘공동교육과정 정보’와 ‘원적교 정보’를 입력하고 저장 → 또는 {수강생조회}로 나이스플러스를 통해 공동교육과정 개설 과목을 수강신청한 학생들의 정보를 확인하고 공동교육과정 수강생으로 등록
    왜?
    수강신청 결과와 이미 정리된 명단을 그대로 옮겨, 학생 한 명씩 학교찾기·학생찾기를 반복하며 생기는 누락과 오기를 줄이려고.

    실무 메모

    • {일괄등록}으로 참여교 수강생을 엑셀 파일로 작성하여 업로드 할 수 있음.
    • {엑셀내려받기} 시 파일명은 ‘타교수강생 일괄등록 템플릿.xlsx’로 정해져 있음.
    • ‘타교수강생 일괄등록 템플릿.xlsx’ 파일을 엑셀 프로그램으로 열기하여 ‘공동교육과정 정보’와 ‘원적교 정보’를 입력하고 저장함.
    • {수강생조회}로 나이스플러스를 통해 공동교육과정 개설 과목을 수강신청한 학생들의 정보를 확인하며, 공동교육과정 수강생으로 등록할 수 있음.

    05B
    수강생 등록 직후참여교 승인 필요

    공동교육과정 참여교 수강생 확인요청

    거점교에서 타교수강생으로 등록한 참여교 수강생을 참여교에 확인해 달라고 요청하는 단계입니다. '1) 공동교육과정 참여교 수강생 등록'에서 등록한 수강생만 '확인요청목록'에 나타납니다. 참여교의 승인 절차가 끝나야 다음 학적반영을 진행할 수 있습니다.

    무엇을
    어떻게?
    [학적-타교수강생관리(공동교육과정)-타교수강생관리(공동교육과정)-확인요청]에서 '학년도', '학기', '학년', '성명(공란)' 확인 후 {조회} → '확인요청목록'에서 '1) 공동교육과정 참여교 수강생 등록'에서 등록한 공동교육과정 참여교 수강생 선택 후 {확인요청} 함.
    왜?
    거점교가 등록한 수강생 정보가 소속교의 학적과 어긋나지 않는지 참여교로부터 확인받아 두려고.

    • 공동교육과정 참여교에서 공동교육과정 업무당당자가 나이스 로그인 시 '업무요청내역'에 공동교육과정 수강생에 대한 확인요청 안내가 표시됨.

    참여교에서 하는 일

    • 공동교육과정 참여교의 [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생확인요청 접수 및 전송]에서 학생 '성명'을 클릭하여 '공동교육과정학생 상세정보' 창에서 공동교육과정 수강생의 정보 확인 후 공동교육과정 수강생을 선택하고 {승인요청}으로 업무승인과정을 거쳐 결재를 완료하고 {요청확인} 함.
    • {요청확인} 시 '전송상태'가 '전송대기'에서 '전송완료'로 변경됨.
