    01A
    연중 수시상장번호설정 선행

    개인 수상 등록하고 승인요청

    각종 대회의 개인 단위 수상이나 모범상 등 표창장을 발급할 때 쓰는 업무이다. 상장양식이 등록되고 상장번호가 설정되어 있어야 상장번호와 수여기관이 제대로 채워진다. 등록만으로 끝나지 않고 승인요청까지 해야 학교생활기록부 수상경력으로 이어진다.

    언제?
    연중, 상장양식 등록과 상장번호 설정이 끝난 뒤 수상이 확정된 시점.
    누가?
    수상 업무담당교사, 해당 교내상의 업무담당교사
    어디서?
    [학생생활-수상경력-수상대장관리]
    무엇을
    어떻게?
    [학생생활-수상경력-수상대장관리]의 {수상대장관리} 탭에서 조회 조건 확인하고 {조회} 하여 {개인/단체수상등록} 함 → '개인/단체 수상 등록' 창에서 {학생추가하기} 하여 '개인/단체(개인선택)', '교내/교외', '수상명', '상장명(코드)', '등급(위)', '수상년월일', '수여기관', '참가대상(참가인원)', '학생부반영여부'를 선택 또는 입력하여 {저장} 후 {닫기} 하여 {승인요청} 함.
    왜?
    학생이 받은 개인 표창을 상장으로 발급하고, 결재가 끝난 내역만 학교생활기록부 수상경력에 남기려고.

    실무 메모

    • '교내/교외' 구분을 '교내'로 설정하면 상장번호설정에 따라 상장번호와 수여기관은 자동으로 입력됨.
    • '상장명(코드)'을 선택하면 나이스에 등록된 상장양식으로 상장을 출력할 수 있음.
    • 수상등록 시 '학생부 반영여부'를 선택한 후 수상대장의 결재가 완료되면 해당 학생의 학교생활기록부 수상경력에 자동 반영됨.
    • 2024학년도 대입(졸업생 포함)부터 상급학교 진학 시 '수상경력'은 제공하지 않음.

    02A
    연중 수시2인 이상 공동수상·학년·학급 단위

    단체·공동 수상 등록하고 승인요청

    각종 대회에서 동일 실적물로 2인 이상이 수상한 경우, 또는 학교생활기록부 수상경력란에 입력할 수 없는 학년·학급 단위의 단체상장을 발급할 때 쓰는 업무이다. 절차는 개인 수상과 같은 창에서 진행하지만 '개인/단체' 구분에서 '단체'를 선택하면 단체에 속한 모든 학생들에게 동일한 상장번호가 부여되므로 대상 범위를 먼저 확정해야 한다.

    언제?
    연중, 상장양식 등록과 상장번호 설정이 끝난 뒤 공동·단체 수상이 확정된 시점.
    누가?
    수상 업무담당교사, 해당 교내상의 업무담당교사
    어디서?
    [학생생활-수상경력-수상대장관리], [학생생활-수상경력-학급별수상관리]
    무엇을
    어떻게?
    [학생생활-수상경력-수상대장관리]의 {수상대장관리} 탭에서 조회 조건 확인하고 {조회} 하여 {개인/단체수상등록} 함 → '개인/단체 수상 등록' 창에서 {학생추가하기} 하여 '개인/단체(단체 선택)', '교내/교외', '수상명', '상장명(코드)', '등급(위)', '수상년월일', '수여기관', '참가대상(참가인원)', '학생부반영여부'를 선택 또는 입력 후 {저장} 하고 {닫기} 하여 {승인요청} 함.
    왜?
    같은 실적으로 함께 상을 받은 학생들에게 같은 상장번호로 상장을 발급하고, 학생부에 올릴 수 있는 것과 올릴 수 없는 것을 구분해 남기려고.

    등록 후 확인

    • 단체수상의 경우 [학생생활-수상경력-수상대장관리]의 {수상대장조회} 탭에서 조회하면 단체수상 대표명이 등록된 상 하나만 조회되며, 단체상을 수상한 나머지 학생은 [학생생활-수상경력-학급별수상관리]의 {학급별수상조회} 탭에서 입력상태 확인 가능함.

    입력 규칙

    • '개인/단체' 구분에서 '단체'를 선택한 경우 단체에 속한 모든 학생들에게 동일한 상장번호가 부여됨.
    • 공동수상은 동일 실적물로 2인 이상이 수상한 경우로 '단체'로 등록하여 동일한 상장번호로 발급하고, '수상대표명'은 '홍길동외 3인'과 같이 입력할 수 있으며, '수상명'란에 수상명을 입력하고 ( ) 안에 '공동수상'과 '수상인원'을 입력함.
    • 학년·학급 단위의 단체수상은 수상대장에는 입력할 수 있으나 학교생활기록부의 수상경력에는 반영하지 않음.

    03B
    학기말 성적산출 완료 후교과목 권한 필요

    성적우수자 수상 일괄등록

    학기말 성적에 대한 교과우수상을 등록할 때 사용하는 업무입니다. [성적-성적처리선행작업-성적산출기준명관리]에서 '성적구분'이 '학기말'인 성적산출 기준명이 등록되고 학기말 성적산출이 완료되어 있어야 합니다. 동점자로 수상인원 초과문제가 발생할 수 있으므로 학교별 교과우수상 선정기준을 먼저 확인합니다.

    언제?
    학기말, 학기말 성적산출이 완료된 뒤.
    누가?
    수상 업무담당교사
    어디서?
    [학생생활-수상경력-수상대장관리]
    무엇을
    어떻게?
    [학생생활-수상경력-수상대장관리]의 {수상대장관리} 탭에서 '학년도'와 조회 조건 확인 후 {조회}하고 {성적우수자수상등록}함 → '성적우수자 수상 일괄등록' 창에서 '학년도' 확인 후 '학기', '학년', '산출기준', '조건'을 선택한 다음 {찾기}로 시상할 과목을 선택하고 {선택}하여 '조건'을 등록하여 {조회}함 → 목록에서 해당 학생을 선택하고 '개인/단체', '교내/교외', '수상명', '상장명(코드)', '수상년월일', '수여기관', '참가대상', '학생부반영여부'를 선택 또는 입력하여 {저장}하고 {승인요청}함.
    왜?
    학기말 성적으로 가려낸 우수자를 한 번에 시상해, 결재 완결과 동시에 해당 학생의 학교생활기록부 수상경력까지 어긋남 없이 남기려고.

    수상명·참가대상 입력 규칙

    • 교과우수상을 여러 과목에서 수상한 경우는 ( ) 안에 수상과목을 병기함. 예시) 교과우수상(공통국어1, 공통영어1, 공통수학1).
    • 교과우수상의 과목명은 교과목의 정식 명칭으로 입력함. 예시) 기술･가정, 공통수학1, 화법과 작문.
    • 교과우수상의 경우 '참가대상(참가인원)'란에 참가대상은 '수강자'로 입력하되, 참가인원은 입력하지 않음.
    • 성적우수상 ( ) 안의 과목 정렬 순서는 편제 순서가 적용되므로 [교육과정-편제및시간배당기준관리-편제및시간배당관리]에서 편제명 순서를 확인함.
    • 상장양식의 ( ) 안에 개별 과목명을 출력하려면 {상장출력} 탭에서 “□ 체크되면 수상명 “( )” 안의 글자는 출력시 등급 앞에 표시됩니다”를 선택함.

    조회가 안 될 때

    • {성적우수자수상등록}을 이용하기 위해서는 [성적-성적처리선행작업-성적산출기준명관리]에서 '성적구분'이 '학기말'인 성적산출 기준명의 등록과 학기말 성적산출이 완료되어 있어야 함.
    • 조회조건의 '산출기준', '과목' 목록에 '-없음-'으로 나타나면 [성적-성적조회-성적우수/부진자명단조회]에서 조회된 성적이 학기말 성적인지 확인함. '과목' 목록이 '-없음-'인 경우에는 학교권한관리자에게 요청하여 교과목 권한을 부여 받음.
    • 특정 학년만 조회되지 않으면 학교권한관리자에게 요청하여 해당 학년 교과목 권한을 부여받고 학기말 성적처리 완료 여부를 확인 후 조회함.
    • 동석차로 수상에서 제외되는 학생은 '성적우수자 수상 일괄등록' 창의 '분야'에서 해당 과목을 삭제함.
    • {성적우수자수상등록}은 학기말 교과우수상을 등록할 때 유용하지만 동점자에 따른 수상인원 초과문제가 발생할 수 있음(학교별 교과우수상 선정기준에 따라 다를 수 있음).

    04B
    학년말 출결 마감 후

    출석우수자 수상 일괄등록

    개근상 등 출결 관련 상장을 등록할 때 사용하는 업무입니다. 조회되는 수업일수와 출결상황은 학교생활기록부에 반영된 자료를 기준으로 하므로, 수상년월일까지의 출결이 일일출결관리에 입력되고 반별월출결마감관리에서 마감되어 있어야 합니다. 조회 기준은 학교 규정에 따라 설정합니다.

    언제?
    학년말, 수상년월일까지의 출결자료가 마감되어 학교생활기록부에 반영된 뒤.
    누가?
    수상 업무담당교사
    어디서?
    [학생생활-수상경력-수상대장관리]
    무엇을
    어떻게?
    [학생생활-수상경력-수상대장관리]의 {수상대장관리} 탭에서 '학년도' 확인 후 {조회}하여 {출석우수자수상등록}함 → '출석우수자 수상 일괄등록' 창에서 '학년', '출석산출기준'을 선택하고 {조회}하여 목록에서 해당 학생을 선택함 → '개인/단체', '교내/교외', '수상명', '상장명(코드)', '수상년월일', '수여기관', '참가대상(참가인원)', '학생부반영여부'를 선택 또는 입력하고 {저장} 후 {닫기}하여 {승인요청}함.
    왜?
    마감된 출결자료를 기준으로 개근 대상을 가려내 학생이 실제 출석한 대로 상을 받게 하려고.

    실무 메모

    • {출석우수자수상등록}은 학년말 출결 관련 수상(개근)을 등록할 때 유용하며, 학교 규정에 따라 조회 기준을 설정하여 수상대장에 등록하고 상장출력을 할 수 있음.
    • {출석우수자수상등록}에서 조회되는 수업일수와 출결상황은 학교생활기록부에 반영된 자료를 기준으로 조회되므로 [학적-출결관리-출결관리-일일출결관리(담임용)]에서 수상년월일까지의 출결상황을 입력하고 [학적-출결관리-출결관리-반별월출결마감관리]에서 마감하여 출결자료가 학교생활기록부에 반영되어 있어야 함.
    • '3년 개근상'을 수상하는 경우, 3학년의 '1년 개근상'은 자동으로 제외됨.
    • 기안문서상신 과정을 거쳐 결재권자의 결재가 완료되면 학교생활기록부 수상경력란에 등록됨.

    타임라인으로 돌아가기

    05C
    결재 완료 후 오류 발견 시작성자 본교 재직

    작성자가 재직 중일 때 기결문서취소로 수정 길 열기

    이미 결재가 완료된 수상대장에서 오류를 발견한 경우에 해당합니다. 해당 수상 기안자가 본교에 재직하고 있어야 기안자 본인의 상신함에서 기결문서취소를 진행할 수 있습니다. 기결문서취소 결재가 완결되어야 수상대장 자료를 고칠 수 있습니다.

    언제?
    연중, 수상대장 결재가 완료된 뒤 오류를 발견한 시점
    누가?
    해당 교내상의 업무담당교사(기안자), 수상 업무담당교사
    어디서?
    [승인사항-상신함], [학생생활-수상경력-수상대장관리]
    무엇을
    어떻게?
    해당 수상 기안자의 [승인사항-상신함]에서 '결재문서명'란에 '수상대장'을 입력하고 '상신기간' 설정하여 {조회} → 수정해야 할 '결재문서명'을 선택 후 {기결문서취소}하여 {확인}.
    왜?
    결재로 잠긴 수상 내역과 학교생활기록부 수상경력의 잘못된 값을 바로잡을 수 있게 문서를 다시 열어두려고.

    실무 메모

    • 기결문서취소 결재가 완결되면 수상업무담당자가 [학생생활-수상경력-수상대장관리]에서 해당 수상대장 자료의 수정이 가능함.
    • 전년도 수상대장 정정의 경우 [학생부-정정대장관리-정정대장작성]에서 정정하여 수정함.

    06C
    결재 완료 후 오류 발견 시작성자 본교 미재직

    작성자가 재직하지 않을 때 결재문서 삭제로 수정 길 열기

    결재가 완료된 수상대장에 오류가 있으나 수상대장 작성자가 본교에 재직하지 않는 경우에 해당합니다. 기안자 본인이 상신함에서 기결문서취소를 할 수 없으므로, 학교업무분장관리자 아이디로 로그인해 결재문서를 삭제합니다.

    언제?
    연중, 수상대장 결재가 완료된 뒤 오류를 발견한 시점
    누가?
    학교업무분장관리자
    어디서?
    [[업무승인관리]업무승인-결재현황관리-결재현황판관리], [학생생활-수상경력-수상대장관리]
    무엇을
    어떻게?
    학교업무분장관리자 아이디로 로그인 후 [[업무승인관리]업무승인-결재현황관리-결재현황판관리]에서 해당 수상문서에 대해 '기안자' {찾기} 후 '상신기간'을 설정하여 {조회} → 수정해야 할 '결재문서명'을 선택 후 {삭제}하여 {결재문서삭제} 창에서 '삭제사유'를 등록하고 {삭제}.
    왜?
    작성 교사가 학교를 떠난 뒤에도 잘못 결재된 수상 기록을 학교 차원에서 정리할 수 있게 하려고.

    실무 메모

    • 삭제 이후 수상업무담당자가 [학생생활-수상경력-수상대장관리]에서 해당 수상대장 자료의 수정이 가능함.
    • '삭제사유'를 등록해야 결재문서 삭제가 진행됨.
    • 전년도 수상대장 정정의 경우 [학생부-정정대장관리-정정대장작성]에서 정정하여 수정함.
