    01A
    지필평가 실시 전문항정보표 마감 필요2회 이상 라운드 권장

    라운드 등록과 최소능력자 예상정답률 입력·마감

    추정 분할점수를 이용해서 성취율을 산출하는 과목이라면 교과담당교사가 고사·학년·과목·라운드 단위로 최소능력자 예상정답률을 직접 입력한다. [교과담임-성적-지필평가-문항정보표관리]에서 해당 고사의 과목에 대한 문항정보표가 마감되어 있어야만 최소능력자 예상정답률 입력이 가능함. '성취기준', '난이도', '배점' 등을 입력하지 않고 {마감}한 경우에는 지필평가에 대한 추정 분할점수를 산출할 수 없다.

    언제?
    지필평가와 수행평가 실시 전, [성적-지필/수행선행작업-성취평가기준관리]의 과목별 성취기준과 [성적-지필평가-문항정보표관리]의 문항정보표 등록·마감이 끝난 뒤
    누가?
    교과담당교사
    어디서?
    [성적-분할점수-분할점수관리-지필평가추정분할점수산출관리]
    무엇을
    어떻게?
    [성적-분할점수-분할점수관리-지필평가추정분할점수산출관리]에서 '학년도', '학기' 확인 후 '고사', '학년', '과목', '라운드'를 선택하고 {조회}함 → {예상정답률입력} 탭에서 '최소능력자 예상정답률(%)'을 입력하고 {저장} 및 {입력마감}함.
    왜?
    성취도를 매기는 기준선을 교사들의 전문적 판단으로 미리 합의해 두어, 고사 결과가 나온 뒤 임의로 등급 경계가 흔들리지 않게 하려고.

    입력 조건과 제약

    • '최소능력자 예상정답률(%)'은 5% 단위로 입력 가능함. 단, 'E 단계'는 5% 단위를 벗어나서(예: 49% 등) 입력 가능함.
    • 2026학년도 기준으로 평가단계는 5수준+미도달만 선택 가능함. 2015 개정 교육과정을 적용받는 2026학년도 3학년 과목에서 '5수준(A-E)+미도달'을 선택하는 경우 E/미도달 추정 분할점수가 산출되나 확인용도로만 제공되며, E등급의 성취율은 0으로 고정 반영됨.
    • 예상정답률 제약조건을 충족하지 못하는 경우 적색 글자로 표시되며, 라운드 확정이 불가능함. 최소능력자 예상정답률은 상위수준의 예상정답률보다 높을 수 없음. 난이도별 최소 정답률은 낮은 난이도가 높은 난이도보다 정답률이 낮을 수 없음.
    • 상위 성취수준에 해당되는 최소능력자 예상정답률과 차하위 성취수준에 해당되는 최소능력자 예상정답률 간의 차이가 20% 이상인 경우 차하위 정답률 칸의 색상이 적색으로 표시됨(예시: A 95, B 65인 경우).
    • {예상정답률입력} 탭에서 조회되는 '문항구분', '난이도', '해당문항번호', '문항수', '배점합'의 정보는 [성적-지필평가-문항정보표관리]에서 입력한 지필평가 과목의 내용임.
    • 지필평가 추정 분할점수는 소수점 둘째 자리까지 산출됨.

    라운드 운영

    • {라운드등록}하면 '라운드 번호'가 추가되고 '복사대상라운드'에서 이전에 등록한 라운드를 선택하고 {등록}하면 선택한 라운드의 내용이 복사되고 수정할 수 있음.
    • 나이스에서는 라운드를 1회만 진행해도 추정분할점수를 확정할 수 있으나, 2회 이상 라운드 실시를 권장함.
    • 분할점수 산출 시 1, 2라운드를 합산하여 산출하는 것이 아닌 해당 라운드 중에 최종 확정한 라운드에 한해 학기말 분할점수에 활용하도록 되어 있음.
    • {라운드삭제}에서 불필요한 라운드를 삭제할 수 있음.
    • 추정분할점수 확정 시 동일교과 수업에 참여하는 모든 교사가 예상정답율 입력 후 마감이 되어야만 {확정}이 가능함. 다만 현재는 한시적으로 모든 교사가 예상정답률을 등록하지 않아도 업무 처리가 가능함.

    02A
    예상정답률 입력 중·마감 전후조회 전용

    교사별·문항범주별·예상분할점수 조회로 입력 내용 확인

    동일 교과를 여러 교사가 담당하는 과목이라면 라운드를 확정하기 전에 다른 교사의 입력 값과 산출될 분할점수 분포를 미리 확인한다. 세 탭은 모두 조회 기능이므로 입력 값이 바뀌지 않으며, 절차는 탭을 선택하고 {조회}하는 것으로 같다.

    언제?
    지필평가 예상정답률 입력 중이거나 {입력마감} 이후 라운드 확정 전
    누가?
    교과담당교사
    어디서?
    [성적-분할점수-분할점수관리-지필평가추정분할점수산출관리]
    무엇을
    어떻게?
    '학년도', '학기' 확인 후 '고사', '학년', '과목', '라운드'를 선택하고 {조회}함 → {교사별입력정보조회} · {문항범주별조회} · {예상분할점수조회} 탭 중 필요한 탭을 선택하여 {조회}함.
    왜?
    교사 간 판단 차이와 성취수준별 분포를 확정 전에 눈으로 맞춰 보고, 한쪽으로 치우친 분할점수로 확정되는 일을 막으려고.

    어떤 탭을 언제 여는가

    • {교사별입력정보조회} 탭 — 다른 교사가 입력한 지필평가의 정답률이 나타나고 교사명을 입력하여 특정 교사의 입력 내용을 {조회}할 수 있음. 동일교과 모든 교사의 입력·마감 여부를 확인할 때 사용함.
    • {문항범주별조회} 탭 — 지필평가 문항유형(난이도)에 따른 각 성취수준의 '평균', '표준편차', '최솟값', '최댓값'을 조회할 수 있음.
    • {예상분할점수조회} 탭 — 해당 지필평가 예상분할점수 성취수준의 '평균', '표준편차', '최솟값', '최댓값'을 조회할 수 있음. 라운드를 확정하기 전 최종 확인용으로 사용함.

    07C
    지필평가와 수행평가 실시 전전체영역 또는 영역별 중 택일

    수행평가 추정분할점수 입력(전체영역 / 영역별)

    수행평가 추정분할점수는 지필평가처럼 라운드를 돌려 산출하는 것이 아니라 교과별 평가계획에서 설정한 성취수준별 분할점수를 그대로 입력하는 업무입니다. '전체영역'과 '영역별' 중 하나를 선택하여 입력합니다. 학기말 추정분할점수 산출 전에 마쳐 두어야 합니다.

    언제?
    지필평가와 수행평가 실시 전, 과목별 성취기준 등록이 끝난 뒤
    누가?
    교과담당교사
    어디서?
    [성적-분할점수-분할점수관리-수행평가추정분할점수산출관리]
    무엇을
    어떻게?
    [성적-분할점수-분할점수관리-수행평가추정분할점수산출관리]에서 '학년도', '학기' 확인 후 '학년', '과목'을 선택하고 {조회} → '수행평가 추정분할점수'에서 '전체영역'을 선택 후 '성취수준별 추정분할점수'를 입력하고 {저장} → 영역별로 설정하는 경우에는 '수행평가 추정분할점수'에서 '영역별'을 선택 후 '성취수준별 분할점수'를 입력하여 {저장}.
    왜?
    교과별 평가계획에서 합의한 성취수준 기준을 수행평가에도 그대로 적용해, 학기말 최종 추정 분할점수가 계획과 어긋나지 않게 하려고.

    실무 메모

    • 수행평가 분할점수는 '전체영역' 혹은 '영역별' 중 하나를 선택하여 수행평가에 대한 추정분할점수를 설정함.
    • 수행평가에 대한 추정분할점수는 교과별 평가계획에서 설정한 성취수준별 분할점수를 설정함.

    04B
    예상정답률 입력마감 후결재 완료 시 자동 확정

    지필평가 추정분할점수 라운드 확정 승인요청·상신

    라운드별로 입력한 예상정답률 가운데 최종적으로 사용할 라운드 하나를 골라 확정하는 단계입니다. 동일교과 수업에 참여하는 모든 교사가 예상정답율 입력 후 마감이 되어야만 {확정}이 가능함. 나이스에서는 라운드를 1회만 진행해도 추정분할점수를 확정할 수 있으나, 2회 이상 라운드 실시를 권장함.

    언제?
    지필평가 실시 전, 문항정보표 마감과 최소능력자 예상정답률 입력마감이 끝난 뒤
    누가?
    교과담당교사
    어디서?
    [성적-분할점수-분할점수관리-지필평가추정분할점수산출관리]
    무엇을
    어떻게?
    {추정분할점수산출결과관리}에서 '지필평가추정분할점수-산출결과관리' 창에서 적용할 '라운드' 선택 후 {승인요청}하고 {확인}함 → '기안문서상신' 창에서 '내용', '결재선', 산출된 추정 분할점수 자료 확인 후 {상신}함.
    왜?
    여러 라운드 가운데 학교가 실제로 쓸 분할점수 기준 하나를 공식 결재로 못 박아 학기말 최종 분할점수의 근거로 삼으려고.

    실무 메모

    • 지필평가 추정 분할점수의 라운드 회차 확정은 '지필평가추정분할점수-산출결과관리' 창에서 {승인요청}해야 하며, 결재 완료 이후 해당 회차의 라운드가 자동 확정됨.
    • 분할점수 산출 시 1, 2라운드를 합산하여 산출하는 것이 아닌 해당 라운드 중에 최종 확정한 라운드에 한해 학기말 분할점수에 활용하도록 되어 있음.
    • 확정한 라운드가 최종 학기말 분할점수로 산출됨.
    • {라운드삭제}에서 불필요한 라운드를 삭제할 수 있음.
    • 2026학년도 기준으로 평가단계는 5수준+미도달만 선택 가능함.
    • 2015 개정 교육과정을 적용받는 2026학년도 3학년 과목에서 '5수준(A-E)+미도달'을 선택하는 경우 E/미도달 추정 분할점수가 산출되나 확인용도로만 제공되며, E 등급의 성취율은 0으로 고정 반영됨.

    05B

    교과에서 협의로 정한 추정 분할점수가 학기말 성적의 성취율 산출에 실제로 쓰이게 하려고.

    실무 메모

    • [성적-성적처리선행작업-성적산출선행작업관리-분할점수산출결과]에서 2025학년부터 수기 입력이 제한되며, {산출결과가져오기}하여 해당 과목의 학기말 최종 추정 분할점수를 선택 및 {저장}하여 입력해야 함.
    • [성적-성적처리선행작업-성적산출선행작업관리-분할점수산출결과]에서 과목별로 산출결과를 {산출결과가져오기}하여 입력된 정보가 있을 경우 ‘분할점수 산출결과에서 사용됨’이라는 안내문구가 나타나며, {추정분할점수산출취소}할 수 없음.
    • [성적-성적처리선행작업-성적산출선행작업관리-분할점수산출결과]에서 해당 과목의 성취율을 {삭제} 후 취소가 가능함.
    • 2015 개정 교육과정을 적용받는 2026학년도 3학년 과목에서 [지필평가추정분할점수산출관리]의 ‘평가단계’ 5수준(A-E)을 선택하는 경우, [교과담임-성적-분할점수-분할점수관리-학기말추정분할점수산출]에서 산출된 ‘학기말최종추정분할점수’가 적용됨.

    타임라인으로 돌아가기

    12E
    학기말 성적산출 전학과별 통합산출 과목 한정권장 경로

    통합산출 과목의 대표학과 분할점수 산출결과복사

    학과가 여러 개인 학교에서 학기말 성적을 학과별로 통합산출하는 과목에만 해당한다. 추정분할점수는 학과별로 산출이 가능하므로 학과별로 분리 산출하는 경우에는 각각의 학과에서 산출하면 되지만, 학기말 성적산출 시 통합산출하는 과목의 분할점수는 동일해야 성적산출이 가능하다.

    언제?
    학기말, 대표학과에서 학기말 최종 추정 분할점수를 산출한 뒤 성적산출 전.
    누가?
    교과담당교사
    어디서?
    [성적-성적처리선행작업-성적산출선행작업관리-분할점수산출결과]
    무엇을
    어떻게?
    추정분할점수 산출 시 대표학과에 대해서만 분할점수를 산출함 → 다른 학과에서는 [성적-성적처리선행작업-성적산출선행작업관리-분할점수산출결과]에서 {산출결과복사}로 대표 학과의 분할점수를 가져와 처리함.
    왜?
    통합산출 과목의 학과별 분할점수를 어긋나지 않게 맞춰 학기말 성적이 막히지 않도록 하려고.

    실무 메모

    • 추정분할점수는 학과별로 산출이 가능하여 학기말 성적을 학과별로 분리 산출하는 경우에는 각각의 학과에서 분할점수를 산출하여 처리할 수 있음.
    • 학과별로 성적을 통합산출하는 과목의 경우에는 추정분할점수 산출 시 대표학과에 대해서만 분할점수를 산출하고, 다른 학과에서는 {산출결과복사}로 대표 학과의 분할점수를 가져오기 하여 처리하는 것을 권장함.
    • 학기말 성적산출 시 통합산출하는 과목의 분할점수는 동일해야 성적산출이 가능함.
    • 문항 오류 등으로 지필평가 과목의 만점이 100점이 아닌 경우에도 학기말 최종 추정 분할점수 산출이 가능함.

    타임라인으로 돌아가기

    13E
    가정통신문 등 안내 준비 시전 교과목 자료 권한 필요

    전과목 학기말 추정분할점수 확인·출력

    성적처리 담당교사가 가정통신문 등으로 전체 교과의 분할점수를 안내해야 할 때 쓴다. [성적-성적처리선행작업-성적산출선행작업관리-분할점수산출결과]는 학기말에만 확인되므로, 다른 교과 분할점수는 학기말추정분할점수산출 메뉴의 {전과목출력}으로 본다. 해당 교사에게 분할점수를 확인하기 위한 모든 교과목 권한이 부여되어 있어야 조회할 수 있다.

    언제?
    학기말 추정분할점수가 산출된 뒤, 전체 교과 분할점수를 확인해야 할 때.
    누가?
    성적처리담당교사
    어디서?
    [성적-분할점수-분할점수관리-학기말추정분할점수산출관리]
    무엇을
    어떻게?
    해당 학년의 과목별 자료 권한 부여에 따라 {전과목출력} → ‘학기말 추정분할점수 조회-전체교과목’ 창에서 과목별 학기말 추정 분할점수를 확인 → 저장 또는 출력함.
    왜?
    교과별로 흩어진 분할점수를 한자리에서 확인해 학생·학부모 안내 자료를 정확하게 만들려고.

    실무 메모

    • 성적처리 담당교사의 경우 [성적-분할점수-분할점수관리-학기말추정분할점수산출관리] 메뉴에 있는 {전과목 출력} 기능을 통해 확인이 가능함.
    • 이때 해당 교사에게는 분할점수를 확인하기 위한 모든 교과목 권한이 부여되어 있어야 조회할 수 있음.
    • {전과목출력}으로 해당 학년의 과목별 자료 권한 부여에 따라 {전과목출력}하여 ‘학기말 추정분할점수 조회-전체교과목’ 창에서 과목별 학기말 추정 분할점수를 확인하여 저장 또는 출력할 수 있음.

    10D
    문항정보표·예상정답률 수정이 필요할 때필요 시

    학기말 추정분할점수 산출취소와 마감취소

    산출 또는 마감을 마친 뒤 문항정보표나 예상정답률을 고쳐야 하는 경우에만 하는 업무다. [성적-성적처리선행작업-성적산출선행작업관리-분할점수산출결과]에서 {산출결과가져오기}로 입력된 정보가 있으면 '분할점수 산출결과에서 사용됨' 안내문구가 나타나며 {추정분할점수산출취소}를 할 수 없다. 이때는 해당 과목의 성취율을 {삭제}한 후에 취소가 가능하다.

    언제?
    학기말 추정분할점수 산출 또는 마감 이후, 문항정보표나 예상정답률 수정이 필요한 때
    누가?
    교과담당교사
    어디서?
    [성적-분할점수-분할점수관리-학기말추정분할점수산출], [성적-성적처리선행작업-성적산출선행작업관리-분할점수산출결과], [승인사항-상신함]
    무엇을
    어떻게?
    산출 결과를 되돌릴 때는 {추정분할점수산출취소}함 → 이미 마감한 경우 [승인사항-상신함]에서 해당 과목의 '학기말 추정분할점수산출 마감' 문서를 {기결문서취소}로 업무승인과정을 거쳐 결재를 완료하면 {마감취소}가 {마감}으로 변경됨.
    왜?
    문항정보표나 예상정답률이 잘못된 채 확정된 기준으로 성취도가 판정되는 것을 막으려고.

    산출취소가 막히는 경우

    • [성적-성적처리선행작업-성적산출선행작업관리-분할점수산출결과]에서 과목별로 산출결과를 {산출결과가져오기}하여 입력된 정보가 있을 경우 '분할점수 산출결과에서 사용됨'이라는 안내문구가 나타나며, {추정분할점수산출취소}할 수 없음.
    • [성적-성적처리선행작업-성적산출선행작업관리-분할점수산출결과]에서 해당 과목의 성취율을 {삭제} 후 취소가 가능함.
    • {추정분할점수산출} 이후 문항정보표나 예상정답율에 대한 수정이 필요한 경우 {추정분할점수산출취소}를 통해 산출된 결과 취소할 수 있음.

    마감취소 절차

    • {마감}하면 {마감취소} 버튼이 생성되며, [승인사항-상신함]에서 해당 과목의 '학기말 추정분할점수산출 마감' 문서를 {기결문서취소}로 업무승인과정을 거쳐 결재를 완료해야 {마감취소}가 {마감}으로 변경됨.
    • 학기말 추정 분할점수의 산출 및 {승인요청} 후 결재가 완료되면 문항정보표에서 {마감취소}하여 수정 가능함.
    • 지필평가 추정분할점수 확정 이후에도 문항정보표 수정이 가능하나, 학기말 추정분할점수까지 산출된 경우에는 학기말 추정분할점수 산출 취소 후 재산출해야 지필추정분할점수의 변경된 기준으로 처리됨.
