      01A
      학년초, 편제 등록 직후선택과목 2개 이상·교차이수 학교만3세대 이관 학교 확인 필요

      선택과목군 등록과 편성과목 지정

      동일 학년에 선택과목이 2개 이상이거나 학기별로 교차 이수하는 경우에만 해당한다. 동일한 학점의 과목에 대해서만 선택과목군으로 묶을 수 있다. 과목군을 먼저 만들고, 그 과목군에 실제 개설할 과목을 붙이는 두 단계를 한 번에 끝낸다.

      언제?
      학년초, 교육과정 편제를 등록한 뒤
      누가?
      교육과정 업무담당자
      어디서?
      [교육과정-편제및과목개설관리-편제및과목개설관리-선택과목군편성]
      무엇을
      어떻게?
      ‘학년도’, ‘학기’, ‘계열/학년/학과’ 확인 후 {조회} → {행추가} 후 ‘선택과목군 정보’에서 ‘과목군명’, ‘선택과목수’, ‘과목당학점’, ‘무학년제’ 여부를 입력하고 {저장} → 등록할 ‘선택과목군’을 선택하고 우측 하단의 ‘미편성 과목’에서 등록할 과목을 선택 후 {추가}하여 ‘편성과목’을 확인하고 {저장}
      왜?
      학생이 여러 과목 중 골라 듣는 구조를 편제에 그대로 담아, 뒤이은 과목개설과 수강생편성에서 학생별 선택 결과가 어긋나지 않게 하려고.

      실무 메모

      • 3세대 나이스의 편제표가 이관된 경우 ‘선택과목군’에 기존 선택과목군이 등록되어 있으나 ‘과목당 학점’이 ‘0’으로 설정되어 있으므로, ‘과목당 학점’을 입력하고 {저장} 후 편성과목을 등록해야 함.
      • [선택과목군 편성]은 동일 학년에 선택과목이 2개 이상이거나, 교차 이수할 경우 사용함. 예시로 2학년은 제2외국어를 일본어Ⅰ, 중국어Ⅰ 중에서 1과목 선택 이수, 1학년은 정보, 한문Ⅰ을 학기별로 교차 이수하는 경우다.
      • ‘선택과목수’는 개설된 여러 선택과목 중 학생이 실제 수강하는 과목의 개수로, 세계지리·정치와 법·생활과 윤리 중 두 과목 선택이면 선택과목수는 ‘2’로 입력하며, 이 경우 편제 및 시간배당표에 ‘택 2’로 표시됨.
      • [선택과목군편성]에서는 동일한 학점의 과목에 대해서만 선택과목군으로 묶을 수 있음. 3학점 A과목, 2학점 B과목, 1학점 C과목에서 A과목과 B･C과목을 선택과목군으로 묶을 수 없음.

      이동수업이 있는 경우

      • 동일 학급 내 학생별로 선택과목이 달라 교실 이동수업을 하는 경우 [선택과목군편성]을 완료 후 [교육과정-편제및과목개설관리-편제및과목개설관리-과목개설]에서 {과목개설}로 해당 강의실을 연결하고, [교육과정-편제및과목개설관리-편제및과목개설관리-수강생편성]의 {성적수강생편성} 탭에서 수강학생을 편성함.

      02A
      신학년도 편성 전특별실 사용 학교는 필수

      강의실 정보 등록·수정

      신학년도에 편성할 강의실 정보를 등록하거나 기존에 등록된 강의실 정보를 수정하는 업무다. 반(학급) 강의실은 반을 등록하면 자동으로 생성되므로, 음악실·과학실 같은 특별실을 쓰는 학교가 손댈 일이 많다. ‘사용여부’가 ‘미사용’으로 지정된 강의실은 사용할 수 없다.

      언제?
      학년초, 신학년도 반정보를 등록한 뒤
      누가?
      교육과정 업무담당자
      어디서?
      [교육과정-편제및과목개설관리-편제및과목개설관리-강의실관리]
      무엇을
      어떻게?
      ‘학년도’ 확인 후 ‘학년’을 선택하고 {조회} → {행추가}하여 ‘강의실정보내역’에서 ‘학년도’, ‘주야과정구분’ 확인 후 ‘강의실명’, ‘사용여부’, ‘정렬순서’, ‘정원’, ‘비고’를 입력 또는 선택하고 {저장}
      왜?
      과목개설 때 교사와 함께 붙일 수업 장소를 미리 확보해, 이동수업과 시간표 작성에서 장소가 겹치거나 비는 일을 막으려고.

      실무 메모

      • [학교정보-학교정보-기준/반정보관리]에서 반을 등록하면 해당 반 강의실이 자동으로 생성됨.
      • 강의실 현황은 ‘학년’ 단위로 조회할 수 있음. 이때 반(학급)은 해당 학년의 반만 조회되고, [강의실관리]에서 등록한 특별실(예: 음악실, 과학실 등)은 학년과 상관없이 모든 강의실이 조회됨.
      • ‘강의실 정보내역’의 ‘강의실코드’는 자동으로 생성되어 수정할 수 없으며, ‘사용여부’가 ‘미사용’으로 지정된 강의실은 사용할 수 없음.

      03B
      학기초, 편제 등록 후수강생편성 선행

      일반과목 과목개설(과목·교사·강의실 연결)

      모든 학교가 매 학기초에 하는 기본 업무입니다. 교육과정 편제가 등록된 뒤에 편제상의 과목을 실제 교과담당교사와 강의실에 연결합니다. 이후 수강생 편성 등의 업무가 수행되지 않은 경우에만 개설된 과목을 삭제할 수 있습니다.

      언제?
      학년초·학기초, 교육과정 편제 등록이 끝난 뒤
      누가?
      교육과정 업무담당자
      어디서?
      [교육과정-편제및과목개설관리-편제및과목개설관리-과목개설]
      무엇을
      어떻게?
      ‘학년도’, ‘학기’ 확인 후 ‘계열/학년/학과’를 선택하고 {조회}함 → {과목개설}을 클릭하면 나타나는 ‘과목개설’ 창에서 ‘편제명･과목(학점)’, ‘교사명’, ‘강의실’을 각각 선택한 후 {추가}하여 아래의 ‘과목정보’, ‘교사정보’, ‘강의실 정보’로 이동시킨 후 {저장}하고 목록에서 확인함.
      왜?
      학생 성적과 출결이 붙을 자리를 만들기 위해 과목·교사·강의실을 하나로 묶어 두려고 합니다.

      실무 메모

      • 이후 수강생 편성 등의 업무가 수행되지 않은 경우 개설된 과목을 선택하여 {삭제} 가능하며, 교사명을 클릭하면 나타나는 ‘담당교사 변경’ 창에서 해당 교과목의 교과담당교사를 변경할 수 있음.
      • ‘시간표’에서 과목별로 {조회} 시 개설된 교과의 전체시간표 등록 현황을 조회할 수 있음.
      • {엑셀내려받기}로 개설된 교과의 ‘개설과목명(학점)’, ‘계열/학년/학과’, ‘강의실’, ‘교사명’ 자료를 엑셀･한셀･CSV 파일로 내려받을 수 있음.
      • {자료권한재등록}은 인사발령, 사용자 삭제, 교무자료권한승인관리에서 삭제된 교과담당교사의 권한이 조회되며, {자료권한재등록}으로 교과담당교사 권한을 부여할 수 있음.
      • 개설된 교과목에 교과담당교사와 강의실이 편성되면 [성적-지필/수행선행작업-OMR용코드관리]의 {과목코드관리} 탭에서 과목코드를 부여할 수 있음.

      04B
      학기초, 담임편성 후담임편성된 학급 한정

      창의적 체험활동 학급담임교사 일괄등록

      학급담임교사가 창의적 체험활동을 담당하는 경우에 씁니다. 담임편성이 되어 있는 학급에 대해 자율･자치활동, 동아리활동, 진로활동을 한 번에 등록합니다. 비담임교사에게 자율활동･진로활동 등의 창의적 체험활동 영역을 먼저 등록한 경우는 일괄등록이 불가합니다.

      언제?
      학년초·학기초, 담임편성이 끝난 뒤
      누가?
      교육과정 업무담당자
      어디서?
      [교육과정-편제및과목개설관리-편제및과목개설관리-과목개설]
      무엇을
      어떻게?
      ‘학년도’, ‘학기’ 확인 후 ‘계열/학년/학과’를 선택하고 {조회}함 → {담임일괄등록}하여 ‘담임 일괄등록’ 창에서 학급담임교사가 담당하는 창의적 체험활동(자율･자치활동, 동아리활동, 진로활동)을 선택하고 {저장} 후 {닫기}함.
      왜?
      학급마다 담임을 한 건씩 붙이는 반복을 없애고, 담임이 곧바로 창의적 체험활동 누가기록을 쓸 수 있게 하려고 합니다.

      실무 메모

      • {담임일괄등록}하면 담임편성이 되어있는 학급에 대해서 학급담임교사에게 배정할 과목(2015 개정 교육과정을 적용받는 2026학년도 3학년의 경우 자율활동, 동아리활동, 봉사활동, 진로활동)을 일괄 등록할 수 있음.
      • 비담임교사에게 자율활동･진로활동 등의 창의적 체험활동 영역을 먼저 등록한 경우는 일괄등록 불가.

      누가기록 작성 메뉴

      • 자율 활동 담당교사 누가기록 작성 메뉴 [학생생활-창의적체험활동-자율･자치활동(자율활동)누가기록].
      • 진로활동 담당교사 누가기록 작성 메뉴 [학생생활-창의적체험활동-진로활동누가기록].

      06B
      수강생 편성 전잘못 개설한 경우

      개설과목 삭제

      과목을 잘못 개설했거나 개설이 필요 없어진 경우에만 씁니다. 개설 목록에서 해당 과목을 골라 지웁니다. 이후 수강생 편성 등의 업무가 수행되지 않은 경우에만 삭제가 가능합니다.

      언제?
      학기초, 해당 과목에 수강생 편성 등의 후속 업무가 수행되기 전
      누가?
      교육과정 업무담당자
      어디서?
      [교육과정-편제및과목개설관리-편제및과목개설관리-과목개설]
      무엇을
      어떻게?
      ‘학년도’, ‘학기’, ‘계열/학년/학과’ 선택 후 {조회}함 → 삭제할 개설과목을 선택한 후 {삭제}함.
      왜?
      운영하지 않는 과목이 남아 수강생 편성과 시간표, 성적처리에 끼어드는 것을 막으려고 합니다.

      실무 메모

      • 이후 수강생 편성 등의 업무가 수행되지 않은 경우 개설된 과목을 선택하여 {삭제} 가능함.
      • 개설과목을 다시 만들 때는 {과목개설}에서 ‘편제명･과목(학점)’, ‘교사명’, ‘강의실’을 다시 연결해야 함.

      07C
