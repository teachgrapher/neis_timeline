    07D
    교육과정 편성 시점자격기반 능력단위 운영 학교

    자격기반 능력단위 자격종목 등록과 학기별 단위수 입력

    자격기반으로 능력단위를 편성해 운영하는 학교에서 가장 먼저 하는 업무입니다. 입학학년도와 기준학년을 기준으로 자격종목을 먼저 올려 두어야 이후의 편성 능력단위 확인과 수강학생 편성이 이어집니다. 수강학생 편성이 안 되는 경우에는 전문교과Ⅱ 과목의 자격기반 능력단위 등록 뒤 과목개설 및 수강생편성까지 되어 있어야 진행됩니다.

    언제?
    연중, 교육과정 편성에 맞추어 자격종목을 확정한 뒤
    누가?
    자격증 관리 담당교사
    어디서?
    [학생생활-자격증및NCS이수상황-자격기반능력단위편성관리]
    무엇을
    어떻게?
    [학생생활-자격증및NCS이수상황-자격기반능력단위편성관리]에서 '입학학년도', '기준학년' 확인하고 {조회} → {자격종목등록} → '자격기반 능력단위 등록' 창에서 {자격종목추가} → '자격종목찾기' 창에서 '자격명'을 입력하여 {조회} → 자격종목을 클릭하여 {선택} → '자격기반 능력단위 등록' 창에서 학기별 단위수 입력하여 {저장}.
    왜?
    학생이 목표로 하는 자격을 기준으로 능력단위를 학기별로 배분해, 취득 목표에 맞는 이수 경로를 학교 교육과정에 붙여 두려고.

    실무 메모

    • 자격기반 능력단위 편성 관리에서 수강학생 편성이 안되는 경우는 [교육과정-편제및과목개설관리-편제및과목개설관리]에서 {편제및시간배당관리} → 전문교과Ⅱ 과목의 자격기반 능력단위 등록한 뒤 과목개설 및 수강생편성을 하여야 진행이 됨.

    08D
    자격종목 등록 직후자격기반 능력단위 운영 학교

    자격기반 능력단위 편성 조회와 능력단위 추가

    자격종목을 등록한 학교에서 그 자격종목에 어떤 능력단위가 묶여 있는지 확인하는 업무입니다. {편성된능력단위} 탭에서 편성 내용을 확인하고, 빠진 능력단위는 '능력단위추가'로 직접 넣을 수 있습니다. 수강학생 편성 전에 편성 목록이 맞는지 먼저 봐야 합니다.

    언제?
    연중, 자격종목 등록과 학기별 단위수 입력을 마친 뒤
    누가?
    자격증 관리 담당교사
    어디서?
    [학생생활-자격증및NCS이수상황-자격기반능력단위편성관리]
    무엇을
    어떻게?
    [학생생활-자격증및NCS이수상황-자격기반능력단위편성관리]에서 '입학학년도', '기준학년' 확인하고 {조회} → {자격종목명}을 선택 → {편성된능력단위} 탭에서 편성된 능력단위를 확인함.
    왜?
    자격 취득에 필요한 능력단위가 빠짐없이 편성되어 있는지 미리 짚어, 학생이 이수하고도 자격 요건을 못 채우는 일을 막으려고.

    실무 메모

    • '능력단위추가'를 클릭한 후 '능력단위 과목 추가' 창에서 '검색방법선택', '대분류', '세분류'를 선택하여 추가할 수 있음.

    09D
    편성 능력단위 확인 후자격기반 능력단위 운영 학교

    자격기반 능력단위 수강학생 편성

    등록한 자격종목에 실제로 어떤 학생이 붙는지 확정하는 업무입니다. 수강학생 가져오기가 되지 않으면 전문교과Ⅱ 과목의 자격기반 능력단위 등록과 과목개설·수강생편성이 먼저 되어 있는지 확인해야 합니다.

    언제?
    연중, 자격종목 등록과 편성된 능력단위 확인을 마친 뒤
    누가?
    자격증 관리 담당교사
    어디서?
    [학생생활-자격증및NCS이수상황-자격기반능력단위편성관리]
    무엇을
    어떻게?
    [학생생활-자격증및NCS이수상황-자격기반능력단위편성관리]에서 '입학학년도', '기준학년' 확인하고 {조회} → '자격종목명' 클릭 → {수강학생 편성} 탭에서 {수강학생 가져오기} → {확인} → {저장}.
    왜?
    자격기반으로 편성한 능력단위를 실제 수강 학생과 연결해, 학생별 이수 현황과 필수 이수시간이 제대로 집계되게 하려고.

    실무 메모

    • 자격기반 능력단위 편성 관리에서 수강학생 편성이 안되는 경우는 [교육과정-편제및과목개설관리-편제및과목개설관리]에서 {편제및시간배당관리} → 전문교과Ⅱ 과목의 자격기반 능력단위 등록한 뒤 과목개설 및 수강생편성을 하여야 진행이 됨.

    수시 확인자격기반 능력단위 운영 학교

    무엇을

    • 자격기반 능력단위 편성 관리에서 수강학생 편성이 안되는 경우는 [교육과정-편제및과목개설관리-편제및과목개설관리]에서 {편제및시간배당관리} → 전문교과Ⅱ 과목의 자격기반 능력단위 등록한 뒤 과목개설 및 수강생편성을 하여야 진행이 됨.

    06C
    학기 중 수시 확인

    학생별 이수예정 능력단위 및 필수 이수시간조회

    NCS 능력단위를 편성한 학교의 담임이 학생별로 이수해야 할 능력단위와 이수시간을 확인하는 업무이다. '학년도', '학기', '계열/학년/학과', '반'을 확인한 뒤 학생을 클릭해야 이수시간이 보인다. 입력이 아니라 확인 전용 화면이다.

    언제?
    연중, 능력단위 편성과 수강생 편성이 끝난 뒤
    누가?
    학급담임교사
    어디서?
    [학급담임-학생생활-자격증및NCS이수상황-학생별이수능력단위및필수이수시간조회]
    무엇을
    어떻게?
    '학년도', '학기', '계열/학년/학과', '반' 확인하고 {조회} → 학생을 클릭하여 이수시간을 확인함.

    학생이 필수 이수시간을 못 채운 상태로 학기가 끝나는 일을 미리 막으려고.

    04C
    위탁기관 이수 결과 수신 직후위탁학생 한정

    위탁학생 능력단위 추가 입력

    위탁기관에서 위탁학생의 실무과목 없이 능력단위 이수 결과만을 보내온 경우에만 입력 가능하며, 본교 학생은 할 수 없음. 위탁기관이 보내온 능력단위별 이수 결과를 담임이 학생 자료에 직접 얹는 업무이다. 실무과목이 함께 있는 경우에는 이 화면으로 추가하지 않는다.

    언제?
    연중, 위탁기관에서 능력단위 이수 결과를 보내온 뒤
    누가?
    학급담임교사
    어디서?
    [학급담임-학생생활-자격증및NCS이수상황-국가직무능력표준이수상황관리]
    무엇을
    어떻게?
    '학년도', '계열/학년/학과', '반' 확인하고 {조회} → 학생 클릭 후 {능력단위추가} → '능력단위 과목 변경' 창에서 검색 조건 확인 및 선택하고 능력단위코드 클릭 후 {선택} → '이수시간', '원점수', '성취도'를 입력 및 선택하여 {저장}함.
    왜?
    위탁기관에서 이수한 능력단위 결과가 학교 자료에서 빠지지 않도록 학생 이수 이력에 남기려고.

    실무 메모

    • 위탁기관에서 위탁학생의 실무과목 없이 능력단위 이수 결과만을 보내온 경우에 입력 가능하며, 본교 학생은 할 수 없음.
    • 능력단위의 이수시간, 원점수, 성취도를 입력함. 단 실무과목은 공란으로 입력이 되지 않음.

    05C
    입력 후 수시 확인

    국가직무능력표준 이수상황 조회와 삭제·이수시간재계산

    NCS 능력단위를 이수하는 학생이 있는 학교에서 입력 결과를 확인하고 잘못된 항목을 정리하는 업무이다. 일출결마감 이후 시간표가 변경되거나 일출결마감을 취소한 경우에는 계산내역이 반영되지 않으므로 {이수시간재계산}을 다시 수행함. 조회 화면이지만 삭제와 재계산까지 여기서 함께 처리한다.

    언제?
    연중, 능력단위 이수상황 입력이나 일출결마감이 끝난 뒤
    누가?
    학급담임교사
    어디서?
    [학급담임-학생생활-자격증및NCS이수상황-국가직무능력표준이수상황조회]
    무엇을
    어떻게?
    '학년도', '계열/학년/학과', '반' 확인하고 {조회} → 학생 클릭 후 '국가직무능력표준 이수상황'을 확인함.
    왜?
    기업과 학교에서 실제로 이수한 능력단위와 시간이 학생 기록과 어긋나지 않게 맞추려고.

    능력단위코드 입력과 정리

    • 가장 최신 버전의 '능력단위코드'를 선택하여 입력하고, '능력단위명'이 존재하지 않는 경우에는 가장 유사한 '능력단위명(능력단위코드)'을 선택하여 우선 입력한 후 [학적-위탁․현장실습학생관리-위탁․현장실습학생관리-자료관리]의 '세부능력및특기사항'에서 '유사교과명 : 실제 이수 교과명, 실제 능력단위코드' 등을 입력함.
    • 삭제할 능력단위를 선택한 후 {삭제} 가능함.
    • 현장실습생으로 등록한 학생의 능력단위 이수시간은 일출결마감에 따라 능력단위의 시간표와 해당 교시의 출결 정보에 따라 이수 시간이 자동 계산되나 일출결마감 이후 시간표가 변경되거나 일출결마감을 취소한 경우에는 계산내역이 반영되지 않으므로 {이수시간재계산}을 다시 수행함.

    학생 선택 능력단위와 성취도 표기

    • [교육과정-편제및과목개설관리-편제및시간배당관리]에서 교육과정 편성 시 '*학생 선택' 능력단위로 수강 편성된 학생(도제학교 참여 학생 포함)은 [학생생활-자격증및NCS이수상황-국가직무능력표준이수시간관리]에서 {학생선택추가}를 이용하여 '능력단위명', '이수시간', '원점수', '성취도'를 학생이 기업에서 실제 이수한 능력단위로 추가 등록함.
    • 현장실습으로 인해 인정점으로 부여된 능력단위의 성취도는 'P'로 입력하고, 정규교육과정 이외의 교육활동으로 이수한 능력단위와 학적 변동(전출･자퇴･퇴학･전입학 등)으로 성취도 산출이 불가한 능력단위의 경우 성취도는 '･'로 입력함.

    01A
    자격증 등록 전 사전준비자격증 관리 담당교사 전용

    자격증코드 등록과 발급기관 선택

    자격증 등록 화면에서 쓸 자격증명을 미리 코드로 올려두는 업무이다. 담임교사가 학생 자격증을 입력하다가 자격증명이 목록에 없으면 자격증 관리 담당자에게 '자격증 코드 등록'을 요청하게 되므로, 요청이 들어올 때마다 이 화면에서 처리한다.

    언제?
    연중, 담임교사의 자격증 등록보다 앞선 시점 또는 코드 등록 요청을 받은 때.
    누가?
    자격증 관리 담당교사
    어디서?
    [학생생활-자격증및NCS이수상황-자격증코드관리]
    무엇을
    어떻게?
    {등록}하여 '자격증찾기' 창에서 자격증명 입력 후 {조회}함 → 자격증을 선택하고 {등록} 후 {닫기}하여 '발급기관 선택'을 선택하고 {저장}함.
    왜?
    학생마다 제각각 적히는 자격증명을 학교가 관리하는 하나의 코드로 통일해, 담임이 자격증을 등록할 때 골라 쓰기만 하면 되도록 해두려고.

    실무 메모

    • 자격증 등록 중 자격증명이 없는 경우 자격증 관리 담당자에게 '자격증 코드 등록'을 요청함.
    • '발급기관 선택'은 자격증 선택 후 {닫기}한 다음 지정하고 {저장}해야 마무리됨.

    02B
    자격증 취득 직후학생 한 명씩 입력

    자격증 개인별 등록

    학생이 자격증을 취득했을 때 학급담임교사가 학생 한 명씩 자격증 내역을 입력하는 업무입니다. 등록하려는 자격증명이 목록에 없으면 먼저 자격증 관리 담당자에게 '자격증 코드 등록'을 요청해야 합니다. 취득 인원이 적거나 학생마다 자격증 종류가 다를 때 쓰는 경로입니다.

    언제?
    연중, 학생이 자격증을 취득한 뒤 자격증코드가 등록되어 있는 시점.
    누가?
    학급담임교사
    어디서?
    [학생생활-자격증및NCS이수상황-자격증등록]
    무엇을
    어떻게?
    [학생생활-자격증및NCS이수상황-자격증등록]의 {개인} 탭에서 '학년도', '학년', '반' 확인하고 {조회}하여 해당 학생을 클릭함 → {행추가}하여 자격증의 '명칭 또는 종류', '번호 또는 내용', '취득연월일', '발급기관'을 입력 및 선택 후 {저장}함.
    왜?
    학생이 실제로 취득한 자격증을 학교생활기록부에 정확한 번호와 취득일로 남겨 진학·취업 자료로 쓰이게 하려고.

    자격증 입력 방법

    • {과정평가형･일학습병행자격종목조회}, {민간자격증현황}, {자격종목조회}은 각 해당 사이트로 연결됨.
    • 자격증 번호 입력시 '제', '호'는 입력하지 않고 번호 사이의 하이픈(-)은 입력함. 번호 입력 시 숫자와 영문을 구분하여 정확하게 입력함.
    • 자격증의 '취득연월일'은 자격증 합격일(등록일)을 기준으로 입력함.
    • 자격증 발급기관에는 기관장이 아닌 기관명을 입력함. (예시) 한국산업인력공단, 대한상공회의소, 한국생산성본부

    정정과 증빙 처리

    • 이전 학년도에 등록된 자격증 번호 등의 정정이 필요한 경우 학교생활기록부 정정대장을 통해 정정함.
    • 재학 중에 취득한 자격증의 경우 전년도의 경우라도 정정 없이 추가 입력함.
    • 자격증 등록 중 자격증명이 없는 경우 자격증 관리 담당자에게 '자격증 코드 등록'을 요청함.
    • 자격증 증빙자료 자격증 사본이나 자격증 취득확인서를 별도로 보관함.
