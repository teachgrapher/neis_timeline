      01A
      학기초전년도와 동일한 부서가 있을 때

      전년도 부서·반 복사로 동아리활동 부서 만들기

      전년도와 동일한 동아리활동부서를 그대로 운영하는 경우에만 쓰는 방법이다. 전년도와 동일한 동아리활동부서가 있어야 일괄복사 목록에 나타난다. 새로 만들 부서는 이 카드가 아니라 신규 등록 업무로 처리한다.

      언제?
      학기초, 편제및시간배당관리에서 동아리활동 시수 등록과 전체시간표 등록이 끝난 뒤
      누가?
      동아리 업무담당교사
      어디서?
      [학생생활-창의적체험활동-동아리활동관리-부서만들기]
      무엇을
      어떻게?
      [학생생활-창의적체험활동-동아리활동관리-부서만들기]에서 '학년도' 확인 후 {조회} → {전년도부서･반복사} → '동아리활동부서 일괄복사' 창에서 전년도와 동일한 동아리활동부서를 선택 → {일괄복사} 함.
      왜?
      해마다 같은 동아리를 다시 손으로 만들지 않고 전년도 부서 구성을 그대로 이어받아 학생 배정을 바로 시작하려고.

      실무 메모

      • '동아리활동부서명' 등록 시 부서명의 공백은 허용하지 않음.
      • '부서반 명'은 동일한 이름의 동아리활동 부서가 여러 개 개설된 경우 구분하기 위한 반명으로, 개설되는 동아리가 1개 반이면 '반없음'으로 등록함(기본 설정값임).
      • [학생생활-창의적체험활동-동아리활동부서만들기]에서 등록된 부서를 삭제하기 위해서는 부서별 누가기록 및 배정학생을 먼저 삭제하여야 함.

      타임라인으로 돌아가기

      02A
      학기초단일 동아리로 구성하는 경우

      신규 동아리활동 부서 등록 (분반하지 않고 단일 동아리로 구성하는 경우)

      한 부서를 분반 없이 하나로 운영하는 경우에 쓴다. '부서반 명'은 개설되는 동아리가 1개 반이면 '반없음'으로 등록한다. 같은 부서명을 여러 반으로 나눠 운영할 계획이면 분반 동아리 등록 업무로 간다.

      언제?
      학기초, 편제및시간배당관리에서 동아리활동 시수 등록과 전체시간표 등록이 끝난 뒤
      누가?
      동아리 업무담당교사
      어디서?
      [학생생활-창의적체험활동-동아리활동관리-부서만들기]
      무엇을
      어떻게?
      [학생생활-창의적체험활동-동아리활동관리-부서만들기]에서 '학년도' 확인 후 {조회}하여 {행추가} → '동아리활동 부서반 등록/수정/삭제'에서 '동아리활동부서명'을 입력하고 '동아리부서구분'을 선택하고 {담당교사추가} → '교사검색' 창에서 교사명 입력하고 {조회}하여 교사명을 더블클릭하고 {확인} 후 {저장}하여 {확인} 함.
      왜?
      학생이 가입할 동아리 그릇과 기록을 책임질 교사를 먼저 확정해 두려고.

      실무 메모

      • '동아리활동부서명' 등록 시 부서명의 공백은 허용하지 않음.
      • [학생생활-창의적체험활동-동아리활동부서만들기]의 '동아리활동 부서반 수정/삭제'에서 설정한 '동아리부서구분'에 따라 학교생활기록부에 동아리활동 유형(예: 동아리활동, 자율동아리)이 자동 입력되며, 선택 유형에 따라 누가기록과 이수시간 계산 여부가 결정됨.
      • 동아리담당교사가 2인 이상일 때에는 {담당교사추가}에서 추가로 등록할 수 있음.

      수정·삭제 제약

      • 동아리담당교사를 잘못 등록한 경우에는 {담당교사삭제} 후, 다시 {담당교사추가}하여 새로운 동아리담당교사를 등록하고 {저장} 함.
      • 학교생활기록부 자료(이수시간, 특기사항)가 존재하는 부서는 '동아리활동부서명', '동아리부서구분'을 수정 또는 삭제할 수 없음.
      • 동아리활동 누가기록이 존재하는 부서는 '동아리부서구분'을 수정 또는 삭제할 수 없으나 '동아리활동부서명'은 수정할 수 있음.
      • 동아리활동에 이미 학생이 배정된 경우에도 특기사항 입력 전에는 '동아리활동부서명', '담당교사'의 수정이 가능함(배정된 학생의 특기사항이 있는 경우 특기사항을 삭제하고, 배정된 학생을 취소한 후 동아리활동부서 삭제가 가능함).

      03A
      학기초분반 동아리로 구성하는 경우

      신규 동아리활동 부서 등록 (분반 동아리로 구성하는 경우)

      '동아리활동부서명'을 동일하게 하고 '부서반 명'을 구분하여 구성하는 경우에 활용한다. 2025학년도 1학년과 2･3학년을 함께 구성하는 경우에도 활용 가능하며, '동아리활동부서명'이 같고 '부서반 명'이 다른 동아리를 동일한 교사가 담당할 수 있다. 단일 동아리 등록과 달리 '부서반 명' 선택 단계가 하나 더 있다.

      언제?
      학기초, 편제및시간배당관리에서 동아리활동 시수 등록과 전체시간표 등록이 끝난 뒤
      누가?
      동아리 업무담당교사
      어디서?
      [학생생활-창의적체험활동-동아리활동관리-부서만들기]
      무엇을
      어떻게?
      [학생생활-창의적체험활동-동아리활동관리-부서만들기]에서 '학년도' 확인 후 {조회}하여 {행추가} → '동아리활동 부서반 등록/수정/삭제'에서 '동아리활동부서명'을 입력하고 '동아리부서구분'을 선택 후 '부서반 명'을 선택 → {담당교사추가}하여 '교사검색' 창에서 교사명 입력하고 {조회}하여 교사명을 더블클릭하고 {확인} 후 {저장}하여 {확인} 함.
      왜?
      같은 이름의 동아리를 여러 반으로 나눠 운영할 때 반마다 이수시간이 따로 계산되도록 부서를 갈라 두려고.

      실무 메모

      • '부서반 명'은 동일한 이름의 동아리활동 부서가 여러 개 개설된 경우 구분하기 위한 반명으로, 개설되는 동아리가 1개 반이면 '반없음'으로 등록함(기본 설정값임).
      • '동아리활동부서명' 등록 시 부서명의 공백은 허용하지 않음.
      • 지정한 '부서반(1반,2반)'은 학교생활기록부에 기록되지 않음.
      • 이수시간기준등록은 학년별로 구분되므로 학급별로 동아리활동 운영시간이 다른 경우 이수시간을 수기로 입력하거나 동아리부서를 세부적으로 만들어서 운영하여야 함(1･2반은 5교시에 3･4반은 6교시에 하는 경우 1･2반 동아리와 3･4반 동아리를 따로 만들어 운영하면 이수시간이 다르게 계산되도록 할 수 있음).

      04A
      학기초, 부서 등록 후담당교사가 2인 이상인 경우

      개설된 부서에 동아리 담당교사 추가

      이미 만들어진 동아리부서에 담당교사를 더 붙이거나 바꿀 때 쓴다. 동아리담당교사가 2인 이상일 때에는 {담당교사추가}에서 추가로 등록할 수 있다. 담당교사를 잘못 등록했을 때의 수정도 이 화면에서 처리한다.

      언제?
      학기초, 동아리활동 부서를 등록한 뒤
      누가?
      동아리 업무담당교사
      어디서?
      [학생생활-창의적체험활동-동아리활동관리-부서만들기]
      무엇을
      어떻게?
      [학생생활-창의적체험활동-동아리활동관리-부서만들기]에서 '학년도' 확인 후 {조회}하여 담당교사를 추가할 동아리부서를 클릭 → {담당교사추가} 후 '교사검색' 창에서 교사명을 입력하여 {조회}한 후 해당 교사를 더블클릭하여 반영하고 {저장} 후 {확인} 함.
      왜?
      출장이나 공동 지도로 담당이 여러 명인 부서에서도 누가기록과 출석 입력을 할 사람이 비지 않게 하려고.

      실무 메모

      • 동아리담당교사를 잘못 등록한 경우에는 {담당교사삭제} 후, 다시 {담당교사추가}하여 새로운 동아리담당교사를 등록하고 {저장} 함.
      • 동아리 부서 담임의 경우 현재 담임을 기준으로만 추가하여 수정을 하면 되며, 별도 이력으로 관리하지 않으므로 이전 담임은 추가로 등록하지 않아도 됨.
      • 동아리활동에 이미 학생이 배정된 경우에도 특기사항 입력 전에는 '동아리활동부서명', '담당교사'의 수정이 가능함.

      05A
      학기초, 부서와 담당교사 등록 후

      동아리담당교사 교무자료 권한승인 신청

      부서와 담당교사 등록을 마친 뒤 마지막으로 처리하는 절차다. 이 승인요청을 해야 동아리담당교사가 자기 부서의 출석관리와 누가기록 메뉴를 쓸 수 있다. 메뉴 위치가 창의적체험활동이 아니라 기본메뉴 쪽이라는 점에 주의한다.

      언제?
      학기초, 동아리활동 부서와 담당교사 등록을 마친 뒤
      누가?
      동아리 업무담당교사
      어디서?
      [기본메뉴 및 승인사항-기본메뉴-권한관리-교무자료권한승인관리]
      무엇을
      어떻게?
      [기본메뉴 및 승인사항-기본메뉴-권한관리-교무자료권한승인관리]에서 '교무년도', '승인상태', '담임편성' 선택 확인 후 {조회} → {동아리활동} 탭에서 상신할 동아리담당교사를 선택 후 {승인요청} 함.
      왜?
      동아리담당교사가 학기중에 출석과 누가기록을 직접 입력할 수 있도록 자료 접근 권한을 열어 주려고.

      실무 메모

      • 후행처리로 동아리담당교사가 [학생생활-창의적체험활동상황-동아리활동관리]에서 이수시간기준을 등록하고 {출석관리}, {누가기록}, {활동내역}, {학생부자료기록} 작업을 학기중에 수행함.
      • 동아리담당교사가 2인 이상인 부서는 상신 대상 교사를 모두 선택하여 {승인요청} 함.

      06B

      학생별 동아리활동 부서 배정

      학급담임교사가 자기 반 학생들의 동아리활동 기록 상태를 한 화면에서 점검하는 업무입니다. 입력 화면이 아니라 조회 화면이므로 동아리담당교사가 특기사항과 이수시간을 저장한 뒤에 확인해야 실제 기재 내용이 보입니다. {학생부자료} 탭과 {누가기록} 탭은 조건 선택만 다르고 절차가 같습니다.

      언제?
      학기말, 동아리담당교사가 학생부자료기록을 마친 뒤(누가기록은 학기중에도 수시로 확인)
      누가?
      학급담임교사
      어디서?
      [학급담임-학생생활-창의적체험활동-동아리활동반별조회] {학생부자료} 탭, {누가기록} 탭
      무엇을
      어떻게?
      {학생부자료} 탭에서 '학년도', '학년', '반' 확인 후 {조회} → {누가기록} 탭에서 '학년도', '학년', '반' 확인 후 '기간'을 선택하여 {조회} 함.
      왜?
      반 학생 중 이수시간이나 특기사항이 빠진 학생을 담임이 미리 찾아내 동아리담당교사에게 보완을 요청하려고.

      어떤 탭을 언제 여는가

      • {학생부자료} 탭 — 학기말에 학교생활기록부에 기재될 '동아리부서구분', '부서명', '이수시간', '특기사항'이 반 학생별로 채워졌는지 확인할 때 사용함. 조건은 '학년도', '학년', '반'만 필요함.
      • {누가기록} 탭 — 학기중 또는 학기말에 기간을 정해 학생별 활동 일자와 활동내용이 누락되지 않았는지 확인할 때 사용함. '기간'을 반드시 선택해야 조회됨.
      • [학생생활-창의적체험활동-동아리활동관리-동아리활동관리]의 {학생부자료기록}, {누가기록} 탭과 [학생생활-창의적체험활동-동아리활동반별조회]의 {학생부자료}, {누가기록} 탭은 각각 동일한 내용이 조회됨.
      • 동아리담당교사는 [학생생활-창의적체험활동-동아리활동부서반별이수시간조회]에서 이수시간을 동일하게 조회할 수 있음.

      16E
      학적변동 발생 시전입생·위탁학생 있는 학급만

      학적변동 학생 학생부자료·이수시간계산내역·누가기록 확인과 수정

      전입 등 학적변동이 발생한 학생이 학급에 있을 때만 하는 업무입니다. 학급담임교사가 전출교 누가기록과 학교생활기록부 자료(특기사항)를 확인하고 오류사항을 수정 또는 삭제합니다. 전입생이 전출교에서 가져온 자료는 수정할 수 있으나, 전입 전 전입교에서 실시한 동아리활동 내용은 비활성화되어 수정하거나 누가기록 할 수 없습니다.

      언제?
      학기말, 전입 등 학적변동 처리가 끝난 뒤
      누가?
      학급담임교사
      어디서?
      [학급담임-학생생활-창의적체험활동-동아리활동관리(담임용)]
      무엇을
      어떻게?
      ‘학년도’, ‘학년’, ‘반’ 확인 후 {조회} → 학적변동 학생을 클릭하여 {학생부자료} 탭에서 입력된 ‘동아리부서구분’, ‘부서명’, ‘이수시간’, ‘특기사항’, ‘글자수’를 확인 또는 수정 → 해당 학생을 클릭하여 {이수시간계산내역} 탭에서 ‘기준일자’를 선택하고 {조회} 하여 ‘전체시간표’와 부서별 ‘이수시간기준등록’ 내용을 확인 → 해당 학생을 클릭하여 {누가기록} 탭에서 ‘부서명’, ‘일자’, ‘학적변동사항(출결결시내역)’, ‘이수시간’, ‘활동내용’을 확인함.
      왜?
      전학 온 학생의 동아리활동 기록이 전출교와 본교에 걸쳐 끊기지 않도록 담임이 마지막으로 메워 학교생활기록부를 온전하게 남기려고.

      학생부자료 탭에서 알아둘 것

      • ‘동아리부서구분’에서 ‘동아리활동’, ‘자율동아리’를 선택할 수 있으며, 해당 학생의 ‘자율동아리’의 학교생활기록부 반영 내용이 있을 경우 ‘부서명’, ‘특기사항’, ‘글자수’를 확인할 수 있음.
      • 전입생의 전출교 자율동아리 특기사항 학교생활기록부 반영은 [학생생활-창의적체험활동-동아리활동관리(담임용)]의 {학생부자료} 탭에서 {추가} 하여 입력함. 본교에서 실시한 자율동아리 학교생활기록부 반영은 [학생생활-창의적체험활동-동아리활동부서별기록]에서만 선택 가능함.
      • 전입생의 동아리활동 이수시간은 전출교와 전입교에서의 이수시간이 합산되어 입력되며, 동아리활동 특기사항은 전출교와 전입교의 특기사항이 모두 입력됨.

      누락된 전출교 자료를 넣을 때

      • 이전학교 동아리활동 누가기록을 등록하려면 [학생생활-창의적체험활동-동아리활동기록(담임용)]에서 해당 전입생을 선택한 후 {누가기록} 탭에서 {추가} 하여 ‘부서명’, ‘일자’, ‘이수시간’, ‘활동내용’ 등을 직접 입력함.
      • 전입생의 전출교 부서명이 {학생부자료} 탭에서 조회되지 않으면 [학생생활-창의적체험활동-동아리활동기록(담임용)]의 {학생부자료} 탭에서 {추가} 하여 ‘부서명’, ‘동아리부서구분’, ‘이수시간’, ‘특기사항’ 등을 직접 입력하여 {저장} 함.
      • 전입생의 학교스포츠클럽에 관한 내용은 [학생생활-창의적체험활동-동아리활동관리(담임용)]의 {학교스포츠클럽자료입력}에서 ‘이수시간’과 ‘클럽명’을 직접 입력하여 {반영} 하면 됨.
      • 위탁교육기관의 1학기 동아리활동 이수시간과 특기사항에 2학기 자료를 추가해야 하는 경우, {학생부자료} 탭에서 등록된 1학기 자료를 {행삭제} 로 삭제한 후 [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-자료관리]의 ‘창의적체험활동’에서 기존에 입력한 1학기 동아리활동에 추가하여 2학기 이수시간과 특기사항을 기록함.

      위탁기관 자료 등록 후위탁학생이 있는 학급만

      위탁학생의 동아리활동 가져오기

      위탁학생이 배정된 학급에서만 하는 업무입니다. 위탁교육기관에서 실시한 동아리활동을 담임이 가져와 학생부자료에 반영합니다. 위탁학생의 동아리활동 등록은 [학적-위탁･현장실습학생관리-위탁학생창의적체험활동관리]-{창의적체험활동} 탭의 ‘동아리활동’ 항목에서 먼저 등록되어 있어야 합니다.

      언제?
      학기말, 위탁기관 자료가 창의적체험활동에 등록된 뒤
      누가?
      학급담임교사
      어디서?
      [학급담임-학생생활-창의적체험활동-동아리활동관리(담임용)]
      무엇을
      어떻게?
      ‘학년도’, ‘학년’, ‘반’ 확인 후 {조회} → 위탁 학생을 클릭하고 {학생부자료} 탭에서 {위탁가져오기} → ‘위탁 및 공동교육과정 학생자료 등록’ 창에서 반영할 동아리 내용을 선택( ) 후 {반영} 하여 {저장} 함.
      왜?
      학교 밖에서 이루어진 동아리활동도 본교 학생부에 빠짐없이 이어 붙여 위탁학생이 기록상 불이익을 받지 않게 하려고.

      위탁자료 등록 경로

      • 위탁학생의 동아리활동 등록은 [학적-위탁･현장실습학생관리-위탁학생창의적체험활동관리]-{창의적체험활동} 탭의 ‘동아리활동’ 항목에서 등록하며, 동아리부서가 여러 개인 경우 ‘동아리별특기사항등록’ 창에서 {추가} 하여 입력함.
      • 순회교육, 위탁교육기관, 병원학교･원격수업기관의 활동 내용이 있는 경우 해당 자료를 그대로 입력하되, 자료 입력 내용은 학교생활기록부 기재요령의 각종 유의사항을 준수하여 [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-자료관리]의 ‘창의적체험활동’을 선택( )하여 영역별로 입력하고 저장함.
      • 위탁교육기관에서 실시한 동아리활동의 누가기록은 입력하지 않으며, 동아리활동 부서명, 동아리활동 유형, 이수시간, 특기사항을 입력함.

      위탁학생이 본교 동아리에 참여하는 경우

      • 선행작업으로 동아리업무담당교사가 [학생생활-창의적체험활동-동아리활동관리-부서만들기]에서 위탁학생들을 배정할 동아리 활동부서와 담당교사를 등록한 후, 학급담임교사가 [학생생활-창의적체험활동-동아리활동관리-부서배정]에서 위탁학생들을 해당 부서에 배정 후 {저장} 함.
      • [교육과정-시간표관리-전체시간표관리]에 등록된 동아리활동에 해당되지 않으므로 누가기록 ‘일자’를 ‘일자추가(직접입력)’으로 선택하여 입력하고 ‘이수시간’과 ‘활동내용’을 입력 후 {저장} 함.

      무엇을
      어떻게?
      ‘학년도’, ‘학년’, ‘반’ 확인 후 {조회} → 해당 학생들을 선택( )하고 {학생부자료} 탭에서 {스포츠클럽정보가져오기} → ‘스포츠클럽정보가져오기’ 창에서 {가져오기} 하여 {확인} 후 {확인} 함.
