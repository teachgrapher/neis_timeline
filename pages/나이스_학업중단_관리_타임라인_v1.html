    04C
    학적 처리 전특수교육대상학생 한정

    개별화교육 대상자 등록

    특수교육대상학생이 있는 학교에서만 하는 업무이다. 고등학교 특수교육대상학생은 의무교육 대상자의 학적처리에 준하여 처리하므로, 특수교육대상학생의 학적 변동 시 먼저 개별화교육대상자로 등록하고 학적을 처리한다.

    언제?

    무엇을
    어떻게?
    [개별화교육계획-인적사항관리-인적사항관리-개별화교육대상자관리]에서 '학년도', '학년', '반' 확인 후 {조회} → {등록}을 클릭하면 나타나는 '개별화교육대상자등록' 창에서 '학년도', '계열/학년/학과', '반' 확인 후 '성명'을 입력하고 {조회} → 해당 학생을 선택하고 {저장}함.
    왜?
    특수교육대상학생에게 의무교육에 준하는 학적 용어를 쓸 수 있게 만들어, 뒤이은 학적 처리가 장기결석에 따른 정원 외 학적관리·유예·면제로 잡히게 하려고.

    실무 메모

    • 고등학교 특수교육대상학생은 의무교육 대상자의 학적처리에 준하여 처리함.
    • 특수교육대상학생의 학적 변동 시 먼저 개별화교육대상자로 등록하고 학적을 처리하되, 의무교육 학적 용어를 사용함(장기결석에 따른 정원 외 학적관리, 유예, 면제 등).
    • 의무교육에 준하는 학적 용어를 사용하려면 [개별화교육계획-인적사항관리-인적사항관리-개별화교육대상자관리]에서 개별화교육 대상자로 등록하고, 이후 [학적-학업중단관리-휴학/자퇴/퇴학/제적관리]에서 학적 처리를 순으로 진행함.

    05C
    개별화교육 대상자 등록 후특수교육대상학생 한정

    장기결석에 따른 정원 외 학적관리

    장기결석 중인 특수교육대상학생이 있는 경우에만 하는 업무이다. 개별화교육 대상자로 등록을 마친 뒤 같은 휴학/자퇴/퇴학/제적관리 화면에서 의무교육 학적 용어로 학적을 처리한다. '변동사유'를 선택하면 '비고'가 자동 반영된다.

    언제?
    학년초, 학기중. 개별화교육 대상자 등록을 마친 뒤
    누가?
    학적 업무담당자
    어디서?
    [학적-학업중단관리-휴학/자퇴/퇴학/제적관리]
    무엇을
    어떻게?
    [학적-학업중단관리-휴학/자퇴/퇴학/제적관리]에서 '학년도' 확인 후 '기간' 설정 및 '미반영된자료'를 선택하고 {조회} → {추가} 후 '휴학/자퇴/퇴학/제적생 상세조회'에서 {학생찾기}로 해당 특수교육대상학생을 조회하고 '변동일자', '변동구분' 선택 후 '학년', '반', '번호' 확인 및 '변동사유'를 선택('비고' 자동 반영)하고 '학적특기사항' 입력 후 {저장}함.
    왜?
    장기결석한 특수교육대상학생을 의무교육 대상자에 준하는 학적으로 남겨, 재학 정원과 출결·수업일수가 실제 학적 상태와 어긋나지 않게 하려고.

    실무 메모 — 생성과 반영

    • [학적-학업중단관리-휴학/자퇴/퇴학/제적관리]에서 자퇴 등의 학적변동일자 기준으로 {학교생활기록부생성}하면 학교생활기록부 인적･학적사항의 '학적사항'에 '(2025년 ○○월 ○○일 □□고등학교 자퇴)'로 표기되며, 출결상황의 출결자료도 학적변동일자 기준으로 반영됨(학적변동일자까지 수업일수에 포함됨).
    • 휴학생･퇴학생･제적생 처리도 같은 방법으로 처리하되, '변동구분'을 '휴학', '퇴학', '제적'으로 선택함.

    실무 메모 — 출력

    • 학적변동자(자퇴･퇴학 등)의 학교생활기록부 출력은 [학생부-학교생활기록부-학교생활기록부-학생부조회및출력]에서 '재학아닌학생'을 선택하고 '성명'을 입력 후 {조회}하여 출력할 수 있음.

    학업중단자 확정 직후휴학·자퇴·퇴학·제적 공통

    02B
    변동내용 저장 직후

    항목별 내용 확인과 학교생활기록부생성

    학업중단자의 변동일자와 변동구분을 저장한 뒤에 하는 일입니다. 목록에서 해당 학생을 다시 열어 우측 항목별 내용을 하나씩 확인해야 하며, 학적변동일자 기준으로 학교생활기록부가 생성되므로 변동일자가 맞는지 먼저 확인합니다.

    언제?
    학년초, 학기중. 학업중단자의 '변동일자', '변동구분', '변동사유' 등을 저장한 뒤
    누가?
    학적 업무담당자
    어디서?
    [학적-학업중단관리-휴학/자퇴/퇴학/제적관리]
    무엇을

    언제?

    왜?
    학교장의 결재를 거친 사실만 학적으로 확정해 학업중단 처리의 근거를 남기기 위해서입니다.

    자퇴·퇴학 등으로 학적반영이 끝나 재학생 명부에서 빠진 학생은 일반 학생부 조회 화면의 재학생 목록에서 검색되지 않습니다. 학업중단 학생의 학교생활기록부를 확인하거나 출력해야 할 때 쓰는 업무입니다.

    언제?
    학년초, 학기중. 학적변동자의 {학교생활기록부생성}과 {학적반영}이 끝난 뒤.

    무엇을

    왜?
    학교를 떠난 학생의 학적·출결이 변동일자 기준으로 제대로 기록되었는지 확인하고, 상급학교 진학이나 증명 요청에 쓸 기록을 내주려고.
