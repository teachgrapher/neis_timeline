    01A
    연속 7일 이상 미인정결석 발생 시학급담임 등록

    미인정결석학생 등록

    우리 반에 연속 7일 이상 미인정결석한 학생이 있으면 담임이 직접 등록하는 업무입니다. 미인정결석이 연속 7일 미만이라도 아동학대 의심 등으로 '경찰에 수사 의뢰된 학생'은 포함합니다. 등록 주체가 학급담임교사이므로 대상학생 조회 시 해당 반 학생만 조회됩니다.

    언제?
    학기중, 학급담임교사가 [학적-출결관리-출결관리-일일출결관리(담임용)]에서 출결관리를 마친 뒤 연속 7일 이상 미인정결석이 확인된 시점.
    누가?
    학급담임교사
    어디서?
    [학급담임-학적-미인정결석학생관리-미인정결석학생관리]
    무엇을
    어떻게?
    '학년도', '학년', '반' 확인 후 {등록} → '미인정결석학생 등록' 창에서 {학생찾기}를 클릭 → '학생찾기' 창에서 '일출결조회'나 '수기입력' 선택 후 {조회}('수기입력' 선택 시 '성명'에 학생 '성명'을 입력함) → 해당 학생 선택 후 '최초미인정결석일자'를 입력하고 {확인} → '미인정결석학생 등록' 창에서 '기본정보' 및 '미인정결석 관리항목' 등을 입력하고 {저장}.
    왜?
    장기 미인정결석 학생을 학교가 놓치지 않고 붙잡아 상급 교육기관 보고까지 이어지는 관리 체계에 올려두려고 합니다.

    등록 대상 기준

    • 3월 입학일부터 연속 7일 이상 미인정결석한 학생을 등록합니다.
    • 미인정결석이 연속 7일 미만이라도 아동학대 의심 등으로 '경찰에 수사 의뢰된 학생'은 포함합니다.
    • 미인정결석학생 등록 주체는 학급담임교사이므로 대상학생 조회 시 해당 반 학생만 조회할 수 있습니다.

    등록 창 입력 항목

    • '미인정결석학생 등록' 창에서는 '기본정보', '미인정결석 관리항목', '경찰수사의뢰 관리항목', '복귀 관리항목', '월별 관리이력'을 확인 또는 입력합니다.

    02B
    등록 이후 관리 기간 중

    미인정결석학생 관리항목 조회 및 수정

    이미 등록한 미인정결석학생의 관리 내용을 확인하거나 고쳐야 할 때 하는 업무입니다. 목록에서 '성명'을 클릭하면 열리는 '미인정결석학생조회' 창에서 '기본정보', '미인정결석 관리항목', '경찰수사의뢰 관리항목', '복귀 관리항목', '월별 관리이력'을 조회하거나 수정할 수 있습니다.

    언제?
    학기중, 미인정결석학생 등록을 마친 뒤 학생 상황이 바뀔 때마다.
    누가?
    학급담임교사
    어디서?
    [학급담임-학적-미인정결석학생관리-미인정결석학생관리]
    무엇을
    어떻게?
    '학년도', '학년', '반' 확인 후 목록에서 '성명'을 클릭함 → 나타나는 '미인정결석학생조회' 창에서 '기본정보', '미인정결석 관리항목', '경찰수사의뢰 관리항목', '복귀 관리항목', '월별 관리이력'을 조회하거나 수정함.
    왜?
    학생의 결석 경과와 경찰수사의뢰, 복귀 상황을 최신 상태로 남겨 상급 교육기관 보고 내용이 실제와 어긋나지 않게 하려고.

    실무 메모

    • '미인정결석학생 등록' 창과 '미인정결석학생조회' 창에서 다루는 항목은 '기본정보', '미인정결석 관리항목', '경찰수사의뢰 관리항목', '복귀 관리항목', '월별 관리이력'으로 같음.
    • 미인정결석학생 등록 주체는 학급담임교사이므로 대상학생 조회 시 해당 반 학생만 조회할 수 있음.
    • 항목명 옆의 △를 클릭할 때마다 △ → ▲ → ▼ 순으로 변경되고 각각 '정렬 없음', '오름차순', '내림차순'을 의미하며, 항목을 기준으로 여러 개 정렬 기준을 부여하는 경우 순서대로 번호가 부여됨(대부분의 조회 메뉴에 적용되는 기능임).

    보고 전 확인 시조회·출력

    집중관리 대상자 관리카드 조회 및 저장·출력

    미인정결석학생으로 등록된 학생의 관리 내용을 한 장으로 모아 보는 업무입니다. 미인정결석학생관리에 등록된 학생만 조회 대상이 됩니다. 상급 교육기관 보고 전이나 내부 협의 자료가 필요할 때 사용합니다.

    언제?
    학기중, 미인정결석학생 등록을 마친 뒤 보고 자료나 관리 내용 확인이 필요한 시점.
    누가?
    학급담임교사
    어디서?
    [학급담임-학적-미인정결석학생관리-미인정결석학생관리]
    무엇을
    어떻게?
    학생을 선택( ) → {개인별관리카드조회} 클릭 → 나타나는 ‘집중관리 대상자 관리카드’ 창에서 ‘기본사항’, ‘처리과정’, ‘월별 관리내용’ 확인 → 필요시 저장( ) 또는 출력( )함.
    왜?
    흩어져 입력한 관리 내용을 학생 한 명 단위로 모아, 보고와 협의 자리에서 그 학생의 상황을 근거 있게 설명하려고.

    실무 메모

    • PDF, 워드, 엑셀, 파워포인트, 한글 문서로 저장( )하거나 출력( )할 수 있음.

    05C
    보고 시점필요시 승인요청

    대상학생보고 및 상급 교육기관 제출

    등록·관리한 미인정결석 학생을 상급 교육기관으로 올리는 업무입니다. {대상학생보고} 후에도 결재권자의 결재가 완료되어야 {제출}까지 갈 수 있습니다. 학기중 보고가 필요한 시점에 수행합니다.

    언제?
    학기중, 미인정결석학생 등록과 관리항목 입력을 마쳐 보고가 필요한 시점.
    누가?
    학급담임교사, 결재권자
    어디서?
    [학급담임-학적-미인정결석학생관리-미인정결석학생관리]
    무엇을
    어떻게?
    해당 학생을 선택( ) → {대상학생보고} 클릭 → [학급담임-학적-미인정결석학생관리-미인정결석학생관리]에서 조회 → 필요시 {승인요청}으로 업무승인과정을 거침 → 결재권자의 결재 완료 후 상급 교육기관에 {제출}함.
    왜?
    장기 미인정결석 학생의 상황을 학교 안에만 두지 않고 상급 교육기관이 함께 확인·지원할 수 있게 넘기려고.

    실무 메모

    • {대상학생보고} 후 필요시 {승인요청}으로 업무승인과정을 거쳐 결재권자의 결재 완료 후 상급 교육기관에 {제출}함.
    • {대상학생보고}를 클릭하면 [학급담임-학적-미인정결석학생관리-미인정결석학생관리]에서 조회됨.

    06C
    보고 이후조회

    미인정결석학생 보고이력조회

    보고를 마친 학생의 보고 내역을 확인하는 업무입니다. 보고이력은 대상학생보고를 거친 학생에 대해서만 남습니다. 같은 학생의 보고가 여러 차례 이어질 때 앞선 보고 내용을 되짚는 데 씁니다.

    언제?
    학기중, 대상학생보고와 제출을 진행한 뒤.
    누가?
    학급담임교사
    어디서?
    [학급담임-학적-미인정결석학생관리-미인정결석학생관리]
    무엇을
    어떻게?
    해당 학생을 선택( ) → {보고이력조회} 클릭 → 나타나는 ‘미인정결석학생 보고이력조회’ 창에서 미인정결석 대상 학생의 보고이력을 조회함.
    왜?
    이미 올린 보고와 앞으로 올릴 보고가 어긋나지 않도록 지난 보고 내용을 확인하려고.

    03B
    재등교 후 다시 7일 이상 미인정결석이 발생한 때결석 재발 학생 한정

    재발 학생의 최초미인정결석일자 수정

    이미 등록된 학생이 등교를 재개했다가 다시 장기 미인정결석에 들어간 경우에만 해당하는 업무입니다. 동일한 학생이 7일 이상 미인정결석으로 등록된 이후 등교하다가 다시 7일 이상의 미인정결석이 발생하는 경우 새로 등록하지 않고 '최초미인정결석일자'를 고칩니다.

    언제?
    학기중, 등록된 학생이 재등교한 뒤 다시 7일 이상 미인정결석이 발생한 시점.
    누가?
    학급담임교사
    어디서?
    [학급담임-학적-미인정결석학생관리-미인정결석학생관리]
    무엇을
    어떻게?
    목록에서 해당 학생의 '성명'을 클릭함 → '미인정결석학생 등록' 창에서 '최초미인정결석일자'를 두 번째 미인정결석 시작일로 수정함 → {저장}함.
    왜?
    두 번째 결석의 시작일을 기준으로 관리 기간이 다시 세어지게 해 보고 시점과 관리 이력이 실제 결석 상황과 맞도록 하려고.

    실무 메모

    • 동일 학생이 재차 장기 미인정결석하는 경우 별도 등록이 아니라 '최초미인정결석일자'를 두 번째 미인정결석 시작일로 수정함.
    • 3월 입학일부터 연속 7일 이상 미인정결석한 학생을 등록하며, 미인정결석이 연속 7일 미만이라도 아동학대 의심 등으로 '경찰에 수사 의뢰된 학생'은 포함함.
