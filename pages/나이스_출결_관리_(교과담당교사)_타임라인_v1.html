      01A
      매 수업시간 직후일자 기준 입력

      과목별 출결 관리 (일자순)

      교과담당교사가 자기 수업의 교시별 출결을 처리하는 기본 업무이며, 창의적 체험활동은 이 메뉴에서 제외되므로 별도 메뉴에서 처리한다. 수강 학생의 일자별·교시별 출결 처리에 대한 권한과 책임은 교과담당교사에게 있음. 하루에 여러 과목을 가르쳐 그날 수업을 한 번에 정리하고 싶을 때 '일자순'을 고른다.

      언제?
      학기중 매 수업시간, 교육과정 업무담당자가 편제·교과담당교사 입력과 각 과목별 시간표 등록을 마친 뒤.
      누가?
      교과담당교사
      어디서?
      [교과담임-학적-출결관리-과목별출결관리-과목별출결관리(창의적체험활동제외)]
      무엇을
      어떻게?
      '학년도', '학기' 확인 후 '일자순' 선택 → '일자'를 선택하고 {조회} → 1학년 '과목'을 클릭하고 '출석상태'를 표기(결과 시 '/' 표기) → '비고'에 사유 입력 후 {저장} → {출결마감}.
      왜?
      학생이 각 과목의 수업량 3분의 2 이상을 실제로 출석했는지를 그날그날 사실대로 남겨, 학점 취득 여부가 뒤에 정확히 판별되게 하려고.

      출석률·결과 표기 기준

      • 고등학교는 2025학년도 1학년부터 각 학년 과정의 수료에 필요한 출석일수(수업일수의 3분의 2 이상) 외에도 학점 취득을 위한 '과목출석률(실제 운영한 수업 횟수의 3분의 2 이상 출석)'이 적용됨.
      • 나이스에 입력 시 결과 사유(질병/미인정/기타)에 대한 구분 없이 '/'로만 입력하고, 필요 시 '비고'란에 결과처리 사유를 입력할 수 있음.
      • 출석인정으로 처리하는 교시는 결과 표시('/')를 하지 않고 '비고'란에만 '출석인정 결과'를 반드시 입력해야 함. 교과담당교사가 학생의 출석인정 결과를 사전에 인지한 경우와 사후에 학급담임교사로부터 '기존에 처리한 결과 기록의 삭제 요청'이 있는 경우 모두 입력이 필요함.
      • 수업시간에 불참한 학생이 없는 경우에는 {출결마감}만 함.
      • 학교는 출결관련 규정에 결과처리 기준을 포함하여야 하며, 사전에 학생 및 학부모에게 안내하여 정확한 출결 관리가 이루어질 수 있도록 노력해야 함. 예시) 수업시간 중 ○○분 이상을 불참한 경우 결과처리, 같은 날짜에 '지각, 조퇴, 결과'가 발생하여 어느 한 가지로만 처리하는 경우 '출석인정' 사유는 제외하고 처리함(2026학년도 1･2학년).
      • 교육부 기초학력진로교육과-3248(2024. 9. 12.) '2025학년도 이후 고교학점제 학점이수 인정기준 및 최소 성취수준 보장지도 운영 계획 안내'를 참고함.

      화면 색 표시와 편의 기능

      • 등록한 출결자료('/')가 다른 사용자에 의해 삭제된 경우 출결 부분 배경이 파란색으로 변경되며, 마우스를 가져가면 툴팁으로 최종 수정자를 확인할 수 있음.
      • 다른 사용자가 출결자료('/')를 등록한 경우 출결자료('/')가 분홍색으로 변경되며, 마우스를 가져가면 툴팁으로 최종 수정자를 확인할 수 있음.
      • '비고'란에 같은 내용을 여러 학생에게 입력하기 위해서는 해당 학생들을 선택한 후 '비고 일괄'에 내용을 입력하고 {적용}함.
      • 학생 '성명'을 클릭하면 나타나는 '학생별 교시출결 상세조회' 창에서 일자별 결시여부와 비고(사유)를 확인할 수 있으며, {엑셀다운로드}로 엑셀 파일, 한셀 파일, CSV 파일로 다운받을 수 있음.
      • {현장실습/인정결적용}으로 현장실습생의 출결 내용을 자동으로 반영함.
      • 학급담임교사가 [학적-출결관리-출결관리-일일출결관리(담임용)]에서 수정한 교시는 이 메뉴에서 파란색으로 표기되며, 삭제 요청 전달사항은 {나의할일} 또는 이 메뉴의 '종모양' 아이콘을 클릭하여 확인할 수 있음.
      • 2026학년도 1･2학년 대상으로 '비고'란은 학생의 결과처리 사유를 학급담임교사와 교과담당교사 간에 공유하기 위한 것이며, '출석인정 결과'를 포함한 결과 사유 입력은 학교에서 자율적으로 정하여 활용할 수 있음.
      • 창의적 체험활동은 기존 동아리활동 출결관리와 동일하게 영역별 관리에서 출결을 관리하며(이수시간과 연동) 처리 방법은 과목과 동일함. 다만, 해당 교시에 '출석 인정'인 학생은 특기사항을 입력하지 않으므로 누가기록은 제외하거나 '활동내용'란에 '활동내용 없음'으로 입력함. 관련 메뉴는 [학생생활-창의적체험활동-자율･자치활동(자율활동)관리], [학생생활-창의적체험활동-자율･자치활동(자율활동)누가기록], [학생생활-창의적체험활동-진로활동관리], [학생생활-창의적체험활동-진로활동누가기록]임.

      오류 수정 시한

      • 나이스 교시별 출결 처리 오류는 당해 학년도 내에서만 수정 가능하므로 과목 '이수/미이수' 처리 및 학교생활기록부 마감 전 반드시 확인해야 함.
      • 학년도 종료일(학교생활기록부 마감) 이후에 발견된 출결 처리 오류는 학교생활기록부 정정 절차에 따라 처리하며, 이 경우에는 학교생활기록부 '출결상황'만 정정 가능함(나이스 원자료 정정은 불가함).
      • 출결처리 결과의 진위 여부 논란, 학생･학부모의 이의 제기 등 업무 곤란 상황 발생 시 학업성적관리위원회의 심의를 통해 처리 가능함.
      • '과목별 출석률'의 엄격한 관리를 위해 교과담당교사 및 학급담임교사의 교차 점검 등 수업 교시별 정확한 출결 관리가 필요함.

      매 수업시간 직후과목 기준 입력

      과목별 출결 관리 (과목순)

      입력 화면과 저장·마감 절차는 일자순과 같고, 조회 기준만 '담당과목'으로 바뀐다. 한 과목의 여러 교시를 몰아서 확인하거나 놓친 교시를 과목 단위로 찾아 채울 때 이 방식을 쓴다. 174학점 이내로 개설된 공동교육과정도 거점교 교과담당교사가 이 메뉴에서 처리한다.

      언제?
      학기중 매 수업시간, 교육과정 업무담당자가 편제·교과담당교사 입력과 각 과목별 시간표 등록을 마친 뒤.
      누가?
      교과담당교사
      어디서?
      [교과담임-학적-출결관리-과목별출결관리-과목별출결관리(창의적체험활동제외)]
      무엇을
      어떻게?
      '학년도', '학기' 확인 후 '과목순' 선택 → '담당과목'을 선택하고 {조회} → '과목'을 클릭하고 '출석상태'를 표기(결과 시 '/' 표기) → '비고'에 사유 입력 후 {저장} → {출결마감}.
      왜?
      과목 단위로 교시 출결을 빠짐없이 채워, 학기말 과목 출석률 산정에서 빠진 교시가 남지 않게 하려고.

      실무 메모

      • 학기별 과목 출결 마감 시, 과목별･일자별･전체시간표의 출결 현황이 일치해야 최종 학기 마감 버튼이 활성화됨.
      • 174학점 이내로 개설된 공동교육과정의 경우 거점교 교과담당교사가 이 메뉴에서 '출석상태'를 체크하고 {저장} 후 {출결마감}하면, 타교수강생은 소속교(참여교)의 학급담임교사가 [학급담임-학적-출결관리-출결관리-일일출결관리(담임용)]에서 공동교육과정 수강생 '성명'을 클릭하면 나타나는 '타학교출결내역' 창에서 {결시} 또는 {출석}을 클릭하여 반영함.
      • 기존 출결관리 업무 절차에서 과목별 출결관리 절차가 새롭게 추가됨(2025학도부터 전체 학년에 동일하게 사용함).
      • 창의적 체험활동의 경우 기존 동아리활동 출결관리와 동일하게 영역별 관리에서 출결도 같이 처리할 수 있도록 분리함.
      • 교과담당교사는 이 메뉴에서 해당 교시에 결과 표시('/')와 '비고'에 사유를 등록하며, 일과 후 학급담임교사가 [학급담임-학적-출결관리-출결관리-일일출결관리(담임용)]에서 {출결마감} 시 수업 불참의 종류(마감구분)를 표시하고 '사유'란에 불참 사유를 입력함.

      나이스플러스 출결자료 나이스 반영

      나이스플러스로 수업 중 실시간 출결을 처리하는 교사에게만 해당한다. 나이스플러스에서 {마감}하면 출결정보가 [교과담임-학적-출결관리-출결관리-교과시간별출결등록]에 자동으로 반영된다. 나이스 쪽에서는 반영 내용을 확인해 걸러 넣는 작업만 한다.

      언제?
      학기중, 나이스플러스에서 해당 차시 출결을 저장·마감한 뒤.
      누가?
      교과담당교사
      어디서?
      [교과담임-학적-출결관리-과목별출결관리-과목별출결관리(창의적체험활동제외)], [교과담임-학적-출결관리-출결관리-교과시간별출결등록]
      무엇을
      어떻게?
      나이스플러스(https://neisplus.kr)에서 수업 강의실 해당 차시의 수업 미참여 학생 '출석상태'를 체크하고 {저장} 후 {마감} → 나이스에서 {나이스플러스출결조회}를 클릭 → '나이스플러스 출결조회' 창에서 반영할 출결 내용을 선택 후 {반영}.
      왜?
      수업 현장에서 확인한 참여 여부가 옮겨 적는 과정에서 어긋나지 않도록, 실시간으로 잡은 자료를 그대로 학적 원자료에 넘기려고.

      실무 메모

      • 교과담당교사는 나이스플러스를 활용하여 출결 관리를 실시간으로 진행 후 {나이스플러스출결조회}로 출결자료를 나이스에 반영할 수 있음.
      • 반영은 자동이 아니라 '나이스플러스 출결조회' 창에서 반영할 내용을 선택한 뒤 {반영}해야 완료됨.

      • '과목별 출석률'의 엄격한 관리를 위해 교과담당교사 및 학급담임교사의 교차 점검 등 수업 교시별 정확한 출결 관리가 필요함.
