    현장실습생 관리 업무 5개를 손대는 시점 순서로

    타임라인의 버튼을 업무카드 누르면 해당 업무 카드로 바로 이동합니다.

    업무시기
    학기초, 학기중, 학기말
    업무담당
    현장실습 업무담당자, 학급담임교사
    메뉴경로
    [학적-위탁･현장실습학생관리-위탁･현장실습학생관리]
    선행조건
    후행처리로 학급담임교사가 [학적-출결관리-출결관리-일일출결관리(담임용)]에서 현장실습생 대상으로 출결관리({저장} 후 {출결마감})함.

    업무 타임라인

    왼쪽에서 오른쪽으로 갈수록 나중에 하는 일입니다. 번호는 원문 업무 번호입니다.

    1. 01

      현장실습 시작 전 등록

      산업수요 맞춤형고·특성화고·직업계열 학과 설치 일반고 한정 · 실습 기간 시작 전 완료

    2. 02

      현장실습 기간 출결 처리

      현장실습생 등록이 끝난 학급의 담임교사가 기간 시작에 맞추어 진행.

    3. 03

      출결마감 후 이수시간 확인

      출결마감 완료가 선행조건 · 학기중·학기말 수시 확인

    4. 04

      시간표 변경·대입자료 작성 시

      실무과목 능력단위 시간표를 고친 학교와 수시·정시 대입전형자료를 만드는 학년만 해당.

    실선 모든 학교가 거치는 구간 점선 해당하는 경우에만 하는 구간 카드 좌측 글자 원문 STAGE 표기

    01A
    현장실습 시작 전산업수요 맞춤형고·특성화고·직업계열 학과 설치 일반고 한정

    위탁･현장실습학생 조회 후 현장실습생 등록

    산업수요 맞춤형 고등학교, 특성화고등학교, 직업계열 학과가 설치된 일반고등학교에서 현장실습을 운영하는 경우에만 해당하는 업무입니다. 나이스를 활용하지 않거나 나이스플러스(NEIS+)를 활용하는 현장실습기관의 현장실습생을 등록하는 과정입니다. 여기서 등록해 두어야 학급담임교사가 출결관리에서 현장실습생을 대상으로 처리할 수 있습니다.

    언제?
    학기초, 학기중, 학기말에 현장실습 기간이 시작되기 전.
    누가?
    현장실습 업무담당자
    어디서?
    [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-위탁･현장실습학생등록]
    무엇을
    어떻게?
    ‘학년도’, ‘학기’ 확인 후 ‘계열/학년/학과’, ‘반’, ‘기관명(타학교)’을 선택하고 {조회} → {등록}을 클릭하면 나타나는 ‘위탁학생등록’ 창에서 나이스플러스(NEIS+) 활용 기관과 나이스를 활용하지 않는 현장실습기관을 검색하여 반영하고 현장실습생의 정보를 등록함.
    왜?
    현장실습 기간에도 소속교 개설 실무과목의 능력단위 이수시간이 학생에게 제대로 쌓이게 하려고.

    실무 메모

    • {등록}을 클릭하면 나타나는 ‘위탁학생 등록’ 창과 이 창에서 {기관찾기}를 클릭하면 나타나는 ‘위탁기관찾기’ 창은 제시된 순서대로 현장실습생을 등록함.
    • 현장실습기관이 조회되지 않으면 {수기입력}으로 직접 등록함.

    후행처리

    • 학급담임교사가 [학적-출결관리-출결관리-일일출결관리(담임용)]에서 현장실습생 대상으로 출결관리({저장} 후 {출결마감})함.

    타임라인으로 돌아가기

    02B
    현장실습 기간 시작 시담임 업무

    현장실습/인정결 출결기간 입력

    현장실습생으로 등록된 학생이 있는 학급의 담임교사가 하는 일입니다. 현장실습 기간 전체를 하루씩 손으로 처리하는 대신 '시작일자'와 '종료일자'로 기간을 한 번에 입력해 두는 단계입니다.

    언제?
    학기중, 현장실습생 등록이 끝난 뒤 현장실습 기간에 맞추어
    누가?
    학급담임교사
    어디서?
    [학급담임-학적-출결관리-출결관리-일일출결관리(담임용)]
    무엇을
    어떻게?
    '학년도', '계열/학년/학과', '반' 확인 후 '일자'를 선택하고 {조회} 함 → {현장실습/인정결} 을 클릭하면 나타나는 '일일출결관리 현장실습/인정결 출결기간입력' 창에서 현장실습생에 대해 '시작일자', '종료일자', '비고'를 입력하고 {저장} 후 {닫기} 함.
    왜?
    현장실습으로 학교에 나오지 않는 기간을 결석이 아닌 출석인정결석으로 처리할 근거를 미리 잡아두려고 합니다.

    실무 메모

    • {현장실습/인정결} 을 클릭하면 나타나는 '일일출결관리 현장실습/인정결 출결기간입력' 창에서 현장실습생의 '비고'란을 일괄입력하고자 하는 경우 '선택학생 비고 일괄 반영'에서 '비고'란을 입력 후 해당 현장실습생을 선택하고 {선택학생비고반영} 함.
    • 공강시간의 출결처리는 공동교육과정에 한하여 사용 가능함(클릭 시 활성화 됨).

    타임라인으로 돌아가기

    03B
    출결기간 입력 직후담임 업무

    현장실습/인정결적용 후 저장·출결마감

    출결기간 입력을 마친 학급담임교사가 이어서 하는 일입니다. 적용하면 '조회', '교시', '종례'란에 '/'가 표시되고 '마감'란에 '출석인정결석'으로 입력되며, {출결마감}까지 해야 실무과목 능력단위 이수시간이 누적 반영됩니다.

    언제?
    학기중, 현장실습/인정결 출결기간 입력을 마친 뒤
    누가?
    학급담임교사
    어디서?
    [학급담임-학적-출결관리-출결관리-일일출결관리(담임용)]
    무엇을
    어떻게?
    {현장실습/인정결적용} 하면 '조회', '교시', '종례'란에 '/'가 표시되고 '마감'란에 '출석인정결석'으로 입력된 현장실습생의 출결정보를 확인 후 {저장} 하고 {출결마감} 함.
    왜?
    현장실습 기간을 출석으로 인정하고, 그 기간이 실무과목 능력단위 이수시간으로 학생 기록에 쌓이게 하려고 합니다.

    마감이 만드는 결과

    • {출결마감} 시 현장실습생의 대상자의 출결이 비어있는 경우 출석인정결석으로 마감되며, 실무과목 능력단위 이수시간이 [학생생활-자격증및NCS이수상황-국가직무능력표준이수상황관리] 에 누적하여 반영됨.
    • 학생/학부모서비스의 [학교생활-출석부-출석상세조회] 에서 조회되는 출결유형인 '마감' 정보는 [학적-출결관리-출결관리-일일출결관리(담임용)] 에서 등록한 '마감' 자료임.
    • 해당일자 기준 이전 출결이 연속 7일 이상 같은 사유의 결석 학생의 경우 장기결석자 대상을 알림을 나의할일에 전송됨.

    잘못 등록한 출결 되돌리기

    • 잘못 등록된 출결자료를 삭제하기 위해서는 '깨끗이'를 선택하고 '마감' 또는 '교시'를 클릭함(2026학년도 3학년 기준).

    04C
    현장실습 출결마감 이후 수시현장실습 운영 학교 한정

    국가직무능력표준이수상황에서 월별 이수시간 확인

    산업수요 맞춤형 고등학교, 특성화고등학교, 직업계열 학과가 설치된 일반고등학교에서 현장실습을 운영하는 경우에 해당한다. {출결마감} 시 현장실습생의 실무과목 능력단위 이수시간이 [학생생활-자격증및NCS이수상황-국가직무능력표준이수상황관리]에 누적하여 반영되므로, 출결마감 뒤 실제로 반영된 시간을 학생별로 확인한다.

    언제?
    학기중, 학기말. 현장실습생 대상 출결관리({저장} 후 {출결마감})가 끝난 뒤
    누가?
    학급담임교사, 현장실습 업무담당자
    어디서?
    [학급담임-학생생활-자격증및NCS이수상황-국가직무능력표준이수상황관리]
    무엇을
    어떻게?
    '학년도', '학기', '계열/학년/학과', '반' 확인 후 {조회} → 해당 학생의 성명을 선택하고 실무과목 능력단위 '이수시간'을 클릭 → 나타나는 '국가직무능력표준 이수시간 상세내역' 창에서 현장실습 기간의 월별 실무과목 능력단위 이수시간을 확인 후 {닫기}함.
    왜?
    현장실습 기간이 실무과목 능력단위 이수시간으로 제대로 쌓였는지 학생별로 짚어, 이수 누락을 학기말 이전에 잡아내려고.

    실무 메모

    • [학생생활-자격증및NCS이수상황-국가직무능력표준이수상황조회]에서도 현장실습 기간의 월별 실무과목 능력단위 이수시간을 확인할 수 있음.
    • 학생/학부모서비스의 [학교생활-출석부-출석상세조회]에서 조회되는 출결유형인 '마감' 정보는 [학적-출결관리-출결관리-일일출결관리(담임용)]에서 등록한 '마감' 자료임.

    05C
    시간표 변경 시, 수시·정시 대입전형자료 작성 시해당 시 선택

    기준일 설정 후 이수시간재계산

    실무과목 능력단위 시간표를 고친 학교와 대입전형자료를 만드는 학년에 해당한다. [교육과정-시간표관리-전체시간표관리]에서 실무과목 능력단위 시간표가 변경된 경우에는 이수시간 기준일의 시작일과 종료일을 설정하고 {이수시간재계산}으로 다시 반영해야 함. 대입전형자료를 생성할 때는 전형별 기준일에 맞춰 학생별로 재계산한다.

    언제?
    학기중, 학기말. 실무과목 능력단위 시간표가 변경된 뒤 또는 수시·정시 대입전형자료 작성 시점
    누가?
    학급담임교사, 현장실습 업무담당자
    어디서?
    [학급담임-학생생활-자격증및NCS이수상황-국가직무능력표준이수상황관리], [교육과정-시간표관리-전체시간표관리]
    무엇을
    어떻게?
    이수시간 기준일의 시작일과 종료일을 설정하고 {이수시간재계산}으로 실무과목 능력단위 이수시간을 다시 반영 → 대입전형자료 작성 시에는 이수시간 기준일의 종료일을 '직접입력'으로 선택 후 각각 2025.08.31.과 2025.11.30.로 설정하여 학생별로 {이수시간재계산} 후 {저장}하고 대입전형자료를 생성함.
    왜?
    시간표가 바뀌거나 전형별 마감 시점이 다를 때, 그 시점까지의 이수시간이 그대로 대입전형자료에 실리게 하려고.

    시간표를 고친 경우

    • [교육과정-시간표관리-전체시간표관리]에서 실무과목 능력단위 시간표가 변경된 경우 이수시간 기준일의 시작일과 종료일을 설정하고 {이수시간재계산}으로 실무과목 능력단위 이수시간을 다시 반영해야 함.

    대입전형자료를 만드는 경우

    • 수시 및 정시 대입전형자료 작성 시 이수시간 기준일의 종료일을 '직접입력'으로 선택 후 각각 2025.08.31.과 2025.11.30.로 설정하여 학생별로 {이수시간재계산} 후 {저장}하고 대입전형자료를 생성함.
