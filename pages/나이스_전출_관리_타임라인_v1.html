      01A
      전입교 자료요청 직후

      전출자료 요청 접수 확인

      전출생이 발생해 전입교에서 자료를 요청하면 가장 먼저 하는 확인 작업입니다. 전출일 기준 학교생활기록부 모든 항목 입력이 확인되고 전입교에서 자료를 요청한 상태여야 이후 절차를 진행할 수 있습니다.

      언제?
      학년초, 학기중. 전입교에서 전출생 자료를 요청한 뒤.
      누가?
      학적 업무담당자
      어디서?
      [학적-전출관리-전출관리-전출자료요청접수(2025학년도)]
      무엇을
      어떻게?
      ‘학년도’, ‘학년’ 확인 → ‘기간’을 설정하고 {조회} → 전입교에서 전출생 자료요청한 내용을 확인함.
      왜?
      어느 학교가 어떤 학생의 자료를 요청했는지 먼저 확인해 엉뚱한 학생의 자료를 내보내지 않으려고.

      실무 메모

      • 재외한국학교에서 국내학교로 전출하였는데 국내학교에서 건강기록부 자료 입력 요청이 온 경우, 재외한국학교는 나이스의 [보건]을 사용하지 않으므로 온라인으로 건강기록부를 전송할 수 없음. 재외한국학교에서는 수기로 작성한 건강기록부를 공문 발송 등의 방법으로 처리하고 있음.

      타임라인으로 돌아가기

      02A
      학교생활기록부 생성 전필요시

      월출결자료 등록(필요시)

      모든 학교가 하는 업무는 아닙니다. [학적-출결관리-출결관리-일일출결관리(담임용)]을 활용하는 학교에서는 본 과정을 생략하고, 일일출결관리를 쓰지 않는 학교만 전출생의 월별 출결자료를 직접 입력합니다.

      언제?
      학년초, 학기중. 전출자료 요청 접수를 확인한 뒤, 학교생활기록부 생성 전.
      누가?
      학적 업무담당자
      어디서?
      [학적-전출관리-전출관리-월출결자료등록(선택)]
      무엇을
      어떻게?
      ‘학년도’, ‘학년’ 확인 → ‘기간’을 설정하고 {조회} → 전출생 ‘성명’을 클릭 → ‘월출결자료등록’ 창에서 월별 출결자료를 입력하고 {저장}.
      왜?
      전출일까지의 출결이 비어 있으면 전입교로 넘어가는 학교생활기록부 출결상황이 어긋나므로, 넘기기 전에 출결을 맞춰 두려고.

      실무 메모

      • [학적-출결관리-출결관리-일일출결관리(담임용)]을 활용하는 학교에서는 본 과정을 생략함.

      03A
      출결 정비 후, 전출자료 전송 전

      전출일자 기준 학교생활기록부 생성

      전출생 전원에게 해당하는 업무입니다. ‘학적반영일자’를 전출일자로 설정해야 학적사항과 출결자료가 전출일 기준으로 맞게 반영됩니다.

      언제?
      학년초, 학기중. 월출결자료 등록 등 자료 정비가 끝난 뒤, 전출자료 전송 전.
      누가?
      학적 업무담당자
      어디서?
      [학적-전출관리-전출관리-학교생활기록부생성]
      무엇을
      어떻게?
      ‘학년도’, ‘학년’, ‘기간’ 확인 → ‘전체’ 또는 ‘미생성’을 선택하고 {조회} → 전출생 ‘성명’을 클릭 → ‘학교생활기록부생성’ 창에서 ‘학적반영일자’를 전출일자로 설정 → {학교생활기록부생성} 후 {닫기}.
      왜?
      전출일까지의 학교생활을 확정된 기록으로 굳혀 전입교가 이어서 쓸 수 있게 하려고.

      실무 메모

      • [학적-전출관리-전출관리-학교생활기록부생성]에서 전출일자 기준으로 학교생활기록부를 생성하면 학교생활기록부 인적･학적사항의 ‘학적사항’에 ‘2025년 ○○월 ○○일 □□고등학교 전출’로 표기되며, 출결상황의 출결자료도 전출일자 기준으로 반영됨.
      • 여기에서 전출일자 기준으로 학교생활기록부를 생성한 경우 [학적-전출관리-전출관리-전출자료전송]에서 {➁학교생활기록부생성}은 하지 않음.

      타임라인으로 돌아가기

      04B
      학생부 생성 직후항목별 오류 확인 필요

      항목 확인 후 전출자료 전송

      전입교로 전출생의 학적 자료를 실제로 넘기는 단계입니다. 전출일자 기준으로 학교생활기록부 생성을 마친 뒤 진행하며, [학적-전출관리-전출관리-학교생활기록부생성]에서 이미 생성한 경우 이 화면의 {➁학교생활기록부생성}은 하지 않습니다. 항목별로 내용을 열어 오류 유무를 먼저 확인합니다.

      언제?
      학년초, 학기중. 전출일자 기준 학교생활기록부 생성을 마친 뒤
      누가?
      학적 업무담당자
      어디서?
      [학적-전출관리-전출관리-전출자료전송]
      무엇을
      어떻게?
      ‘학년도’, ‘학년’, ‘기간’ 확인 후 ‘전체’ 또는 ‘미전송’을 선택하고 {조회}하여 전출생 ‘성명’을 클릭 → ‘학적반영 자료선택(최종전송일자)’에서 해당 항목({기본학적}, {학생생활}, {성적}, {건강기록부}, {학교생활기록부}, {출결내역}, {PAPS}, {정정대장}, {학교스포츠클럽누가기록}, {개별화교육계획}) 클릭 후 내용의 오류 유무를 확인하고 전출교 교육과정 등을 ‘참고파일 업로드(10MB)’함 → ‘학적반영 자료선택(최종전송일자)’에서 전송할 자료를 선택하고 {③ 전출자료보내기} 후 {확인}함.
      왜?
      전입교가 학생을 받아 곧바로 가르칠 수 있도록, 오류 없는 학적·성적·건강 자료를 전출일 기준으로 넘겨주려고 합니다.

      실무 메모

      • [학적-전출관리-전출관리-학교생활기록부생성]에서 전출일자 기준으로 학교생활기록부를 생성한 경우 [학적-전출관리-전출관리-전출자료전송]에서 {➁학교생활기록부생성}은 하지 않음.
      • 항목별 확인 과정에서 창의적 체험활동 영역별 누가기록 시수 등의 오류가 있는 경우 나이스 해당 메뉴에서 수정 후 [학생부-학교생활기록부-학교생활기록부-학생부 반영]에서 학교생활기록부 항목별 반영 후 본 과정에서 다시 오류 유무를 확인함.

      05B
      전출자료 전송 직후

      전송자료 내역 확인

      전출자료를 보낸 뒤 무엇이 언제 누구에 의해 전송되었는지 확인하는 단계입니다. 전송이 끝난 학생만 대상이므로 조회 조건에서 ‘전송완료’를 선택합니다. 전송 화면과 같은 메뉴에서 이어서 확인합니다.

      언제?
      학년초, 학기중. 전출자료 전송을 마친 뒤
      누가?
      학적 업무담당자
      어디서?
      [학적-전출관리-전출관리-전출자료전송]
      무엇을
      어떻게?
      ‘학년도’, ‘학년’, ‘기간’ 확인(‘전송완료’ 선택)하고 {조회}하여 전출생 ‘성명’을 클릭 → {전송자료내역보기}를 클릭하면 나타나는 ‘전송자료내역 조회’ 창에서 ‘전송자료목록’, ‘최종전송일자’, ‘전송자’를 확인함.
      왜?
      빠진 항목이나 재전송 여부를 두고 전입교와 다투지 않도록, 넘긴 자료의 범위와 시점을 기록으로 확인해 두려고 합니다.

      타임라인으로 돌아가기

      06B
      전출자료 전송 확인 후

      전출 기안문서 상신

      전출생의 학적반영을 하기 전에 결재권자의 결재를 받는 단계입니다. 결재가 완료되어야 다음 단계인 학적반영을 진행할 수 있습니다. 반복적인 결재라인은 {개인결재선}으로 한 번에 지정할 수 있습니다.

      언제?
      학년초, 학기중. 전출자료 전송을 마친 뒤
      누가?
      학적 업무담당자
      어디서?
      [학적-전출관리-전출관리-상신]
      무엇을
      어떻게?
      {결재자지정}으로 결재선을 등록({개인결재선}을 활용하면 반복적인 결재라인 지정을 한 번에 할 수 있음)하고 ‘기안내용’ 선택 후 {상신}으로 업무승인과정을 거쳐 결재권자의 결재를 완료함(필요시 ‘내용’을 입력함).
      왜?
      학생의 학적을 학교 밖으로 옮기는 처분이므로, 담당자 판단만으로 확정하지 않고 결재권자의 승인을 남기려고 합니다.

      타임라인으로 돌아가기

      07B
      결재 완료 후

      전출생 학적반영

      결재가 끝난 전출생의 학적을 나이스에 최종 확정하는 단계입니다. ‘미반영’을 선택해 조회한 뒤 전출일자를 확인하고 반영합니다. 반영 후에는 해당 학생이 재학생 목록에서 빠지므로 학교생활기록부 조회 경로가 달라집니다.

      언제?
      학년초, 학기중. 기안문서 상신으로 결재권자의 결재가 완료된 뒤
      누가?
      학적 업무담당자
      어디서?
      [학적-전출관리-전출관리-학적반영]
      무엇을
      어떻게?
      ‘학년도’, ‘학년’, ‘기간’ 확인 후 ‘미반영’을 선택하고 {조회}하여 전출생 선택 후 전출일자 확인하고 {학적반영}함.
      왜?
      전출 처리를 학적상 확정해 재학생 명부와 출결·수업일수가 실제 재학 상태와 어긋나지 않게 하려고 합니다.

      실무 메모

      • 학적반영한 전출생의 학교생활기록부는 [학생부-학교생활기록부-학교생활기록부-학생부조회및출력]에서 ‘재학아닌학생’으로 선택 후 성명을 입력하고 {조회}할 수 있음.

      타임라인으로 돌아가기

      08C
      전출 자료 입력 완료 후나이스 미사용교 전출 한정

      나이스 미사용교 전출생 추가 등록과 항목 확인

      전입교가 나이스를 사용하지 않는 학교(재외한국학교 등)일 때만 해당하는 업무입니다. 전입교에서 자료요청이 들어오지 않으므로 전출교가 직접 전출생을 등록해야 합니다. 전출일자까지의 출결상황, 창의적 체험활동상황, 봉사활동실적, 행동특성 및 종합의견 등 모든 자료를 학교생활기록부에 입력을 완료한 뒤 진행합니다.

      언제?
      학년초, 학기중. 전출일자까지의 모든 학교생활기록부 자료 입력을 완료한 뒤.
      누가?
      학적 업무담당자
      어디서?
      [학적-전출관리-전출관리-종합자료검색]
      무엇을
      어떻게?
