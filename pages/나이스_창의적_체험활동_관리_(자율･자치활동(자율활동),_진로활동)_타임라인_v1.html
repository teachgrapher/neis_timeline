      활동 실시 직후반 전체 공통 활동일 때

      자율･자치활동(자율활동) 누가기록 반별 일괄입력

      반 전체 학생이 같은 활동을 한 경우에 쓰는 방식이다. 이수시간 기준일에 따른 최대 이수시간을 전체 학생에게 반영하거나, 이수시간과 활동내용을 한 번에 넣을 때 사용한다. 미참여 학생이 있으면 출결에 표기된 내용이 반영되므로 출결관리를 먼저 끝내 두는 편이 낫다.

      언제?
      학기중, 반 전체가 참여한 자율･자치활동(자율활동)을 실시한 직후.
      누가?
      학급담임교사, 교과담당교사
      어디서?
      [학급담임-학생생활-창의적체험활동-자율･자치활동(자율활동)관리] 의 {누가기록} 탭
      무엇을
      어떻게?
      {누가기록} 탭에서 '학년도', '학년', '반'을 확인하여 {조회} 후 {일괄등록} → '자율∙자치활동 누가기록 일괄등록' 창에서 '일자', '시간표내역'을 선택 후 전체 학생을 선택하여 '이수시간'과 '활동내용'을 입력하여 {저장}하고 {닫기}.

      반 단위로 함께한 활동을 학생마다 반복 입력하지 않고 한 번에 남겨, 이수시간이 학생별로 어긋나는 일을 줄이려고.

      실무 메모

      언제?

      누가?
      학급담임교사
      어디서?

      무엇을
      어떻게?
      { 학생부자료기록 } 탭에서 '이수시간기준일'을 설정하고 {이수시간반영} → 학생별 '학생부이수시간'과 '누가기록이수시간합계'를 대조 → 값이 다르면 누가기록 된 일자를 기준으로 [교육과정-시간표관리-전체시간표관리]에서 자율･자치활동(자율활동) 시간표 등록 여부와 마우스 오른쪽 버튼 { 수업정보 }의 수강학생편성여부를 확인 → [학적-출결관리-출결관리-일일출결관리(담임용)]에서 해당 일자로 조회하여 해당 교시 출석상태에 '/' 처리가 되어 있는지 확인 → { 누가기록 } 탭에서 학생을 선택하고 {출결현황조회}를 클릭해 '월'을 선택하여 {조회}한 뒤 결석(과)한 교시의 누가기록을 수동으로 삭제 → 남는 차이는 이수시간을 확인하여 수기로 입력하고 {저장}함.
      왜?
      학생이 실제로 참여해 이수한 시간만 학교생활기록부에 남도록 하여, 참여하지 않은 활동시간이 인정되거나 참여한 시간이 빠지는 것을 막으려고.

      이수시간이 계산되는 방식

      • 이수시간 반영 시 '이수시간기준일'을 설정하지 않으면 현재 시스템 일자로 반영됨.
      • '이수시간'은 누가기록의 시간이 합산되는 것이 아니라 [교육과정-시간표관리-전체시간표관리]에서 자율 ･ 자치활동(자율활동)으로 등록된 시수와 [교육과정-학사일정관리]의 { 행사코드관리 } 탭에서 '학생부 특별활동'이 '자율 ･ 자치활동(자율활동)'으로 등록된 행사가 전체시간표관리에 등록된 시수에 '이수시간기준일'까지 학생의 일일출결현황에 따라 자동 계산됨(자율 ･ 자치활동(자율활동)과 진로활동의 내용이 같음).
      • 창의적 체험활동의 영역별 이수시간은 정규교육과정 내에서 실시한 학년 ･ 학급 단위의 활동시간을 기준으로, 본인이 실제로 참여하여 이수한 시간을 입력함.
      • 학년말에 '학생부자료기록'의 이수시간과 '누가기록'의 누가기록 이수시간 합계를 반드시 대조 ･ 확인하여 일치시키도록 함.

      값이 어긋나는 대표 사례

      • 학기중 반변경 학생 또는 위탁학생, 학적변동자(반변경, 전입 등)의 경우 학생부 이수시간과 누가기록 이수시간 합계가 다를 수 있으니 확인하여 수기 입력함.
      • 반 변경한 학생은 { 학생부자료기록 } 탭에서 반 변경 이전의 이수시간만 자동으로 계산되므로, 반 변경 이전과 반 변경 후의 이수시간을 수기로 합산하여 등록함.
      • 누가기록을 먼저 등록하고 나중에 결석처리를 한 경우 기존에 등록된 누가기록은 자동으로 삭제되지 않고 수동으로 삭제해야 함.
      • 특정 학생만 특정 일자가 조회되지 않으면, 해당 반 강의실에 '자율 ･ 자치활동(자율활동)' 시간표가 등록되어 있는지와 수강학생편성여부를 확인함. 정상 편성되어 있다면 그 일자에 결석(과)을 한 경우이거나 해당 교시 출석상태에 '/' 표시가 되어 있어 조회되지 않음.
      • 수학여행 미참여 학생에 대한 창의적 체험활동 계획이 별도로 마련되지 않은 경우에는 { 누가기록 } 탭에 입력하지 않으며, 등교한 학생은 출석이 인정되어 두 값이 일치하지 않으므로 해당 학생의 이수시간을 확인하여 수동으로 수정해야 함.

      17E
      거점교·위탁기관 자료 수신 후위탁·공동교육과정 학생 한정

      위탁･공동교육과정 학생부 자료 확인과 과년도 누가기록 조회

      공동교육과정 수강생이나 위탁기관 위탁학생이 있는 학급에만 해당한다. 거점교나 위탁기관이 특기사항을 전송하면 { 학생부자료기록 } 탭에 { 위탁 / 공동 } 버튼이 추가로 나타나 자료를 확인할 수 있고, 확인한 내용은 참고로 본교 자료에 합산하여 반영한다. 이전학년도 누가기록은 교무학년도를 바꾸지 않고도 조회할 수 있다.

      언제?
      학기중·학기말 거점교 또는 위탁기관에서 자료를 전송한 뒤, 특기사항을 입력하기 전에 수시로 확인함.
      누가?
      학급담임교사
      어디서?
      [학생생활-창의적체험활동-자율･자치활동(자율활동)관리]의 { 학생부자료기록 } 탭, [학적-기본학적관리-학생자료종합검색]
      무엇을
      어떻게?
      { 학생부자료기록 } 탭에서 {위탁/공동} 버튼을 클릭하여 거점교에서 전송한 학생부 자료를 확인 → 해당 내용을 참고로 본교 자료에 합산하여 반영 → 과년도 자료는 [학적-기본학적관리-학생자료종합검색]에서 '{ 학생생활-창의적체험활동누가기록 }'을 선택하여 해당 학생의 과년도 누가기록을 확인함.
      왜?
      학교 밖에서 이수한 활동까지 빠뜨리지 않고 본교 학생부에 담아 학생의 활동 이력이 끊기지 않게 하려고.

      실무 메모

      • 공동교육과정 수강생의 경우 { 학생부자료기록 } 탭에서 { 위탁 / 공동 }에 거점교에서 전송한 자료를 확인할 수 있는 버튼이 추가로 나타나며, 학급담임교사는 해당 버튼을 클릭해 자료를 확인하고 본교 자료에 합산하여 반영할 수 있음. 위 과정은 공동교육과정뿐 아니라 위탁기관 위탁학생의 경우도 동일함.
      • 위탁기관에서 보내온 누가기록은 나이스에서 별도로 관리하지 않음. 나이스에서는 학생부 자료에 대해서만 입력하며, 공문으로 송부한 누가기록은 별도로 관리함.
      • 교무학년도를 변경하지 않고 [학적-기본학적관리-학생자료종합검색]의 { 학생생활-창의적체험활동누가기록 }을 선택하면 해당 학생의 과년도 누가기록을 확인할 수 있음.
