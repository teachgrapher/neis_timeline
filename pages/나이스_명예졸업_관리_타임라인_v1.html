    01A
    학업성적관리위원회 심의 직후명예졸업자 발생 시 한정

    명예졸업 대상자 등록

    학칙에서 정하는 바에 따라 학교장이 명예졸업으로 인정한 학생이 있을 때만 하는 업무입니다. 학업성적관리위원회의 심의를 거쳐 명예졸업이 인정된 뒤에 나이스에 대상자로 등록합니다. 등록한 학생은 당해 학년도 졸업일을 기준으로 명예졸업 처리됩니다.

    언제?
    명예졸업자 발생 시, 학업성적관리위원회 심의로 명예졸업이 인정된 뒤.
    누가?
    학적 업무담당자
    어디서?
    [학적-명예졸업관리-명예졸업대상자관리]
    무엇을
    어떻게?
    [학적-명예졸업관리-명예졸업대상자관리]에서 '졸업학년도', '학적반영여부' 확인 후 '정렬순'을 선택하고 {조회}하여 {등록}함 → '명예졸업 대상자 등록' 창에서 '학년도' 확인 후 '학년', '반'을 선택하고 {조회}함 → 해당 학생을 선택하여 추가하고 '학적변동일자'를 설정한 후 {저장}하고 {닫기}함.
    왜?
    학교장이 명예졸업으로 인정한 학생을 졸업생과 구분해 남겨, 당해 학년도 졸업일 기준으로 명예졸업 처리가 이루어지게 하려고.

    실무 메모

    • 명예졸업은 학칙에서 정하는 바에 따라 학교장이 명예졸업으로 인정한 경우를 말함.
    • 명예졸업은 수료 및 졸업(｢초･중등교육법 시행령｣ 제50조), 학력인정(｢초･중등교육법 시행령｣ 제96조, 제97조, 제98조)이나 자격인정(｢초･중등교육법 시행령｣ 제99조, 제100조, 제101조, 제102조, 제103조)과 무관함.

    명예졸업 업무 처리 절차

    • 심의 주체는 학업성적관리위원회임.
    • 심의 절차는 심의 신청 → 학업성적관리위원회 개최 및 심의 → 명예졸업 인정 시 나이스에 명예졸업 대상자로 등록 → 당해 학년도 졸업일을 기준으로 명예졸업 처리임.

    02A
    대상자 등록 직후

    명예졸업대장번호 부여

    명예졸업 대상자로 등록한 학생에게 대장번호를 붙이는 업무입니다. '명예졸업대장번호'는 당해 학년도 졸업생의 졸업대장번호와 별도로 관리됩니다. 번호 형식과 시작번호를 정한 뒤 작업을 실행합니다.

    언제?
    명예졸업 대상자 등록을 마친 뒤.
    누가?
    학적 업무담당자
    어디서?
    [학적-명예졸업관리-명예졸업대상자관리], [학적-기본학적관리-기본신상관리]
    무엇을
    어떻게?
    [학적-명예졸업관리-명예졸업대상자관리]에서 '졸업학년도', '학적반영여부' 확인 후 '정렬순'을 선택하고 {조회}하여 해당 학생을 선택하고 {명예졸업대장번호부여}함 → '명예졸업 대장번호 부여' 창에서 '졸업학년도', '졸업회차' 확인 후 '명예졸업대장 시작번호'와 '명예졸업대장 번호부여' 형식을 선택하여 {작업실행} 후 {닫기}함.
    왜?
    명예졸업 학생의 대장 기록을 일반 졸업대장과 섞이지 않게 고유 번호로 관리하려고.

    실무 메모

    • '졸업회차', '명예졸업대장 시작번호'는 이전학년도에 나이스로 처리한 경우 마지막 번호 +1부터 자동으로 부여됨.
    • '명예졸업대장번호'는 당해 학년도 졸업생의 졸업대장번호와 별도 관리됨.
    • 명예졸업대장 시작번호는 숫자만으로 이루어진 자료와 ####-####의 형식으로만 부여할 수 있으며, 최대 16자리까지 부여할 수 있음. 숫자만으로 이루어진 자료는 하이픈(-) 뒤에 위치한 입력창에 졸업대장번호를 입력함. 예시는 2025-10001, 10987임.
    • '대장번호 형식변경'을 선택하면 '명예졸업대장 시작번호'를 '학년도-연번'으로 관리할 수 있음.

    명예졸업 사유 입력

    • [학적-기본학적관리-기본신상관리]의 {학적사항} 탭에서 '학적 특기사항'란에 '2025.06.12. 학교교육활동 중 사망'과 같이 명예졸업 사유를 입력함.

    대상자 등록 후

    명예졸업 대상자 학교생활기록부 생성

    언제?
    명예졸업자 발생 시, 명예졸업 대상자 등록과 명예졸업대장번호 부여가 끝난 뒤.
    누가?
    학적 업무담당자
    어디서?
    [학적-명예졸업관리-명예졸업대상자관리]
    무엇을
    어떻게?
    [학적-명예졸업관리-명예졸업대상자관리]에서 '졸업학년도', '학적반영여부' 확인 후 '정렬순'을 선택하고 {조회} → 해당 학생을 선택하고 {학교생활기록부생성} → '학교생활기록부생성' 창에서 해당 학생 정보를 확인하고 {학교생활기록부생성} 하고 '확인' 창에서 {확인} 후 {닫기} 함.

    04B
    학교생활기록부 생성 후

    명예졸업 대상자 승인요청

    명예졸업 대상자의 학교생활기록부를 생성한 뒤에 해당하는 업무입니다. 결재권자의 결재가 완료되어 '결재상태'가 '완결'이 되어야 다음 단계인 학적반영으로 넘어갈 수 있습니다. 업무승인과정을 거치므로 결재에 걸리는 시간을 감안해 신청합니다.

    언제?
    명예졸업자 발생 시, 명예졸업 대상자 학교생활기록부 생성이 끝난 뒤.
    누가?
    학적 업무담당자
    어디서?
    [학적-명예졸업관리-명예졸업대상자관리]
    무엇을
    어떻게?
    [학적-명예졸업관리-명예졸업대상자관리]에서 '졸업학년도', '학적반영여부' 확인 후 '정렬순'을 선택하고 {조회} → 해당 학생을 선택하고 {승인요청} 으로 업무승인과정을 거쳐 결재권자의 결재를 완료함.
    왜?
    학교장이 인정한 명예졸업이라는 사실을 결재로 확인받아 학적반영의 근거를 남기려고.

    실무 메모

    • {승인요청} 하면 '결재상태'가 '미상신'에서 '상신(진행)'으로 변경되며, 결재권자의 결재가 완료되면 '완결'로 변경됨.
    • 명예졸업 업무 처리 절차의 심의 주체는 학업성적관리위원회이며, 심의 절차는 심의 신청 → 학업성적관리위원회 개최 및 심의 → 명예졸업 인정 시 나이스에 명예졸업 대상자로 등록 → 당해 학년도 졸업일을 기준으로 명예졸업 처리임.

    05C
    결재 완결 후당해 학년도 졸업일 기준

    명예졸업 대상자 학적반영

    학업성적관리위원회 심의로 명예졸업이 인정되어 대상자 등록과 학교생활기록부 생성, 승인요청까지 마친 학교에서 하는 마지막 확정 작업입니다. {승인요청} 후 결재권자의 결재가 완료되어 '결재상태'가 '완결'로 변경된 뒤에 학적반영합니다. 반영하면 해당 학생은 재학생 자료에서 빠집니다.

    언제?
    명예졸업자 발생 시, 명예졸업 대상자 승인요청의 결재가 완결된 뒤
    누가?
    학적 업무담당자
    어디서?
    [학적-명예졸업관리-명예졸업대상자관리]
    무엇을
    어떻게?
    [학적-명예졸업관리-명예졸업대상자관리]에서 '졸업학년도', '학적반영여부' 확인 후 '정렬순'을 선택하고 {조회}하여 해당 학생을 선택하고 {학적반영}하고 {확인}함.
    왜?
    학교장이 명예졸업으로 인정한 학생을 당해 학년도 졸업일 기준으로 확정해, 재학생 통계와 학교생활기록부에 남지 않게 하려고.

    실무 메모

    • {승인요청}하면 '결재상태'가 '미상신'에서 '상신(진행)'으로 변경되며, 결재권자의 결재가 완료되면 '완결'로 변경됨.
    • 명예졸업 대상자를 {학적반영}하면 학적, 학교생활기록부 및 학생 수 현황, 학생이동부에서 제외됨.
    • 당해 학년도 졸업일 기준으로 명예졸업이 처리됨.

    후행 처리

    • [명예졸업관리] 작업 완료 후 졸업자를 생성하고 졸업대장번호를 부여한 후 학적반영하여 명예졸업장을 출력함.

    06C
    학적반영 후 오류 발견 시필요 시

    언제?
    명예졸업자 발생 시, 명예졸업 대상자 학적반영이 완료된 뒤 정정이 필요할 때

    어떻게?

    언제?
    명예졸업자 발생 시, 당해 학년도 졸업생 학적반영이 완료된 뒤

    어디서?

    무엇을
    어떻게?
    [학적-명예졸업관리-명예졸업대장조회]에서 '졸업학년도' 확인 후 '성명' 입력 및 '정렬순'을 선택하고 {조회} → 해당 명예졸업생의 명예졸업대장을 확인함.

    명예졸업 기록이 대장에 제대로 남았는지 확인해 학력 증명 자료가 뒤늦게 어긋나는 일을 막으려고 합니다.

    • {출력}으로 조회된 명예졸업대장을 출력할 수 있음.
