    01A
    학년말, 시·도교육청 배정 직후평준화지역 교육감 전형 한정

    교육청 배정자료 확인 및 출신 중학교 전송 요청

    평준화지역 학교에 해당하는 업무이며, 교육감 전형 입학 대상자는 도교육청에서 입학 대상 학생을 일괄 배정함. 시·도교육청이 등록한 입학생 배정자료를 확인한 뒤 출신 중학교로 기본 신상정보(사진 제외), 진로정보, 건강기록부 등의 자료를 요청함. '본교확인'을 '대상'으로 저장해야 중학교 자료를 가져와 반영함.

    언제?
    학년말, 신입생 배정자료 및 신입생 명단을 확인한 뒤
    누가?
    입학 업무담당자
    어디서?
    [입학-입학관리-입학대상자관리]
    무엇을
    어떻게?
    [입학-입학관리-입학대상자관리]에서 조회 조건 확인하고 {조회} → {재학생} 탭의 배정된 학생에서 '본교 확인' 학생 선택 → '본교확인 일괄선택'에서 '대상' 선택 → {저장} → 본교확인 '대상' 학생 선택 → {전송요청} → 출신 중학교로부터 배정자료의 '전송상태' 항목이 '전송완료' → '출신교상태' 확인과 '자료도착'의 도착일을 확인함.
    왜?
    신입생의 신상·진로·건강 자료를 출신 중학교에서 미리 받아 두어 입학 후 학적과 생활기록을 처음부터 채워 쓰기 위함.

    본교확인 상태의 뜻

    • 교육감 전형 입학 대상자는 도교육청에서 입학 대상 학생을 일괄 배정함.
    • '본교확인'은 배정자료가 도착하면 수정이 가능하고, 고등학교에서 직접 입력한 학생의 경우 초기 상태는 '대상'임.
    • 대상 — 본교 입학 대상자인지를 확인하는 단계로 '대상'으로 선택하여 {저장}하면 중학교로부터 기본 신상정보(사진 제외), 진로정보(개인정보(진로 관련 사항) 활동 동의서에 동의한 졸업예정자에 한함), 건강기록부 등을 가져와 반영함.
    • 비대상 — 배정자료는 도착했으나 실제 입학 대상자가 아닌 경우이며, '비대상'으로 저장하면 중학교로부터 받은 기본 신상정보(사진 제외), 진로정보, 건강기록부를 삭제하고 입학 대상자에서 제외함.
    • 미확인 — 입학 대상자에 대한 본교확인 상태가 미확인 상태임.

    출신교상태 확인

    • '출신교상태'는 입학 대상자의 출신중학교 확인 상태를 뜻함.
    • 확인 — 출신학교에서 입학 대상자의 배정학교와 학적사항을 확인한 상태임.
    • 미확인 — 출신학교에서 미확인한 경우로 {전체출력}하면 출신교의 작업 상태가 출력됨. 예시로 출신학교가 사전일괄승인을 설정하지 않았거나 [진로지도-동의여부마감관리]에서 진로정보 학생동의서 학년 마감 또는 건강기록부 마감을 하지 않은 경우가 있음.
    • 오류 — 출신학교 입학 대상자의 배정 학교나 인적·학적사항이 잘못되었음을 나타냄. '오류' 글자 위에 마우스를 올리면 출신학교에서 작성한 오류 사유를 확인할 수 있음.

    05B
    합격사정 완료 후학교장 전형 학교 한정

    입학 대상자 파일 생성(고교입학시스템 활용)

    학교장 전형으로 시행하는 학교에서만 하는 업무입니다. 교육감 전형과 달리 시·도교육청이 배정자료를 보내주지 않으므로, 입학 대상자를 고등학교에서 나이스 시스템에 직접 등록해야 합니다. 등록 방법은 파일로 만들어 일괄 등록하거나 개별 등록하는 두 가지가 있고, 이 카드는 일괄 등록에 쓸 파일을 먼저 내리는 단계입니다.

    언제?
    학년말, 고교입학시스템에서 합격사정이 끝난 뒤
    누가?
    입학 업무담당자
    어디서?
    [고교입학시스템] → [입학전형-합격사정관리-입학대상자다운로드]
    무엇을
    어떻게?
    업무포털에서 [고교입학시스템]을 클릭하여 로그인함 → [입학전형-합격사정관리-입학대상자다운로드]에서 조회 조건 선택 → {합격자다운로드} 함.
    왜?
    합격 사정 결과를 손으로 다시 옮겨 적지 않고 그대로 나이스 입학 대상자로 넘겨, 명단이 어긋나는 일을 막으려고.

    실무 메모

    • 학교장 전형의 경우 입학 대상자를 고등학교에서 나이스 시스템에 직접 등록함.
    • 입학 대상자를 고교입학시스템에서 파일로 만들어 일괄 등록하거나 개별 등록하는 방법이 있음.

    06B
    합격자 파일을 내린 직후학교장 전형 학교 한정개별추가로 대체 가능

    입학 대상자 파일로 일괄 추가

    학교장 전형으로 시행하는 학교에서 사용하는 방법입니다. 입학대상자 명단 파일을 이용하여 일괄 등록하는 방식으로 동명이인 학생은 특별히 유의하여 처리합니다. 등록된 학생이 본교 입학대상자가 아닐 경우 {삭제} 합니다.

    언제?
    학년말, 고교입학시스템에서 합격자 명단 파일을 다운로드한 뒤
    누가?
    입학 업무담당자
    어디서?
    [입학-입학관리-입학대상자관리]
    무엇을
    어떻게?
    [입학-입학관리-입학대상자관리]에서 '입학예정 학년도'와 조회 조건 확인하고 {조회} 하여 {재학생} 탭에서 {일괄추가} 함 → '일괄추가' 창의 '입학담당자정보'에서 '성명', '연락처' 입력 후 '입학대상자파일 올리기'에서 {찾아보기} 하여 업로드할 파일을 선택하고 {작업실행} 함 → '입학정보'에서 '과정', '계열', '학과' 선택하여 {조회} 후 '학생목록'에서 일괄 추가할 학생을 선택(Shift + 마우스를 클릭하면 연속으로 선택 가능, Ctrl + 마우스를 클릭하면 비연속으로 선택 가능)하여 추가하고 {저장} 함.
    왜?
    합격자 명단을 한 번에 올려 신입생 예비 학적의 출발 자료를 정확한 과정·계열·학과에 붙여 두려고.

    실무 메모 — 파일과 등록 방식

    • 학교장 전형인 지역의 학교에서는 {개별추가} 또는 {일괄추가}를 이용하여 입학 대상자를 직접 등록함. 등록된 학생이 본교 입학대상자가 아닐 경우 {삭제} 함.
    • 업로드할 파일은 배정할 학과별 또는 소단위로 나누어 각각 업로드하는 것이 편리함.
    • 파일 형태는 출신학교코드, 성명, 반코드, 번호, 학년 순으로 반코드는 반드시 2자리로 구성되어야 하며, 파일 내용 중 학년을 생략할 경우 3학년으로 등록됨.
    • [시스템관리-코드관리-학교정보조회]에서 {타학교코드조회}로 검색하면 출신 중학교의 나이스코드를 직접 확인할 수 있음.

    실무 메모 — 창의 버튼과 오류 처리

    • {찾아보기}는 일괄추가 할 입학 대상자 파일을 선택함.
    • {작업실행}은 입학 대상자의 출신학교 조회 후 목록에서 보여줌.
    • {샘플다운로드}는 입학 대상자 파일을 다운로드 받아 입력 내용을 확인함.
    • {조회}는 입학 대상자 목록을 조회함.
    • '학생목록'의 '존재여부'란에 '미존재'로 표시된 학생은 해당 출신학교에서 학생을 찾을 수 없는 경우이며, 이 경우 오른쪽으로 자료가 이동되지 않음('미존재'로 남는 경우 학생정보가 잘못된 경우일 수 있으므로 {개별추가}를 이용하여 해당 학생이 검색되는지 여부를 확인함).
    • {주간/계열/학과일괄변경}은 {일괄추가} 시 '입학정보'를 잘못 등록한 경우 입학생들의 입학정보를 한 번에 변경하는 기능임.

    배정자료 확인 후, 누락자 확인 시점교육감 전형·학교장 전형 공통

    재학생 입학 대상자 개별 추가

    시·도교육청 배정자료에 들어오지 않은 학생을 한 명씩 등록하는 업무임. 소규모 입학생, 해당 학교에 배정된 특수학생, 검정고시 학생, 별도로 배정된 체육특기생 등이 대상이며 평준화지역 재배정 결과 반영도 이 방식으로 처리함. 현재 학년도 중학교 3학년 학생은 졸업 처리를 완료했어도 {재학생} 탭에서 검색하여 등록함.

    언제?
    학년말, 교육청 배정자료 확인 후 누락 대상자가 파악된 뒤
    누가?
    입학 업무담당자
    어디서?
    [입학-입학관리-입학대상자관리]
    무엇을
    어떻게?
    [입학-입학관리-입학대상자관리]에서 '입학예정 학년도'와 조회 조건 확인하고 {조회}하여 {재학생} 탭에서 {개별추가} → '개별추가' 창의 '입학담당자 정보'에서 '성명', '연락처' 입력 → '학생찾기'에서 {학교찾기}로 출신중학교를 검색 → '학년', '반', '성명'으로 {학생찾기} → '입학정보'에서 '과정', '계열', '학과' 선택 → '학생목록'에서 학생 선택하여 {추가}하고 {저장}함.
    왜?
    배정자료만으로는 빠지는 학생이 생기므로, 실제 입학할 학생 전원을 명부에 올려 어느 한 명도 학적 없이 남지 않게 하려고.

    실무 메모

    • 평준화지역 재배정 결과 반영은 [입학-입학관리-입학대상자관리]에서 {개별추가} 또는 {일괄추가}로 직접 등록함.
    • {삭제}하여 입학 대상자 중 입력 오류 건을 삭제할 수 있으며, {삭제} 시 지원학교의 배정 결과도 삭제됨. 단 시·도교육청에서 전송한 정보는 삭제가 불가능하므로 본교 입학 대상자가 아니라면 '본교확인'을 '비대상'으로 설정함.

    입학 대상자 등록 시점이전 학년도 졸업생이 있는 학교만

    이전 학년도 졸업생 입학 대상자 추가

    이전 학년도에 중학교를 졸업한 학생이 입학하는 경우에만 해당함. 이전 학년도 졸업생은 교육감 전형이라도 시·도교육청에서 전송되지 않으므로 해당 학교에서 {졸업생} 탭에서 검색하여 추가함. 재학생 검색으로는 찾을 수 없어 절차가 따로 갈림.

    언제?
    학년말, 입학 대상자 명단에서 이전 학년도 졸업생을 확인한 뒤
    누가?

    어디서?
    [입학-입학관리-입학대상자관리]

    어떻게?

    입학 대상자 등록 시점검정고시 합격자·학력인정 학교 출신자가 있는 학교만

    전송요청 후 자료 도착 대기 중교육감 전형 위주

    출신교 미확인·미도착 학생 확인

    입학 대상자로 등록하고 전송요청까지 마쳤는데도 출신 중학교에서 자료가 오지 않은 학생을 걸러내는 업무입니다. ‘출신교상태’가 ‘미확인’인 입학 대상자의 출신 중학교의 업무 진행 상태를 확인함. 학적일괄생성 전에 미도착 건을 정리해 두어야 합니다.

    언제?
    학년말, 입학 대상자 등록과 전송요청을 마쳐 배정자료가 도착하기를 기다리는 시점.
    누가?
    입학 업무담당자
    어디서?
    [입학-입학관리-입학대상자관리]
    무엇을
    어떻게?
    [입학-입학관리-입학대상자관리]에서 ‘입학예정 학년도’와 조회 조건 확인하고 ‘자료도착’을 ‘미도착’으로 선택하여 {조회} → {전체출력} → ‘비고’에서 출신 중학교의 미도착 사유를 확인함.
    왜?
    자료가 오지 않은 이유를 출신 중학교별로 짚어 두어야 학적 생성 전에 해당 중학교에 다시 요청해 빠진 학생 없이 신입생 자료를 갖출 수 있습니다.

    실무 메모

    • ‘출신교상태’는 입학 대상자의 출신중학교 확인 상태를 뜻함.
    • 확인 — 출신학교에서 입학 대상자의 배정학교와 학적사항을 확인한 상태임.
    • 미확인 — 출신학교에서 미확인한 경우로 {전체출력}하면 출신교의 작업 상태가 출력됨. 예시로 출신학교가 사전일괄승인을 설정하지 않았거나 [진로지도-동의여부마감관리]에서 진로정보 학생동의서 학년 마감 또는 건강기록부 마감을 하지 않은 경우가 있음.
    • 오류 — 출신학교 입학 대상자의 배정 학교나 인적·학적사항이 잘못되었음을 나타냄(‘오류’ 글자 위에 마우스를 올리면 출신학교에서 작성한 오류 사유를 확인할 수 있음).

    어디서?

    무엇을
    어떻게?
    '진급학년도' 확인 후 '반편성기준'을 '파일업로드'로 선택 → '1. 반편성자료 생성'하여 '자료내리기'에서 '학생구분 : 입학생'으로 선택 후 {내리기} → 다운로드한 파일을 열어 자료 입력('진급반코드', '진급반번호') → '자료올리기'에서 '학생구분 : 입학생' 선택 후 {찾아보기}하여 입학생의 반편성자료 파일을 선택 → {올리기} 함.
    왜?
    입학 성적순 등으로 미리 정해 둔 학급 배정을 신학년도 학적에 그대로 옮겨 담기 위함.

    실무 메모

    • '일괄반편성' 후 '개별반편성'에서 일괄 반편성 내역 중 일부를 수정하거나, 개별로 반 편성할 수 있음(동명이인 확인).

    타임라인으로 돌아가기

    12D
    일괄 반편성 직후 또는 학년말업무 11로 대체 가능

    직접 등록하는 개별 반편성

    파일을 쓰지 않고 화면에서 학생마다 반을 지정하는 방식입니다. 인원이 적은 학교에서 처음부터 쓸 수도 있고, 업무 11의 일괄 반편성 결과 중 일부만 고쳐야 할 때도 이 화면에서 수정합니다. 동명이인이 있는지도 이 화면에서 확인합니다.

    언제?
    학년말, 입학생 학적이 생성된 뒤. 일괄 반편성을 했다면 그 직후.
    누가?
    반편성 업무담당자
    어디서?
    [학적-진급대상자반편성관리-진급대상자반편성관리-개별반편성]
    무엇을
    어떻게?
    {입학생반편성내역개별등록} 탭에서 '진급학년도' 확인 후 {조회}하여 입학생들의 '진급반' 선택하고 {저장} 함.
    왜?
    일괄 처리로 걸러지지 않는 소수 인원과 동명이인을 사람 손으로 확인해 학급 배정 오류를 남기지 않기 위함.

    실무 메모

    • '일괄반편성' 후 '개별반편성'에서 일괄 반편성 내역 중 일부를 수정하거나, 개별로 반 편성할 수 있음(동명이인 확인).

    타임라인으로 돌아가기

    13D
    반편성 완료 후

    학생 반 번호 부여 및 수정

    반편성이 끝난 학생에게 학급 내 번호를 매기는 업무입니다. '성명순 / 주민등록번호순' 중 '부여기준'을 정해 일괄로 부여한 뒤, {결과조회}의 '변경번호'에서 개별 수정합니다. 반편성 결과를 학생에게 알릴 때는 개인정보 유출에 특히 주의합니다.

    언제?
    학년말, 일괄 반편성 또는 개별 반편성으로 진급반 지정이 끝난 뒤.
    누가?
    반편성 업무담당자
    어디서?
    [학적-진급대상자반편성관리-진급대상자반편성관리-반번호부여]
    무엇을
    어떻게?
    '진급학년도' 확인 후 {조회}하여 '진급학년', '남녀구분', '부여기준(성명순/주민등록번호순)' 설정 → {작업실행}하여 {확인} 후 {확인} → {결과조회}하여 '반번호수정' 창에서 '진급학년도' 확인 후 '학년', '반'을 선택하고 {조회} → '변경번호'에 반번호를 수정 후 {저장} 함.
    왜?
    신학년도 출결과 성적 등 모든 학생 자료가 붙을 학급 내 번호를 확정하기 위함.

    실무 메모

    • {결과조회}에서 {동명이인}을 클릭하여 동명이인의 반편성 내역을 확인하고 같은 학급인 경우 반편성 내역을 수정할 수 있음.

    개인정보 보호

    • 반편성 결과를 학생들에게 배부하여 확인할 경우 학생의 개인정보가 공개적으로 유출되지 않도록 파일로 다운로드하여 '기준성적'을 삭제한 후 활용하되, 전체학급 홈페이지 게시 금지.

    타임라인으로 돌아가기

    14D
    반 번호 부여 후, 학교생활기록부·건강기록부 마감 후

    진급자 학적반영

    반편성과 반 번호 부여를 마친 진급대상자를 신학년도 학적으로 확정하는 마지막 업무입니다. 학교생활기록부와 건강기록부가 마감되어 있어야 {승인요청}이 가능합니다. 반영은 3학년부터 1학년 순서로 진행합니다.

    언제?
    학년말, 반편성과 반 번호 부여가 끝나고 학교생활기록부와 건강기록부 마감이 완료된 뒤.
    누가?
    학적 업무담당자
    어디서?
    [학적-진급대상자반편성관리-진급대상자반편성관리-진급자학적반영]
    무엇을
    어떻게?
    '진급학년도' 확인 후 {조회}하여 {학적미반영자료조회}, {반편성/반번호미부여자조회}, {유급대상자조회}하여 이상 유무 파악 → '학적반영일자'를 확인하고 3학년부터 1학년 순서로 {승인요청} → {학적반영} 함.
    왜?
    신학년도 학적과 통계가 시작되는 기준점을 확정해 새 학년 업무를 정상적으로 시작할 수 있게 하기 위함.

    실무 메모

    • 학교생활기록부와 건강기록부가 마감되어 있어야 진급자 학적반영을 위한 {승인요청}이 가능함.
    • '학적미반영자료조회'에서 미반영된 학적 변동자의 성명, 학적 변동명, 상태(자료 도착 여부)를 조회할 수 있음.
    • '반편성/반번호미부여자조회'는 진급자 반편성 및 반 번호 미부여자를 알 수 있으며 기안문이 상신되었을 경우, '결재상태'에 마우스를 가져가면 기안자 정보가 표시됨.
    • {학적반영} 후 결재가 완결되면 '결재상태'에 {학적반영}이 나타나고, 학적반영이 되었을 경우에는 {학적반영취소}가 나타남.

    학적반영일자 주의

    • {학적반영일자수정}으로 학적반영일자를 수정할 경우 신학년도 해당 월의 '월출결마감'을 다시 해야 함. 진급자 학적반영일자부터 신학년도의 모든 통계자료가 생성되기 때문에 정확한 학적반영일자를 입력함.
