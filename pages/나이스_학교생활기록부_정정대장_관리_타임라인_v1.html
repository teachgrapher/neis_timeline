      08C
      정정대장 작성 전이전학년도 성적 정정 시에만

      기준년도/학기 변경 후 이전학년도 성적 재처리

      이전학년도 성적을 정정해야 하는 경우에만 해당하는 준비 작업입니다. 성적은 정정대장에서 직접 고칠 수 없으므로 기준년도/학기를 정정할 학년도·학기로 되돌려 성적을 재처리한 뒤 현재 학년도로 다시 바꿔놓아야 합니다. 이 작업을 거친 과목만 이후 이전년도성적자료반영에서 조회됩니다.

      언제?
      연중, 학업성적관리위원회 심의를 거친 뒤 정정대장 작성에 앞서
      누가?
      업무담당교사
      어디서?
      [학교정보-학교정보-기준년도/학기관리]
      무엇을
      어떻게?
      ‘교무/수업학년도’와 ‘교무/수업학기’를 정정학년도/학기로 설정 → 성적을 재처리 → 현재 학년도로 변경 → 학교생활기록부 정정대장을 작성함.
      왜?
      성적 원자료를 정정 시점 기준으로 다시 산출해 두어야 정정 내용이 학교생활기록부에 실제 성적으로 반영되기 때문입니다.

      실무 메모

      • 이전학년도 학교생활기록부 보조부(각종 누가기록)의 수정은 불가능함. 단, 이전 학년도 성적의 경우 [학교정보-기준년도/학기관리]에서 ‘교무/수업학년도’와 ‘교무/수업학기’를 정정학년도/학기로 설정한 후 성적을 재처리하고, 현재 학년도로 변경 후 학교생활기록부 정정대장을 작성함.
      • 이전년도 성적자료반영에 조회되는 과목은 과년도의 성적을 재산출한 과목만 조회됨.

      09C
      성적 재처리 직후재학생만 가능

      이전학년도 성적 자료 반영

      이전학년도 성적을 재산출한 과목을 학교생활기록부에 다시 반영할 때 사용합니다. 재학생에 대해서만 작성이 가능하며, 재학 아닌 학생은 [학생부-정정대장관리-정정대장작성]에서 교과학습발달상황으로 편제를 수정해야 합니다. 반영 후에는 승인요청을 거쳐 최종결재권자의 결재까지 완료해야 합니다.

      언제?
      연중, 기준년도/학기를 되돌려 이전학년도 성적을 재처리한 뒤
      누가?
      업무담당교사
      어디서?
      [학생부-정정대장관리-이전년도성적자료반영]
      무엇을
      어떻게?
      ‘학년도’ 확인 후 ‘계열/학년/학과’, ‘반’을 선택하고 {조회} → 해당 학생 클릭 후 {2. 이전년도성적반영} 하여 {확인} → ‘성적반영 과목 선택’에서 과목을 선택하여 ‘심의일자’, ‘오류내용’, ‘정정내용’, ‘정정사유’ 입력 → 반영 과목, 반영 학생 선택 후 {학생부반영} → {3. 승인요청}으로 기안문 상신을 통해 최종결재권자의 업무승인을 완료함.
      왜?
      재산출한 이전학년도 성적을 심의 결과와 함께 정식 정정 이력으로 남겨 학교생활기록부의 성적 기록을 사실과 맞추기 위해서입니다.

      실무 메모

      • 이전년도 성적자료반영에 조회되는 과목은 과년도의 성적을 재산출한 과목만 조회됨.
      • 이전년도 성적자료반영은 재학생에 대해서만 작성이 가능하며, 재학아닌 학생은 [학생부-정정대장관리-정정대장작성]에서 교과학습발달상황으로 편제를 수정해야 함.

      결재·반영 관련

      • [학생부-정정대장관리-정정대장작성]에서 {4. 승인요청} 후 결재경로를 지정하고 {상신}하여 업무승인과정을 거쳐 결재권자의 결재가 완료되면 정정한 내용이 자동으로 학교생활기록부에 반영됨.
      • 학교생활기록부 정정대장의 결재경로는 ‘담임(담당) → 담당부장 → 교감 → 교장’의 4단 결재를 거치며 대결 또는 전결로 처리하지 않음(학교장 결재 필수).
      • 결재 진행 중인 정정대장은 수정, 삭제를 할 수 없으며, 정정대장 상세조회만 가능함.

      01A
      학업성적관리위원회 심의 직후학업중단학생은 '재학아닌학생' 선택

      학교생활기록부 정정대장 등록

      재학생의 이전학년도 학교생활기록부에 오류가 확인된 경우에 시작하는 첫 단계다. 인적･학적사항의 학생정보 정정을 제외한 모든 정정은 학업성적관리위원회 심의 절차를 먼저 거쳐야 한다. 앞선 정정 건의 결재가 아직 끝나지 않은 학생은 새 정정대장을 등록할 수 없으므로 미상신 내용을 먼저 확인한다.

      언제?
      연중, 학업성적관리위원회 심의를 마친 뒤
      누가?
      학급담임교사, 업무담당교사
      어디서?
      [학생부-정정대장관리-정정대장작성]
      무엇을
      어떻게?
      '반별조회' 선택 후 '학년도', '학년', '반'을 확인하고 {조회} → 정정할 학생을 클릭하여 미상신된 내용이 있는지를 확인하고 {2. 정정대장등록} 탭을 선택 → '정정 항목 선택' 후 '심의일자', '오류내용', '정정내용', '정정사유'를 입력과 '공개여부' 설정 후 {저장}
      왜?
      심의를 거친 정정 사유와 근거를 법정장부에 먼저 남겨, 뒤따르는 학생부 수정이 승인 절차 위에서만 이루어지도록 하려고.

      실무 메모

      • 학교생활기록부 정정대장을 작성한 후 해당 정정 건의 업무승인과정으로 결재권자의 결재가 완료되지 않으면 해당 학생에 대해 새로운 학교생활기록부 정정대장 등록이 불가능함.
      • 같은 내용으로 여러 학생의 학교생활기록부 정정대장을 등록할 경우 {2. 정정대장등록} 탭에서 대상 학생들을 동시에 선택하여 작성 가능함.
      • 공개여부는 인적･학적사항, 출결상황, 행동특성및종합의견인 경우에만 선택할 수 있음.
      • 학업중단학생의 정정대장을 등록할 때는 '재학아닌학생'을 선택하고 작성함.

      02A
      정정대장 등록 직후한 항목씩 진행

      학교생활기록부 항목별 정정

      정정대장을 등록한 학생에 대해 실제 학교생활기록부 내용을 고치는 단계다. 여러 항목을 정정해야 하면 한 항목의 정정대장이 결재 완료된 뒤에 다음 항목의 정정대장을 작성한다. 이전학년도 누가기록 등 보조부는 참고자료여서 정정 또는 수정이 불가하다.

      언제?
      연중, 해당 학생의 정정대장 등록을 마친 뒤
      누가?
      학급담임교사, 업무담당교사
      어디서?
      [학생부-정정대장관리-정정대장작성]
      무엇을
      어떻게?
      '반별조회' 선택 후 '학년도', '계열/학년/학과', '반'을 확인하고 {조회} → 정정대장을 작성한 학생 클릭 후 {3. 항목별정정}을 선택하여 정정할 자료 선택 후 '특기사항'에서 오류 내용을 수정하고 {저장}
      왜?
      심의로 확정된 정정 내용을 원본에 반영하면서 원본과 정정 이력을 함께 남겨, 무엇이 어떻게 바뀌었는지 추적할 수 있게 하려고.

      실무 메모

      • 원본 항목을 수정하여 {저장}하면 수정한 원본 밑에 정정 이력이 등록됨.
      • 정정한 후 반드시 {정정내역확인}을 통해 정정하고자 하는 사항이 모두 정상적으로 등록되었는지 확인 후 {승인요청}해야 함.
      • 여러 항목을 정정해야 할 경우 한 항목에 대해 학교생활기록부 정정대장을 상신하여 업무승인과정을 거쳐 결재권자의 결재가 완료된 후 다른 항목에 대한 학교생활기록부 정정대장을 작성함.
      • 결재 진행 중인 정정대장은 수정, 삭제를 할 수 없으며, 정정대장 상세조회만 가능함.

      정정할 수 없는 것

      • 이전학년도 학교생활기록부 보조부(각종 누가기록)의 수정은 불가능함. 동아리 활동 시간은 정정 가능하지만, 동아리 활동 누가기록은 참고자료이므로 정정 또는 수정이 불가함.
      • 결재 및 반영까지 완료한 정정대장의 수정은 나이스에서 되지 않음. 심의일자를 잘못 입력했다면 정정대장을 출력하여 수기문서 정정절차에 따라 진행한 후 별도로 보관하여 관리함.
      • 나이스에는 2002년 이후 졸업생부터 학교생활기록부 자료가 있음. 전산 이관하지 않은 졸업생은 수기 장부로 정정을 진행함.

      03A
      항목별 정정 저장 후학교장 결재 필수{개인결재선} 활용 권장

      정정대장 기안문 상신

      항목별 정정까지 마친 뒤 결재를 받아 정정 내용을 확정하는 단계다. 결재경로는 '담임(담당) → 담당부장 → 교감 → 교장'의 4단 결재이며 대결 또는 전결로 처리하지 않는다. 결재권자의 결재가 완료되면 정정한 내용이 자동으로 학교생활기록부에 반영된다.

      언제?
      연중, 항목별 정정을 저장하고 {정정내역확인}을 마친 뒤
      누가?
      학급담임교사, 업무담당교사
      어디서?
      [학생부-정정대장관리-정정대장작성], [상신함]
      무엇을
      어떻게?
      '반별조회' 선택 후 '학년도', '계열/학년/학과', '반'을 확인하고 {조회} → 정정대장을 작성한 학생 클릭 후 {4. 승인요청}을 선택 → '기안문서상신' 창에서 {결재자지정}하여 '결재선'을 확인한 후 '내용'을 입력하고 하단의 기안내용을 선택하여 {상신}
      왜?
      학교장까지의 결재로 정정의 정당성을 확인받은 뒤에만 학생부 원본이 바뀌게 하여, 기록의 신뢰를 지키려고.

      결재선 규정

      • 학교생활기록부 정정대장의 결재경로는 '담임(담당) → 담당부장 → 교감 → 교장'의 4단 결재를 거치며 대결 또는 전결로 처리하지 않음(학교장 결재 필수). 부득이한 경우 해당 건의 정정을 위한 학업성적관리위원회 참석 위원 중 학교장이 정한 자를 포함하여 4단 결재를 실시함.
      • 4단 결재가 부득이한 경우란 교감 미배치교, 담임과 담당부장이 동일인인 경우 등이며 장기 연수, 출장 등의 사유에 따른 장기간 공석은 결재가 부득이한 경우에 해당되지 않음. 4단 결재가 불가능한 경우는 모든 학업성적관리위원회 참석 위원 인원을 결재 단계에 포함하였음에도 교원 수의 부족으로 불가능한 경우임.
      • 담당부장은 학교생활기록부 업무를 관리하는 부서장이며, 결재 단계에 동일인이 2회 이상 포함되는 것을 금지함.
      • [상신함]에서 {개인결재선등록}으로 업무 영역별 결재자를 지정하여 등록해 두고, 해당 메뉴에서 {승인요청} 시 {개인결재선}을 활용하면 빠르고 편리하게 결재자를 지정할 수 있음.

      상신 전후 확인

      • 기안문서 상신 화면에서 결재 항목을 선택하여 이미 작성된 학교생활기록부 정정대장 내용 및 수정한 항목에 대한 정정내역과 학교생활기록부의 현재 내역을 조회하여 정정하고자 하는 사항이 모두 정상적으로 등록되었는지 확인 후 {상신}함.
      • [학생부-정정대장관리-정정대장작성]에서 {4. 승인요청} 후 결재경로를 지정하고 {상신}하여 업무승인과정을 거쳐 결재권자의 결재가 완료되면 정정한 내용이 자동으로 학교생활기록부에 반영됨.
      • 학교별 정정건수가 나이스에서 자동집계 되고, 시도교육청에서도 확인 가능함.
      • 이전 학년도 성적의 경우 [학교정보-기준년도/학기관리]에서 '교무/수업학년도'와 '교무/수업학기'를 정정학년도/학기로 설정한 후 성적을 재처리하고, 현재 학년도로 변경 후 학교생활기록부 정정대장을 작성함.

      • 이전학년도 학교생활기록부 보조부(각종 누가기록)의 수정은 불가능함. 동아리 활동 시간은 정정 가능하나 동아리 활동 누가기록은 참고자료이므로 정정 또는 수정이 불가함.
      • 나이스에서는 2002년 이후 졸업생부터 학교생활기록부 자료가 있으며, 전산 이관하지 않은 경우에는 수기 장부로 정정을 진행함.
      • 졸업 후 8년이 지나 학생부 보존으로 이관된 졸업생은 [학생부보존-보존자료이관관리-보존자료생성]-{추가반영대상생성} 탭에서 해당 학년도 {등록} 후 [보존자료이관] 메뉴에서 추가 반영 건 승인요청하고 완결 후 자료 이관한 다음 정정을 진행함.

      11D
      결재 완료 후항목별·개인별 탭 선택

      정정대장 이력 조회 및 엑셀 다운로드

      정정 이력을 항목 기준 또는 학생 개인 기준으로 나누어 보고, 필요하면 파일로 내려받는 업무입니다. {항목별} 탭과 {개인별} 탭 중 무엇을 보려는지에 따라 탭을 먼저 선택하고 '정정일자'와 '항목'으로 범위를 좁힙니다. 개인정보가 포함된 파일이므로 다운로드 시 사유 입력이 필요합니다.

      언제?
      연중, 정정 건의 결재가 완료된 뒤
      누가?
      업무담당교사
      어디서?
      [학생부-정정대장관리-정정대장이력조회]
      무엇을
      어떻게?
      [학생부-정정대장관리-정정대장이력조회]에서 {항목별} 탭 또는 {개인별} 탭을 선택하고 '학년도' 확인 후 '정정일자', '항목'을 선택하여 {조회} → '엑셀다운로드'를 클릭하여 개인정보 포함 파일 다운로드 사유 입력하고 {제출} 후 '엑셀', '한셀', 'CSV'에서 선택하여 {확인}함.
      왜?
      어느 항목에서 어떤 정정이 얼마나 이루어졌는지 학교 차원에서 점검하려고.

      실무 메모

      • '엑셀다운로드'는 개인정보 포함 파일이므로 다운로드 사유를 입력하고 {제출}해야 내려받을 수 있음.
      • 저장 형식은 '엑셀', '한셀', 'CSV' 중에서 선택함.
      • 결재 진행 중인 정정대장은 수정, 삭제를 할 수 없으며, 정정대장 상세조회만 가능함.

      10D
      학년말법정장부

      학교생활기록부 정정대장 조회 및 출력

      결재가 완료되어 학교생활기록부에 반영된 정정 건을 학년도 단위로 모아 확인하고 종이 장부로 남기는 업무입니다. 학교생활기록부 정정대장은 졸업대장과 마찬가지로 법정장부이므로 학년말에 반드시 출력하여 증빙서류와 합철 후 수기 결재를 득하여 준영구 보관해야 합니다. 개별 정정 건의 원본 내역과 수정 내역을 비교해 보려면 {상세조회}를 이용합니다.

      언제?
      연중 조회 가능하며, 정정 건의 결재가 완료된 뒤. 보관용 출력은 학년말
      누가?
      업무담당교사
      어디서?
      [학생부-정정대장관리-정정대장조회]
      무엇을
      어떻게?
      [학생부-정정대장관리-정정대장조회]에서 '학년도' 확인 후 '정정일자'를 설정하여 {조회} → {출력}을 선택하여 저장 또는 출력하거나, {상세조회}에서 '정정내용'을 클릭하여 '정정대장 상세 이력 조회' 창에서 원본 내역과 수정 내역을 확인함.
      왜?
      정정 사실을 학년도 단위 법정장부로 증빙서류와 함께 남겨 준영구 보존하려고.

      실무 메모

      • 학교생활기록부 정정대장은 졸업대장과 마찬가지로 법정장부이므로 학년말에 반드시 출력하여 증빙서류와 합철 후 수기 결재를 득하여 준영구 보관하되 기록물이 훼손되지 않도록 유의해야 함.
      • 학교생활기록부 정정대장을 출력하면 '결재 및 입력확인'란에 기안자 및 결재자의 이름이 표기되어 있으므로 겉표지에만 결재를 득함.
      • 학교생활기록부 정정대장은 학년도 단위로 작성하며 졸업생과 재학생을 함께 작성하여 증빙서류와 합철하여 보관함. 학년도 단위로 일련번호가 부여되며 졸업생의 경우 졸업대장번호가 병기됨.
      • [학생부-정정대장관리-정정대장공개여부관리]에서 결재권자의 결재가 완료된 학교생활기록부 정정대장의 '공개 여부' 수정이 가능함(공개여부 이외의 항목은 수정 불가).
      • 학교별 정정건수가 나이스에서 자동집계 되고, 시도교육청에서도 확인 가능함.
