    01A
    졸업장 출력 전서식구분별 등록

    졸업장 · 수료장 · 명예졸업장 양식 등록과 편집

    졸업 · 수료 관리에서 가장 먼저 손대는 준비 작업이다. 졸업장이나 수료장을 출력하기 위해서는 [학적-졸업/수료관리-졸업장/수료장/명예졸업장양식관리]에서 졸업장이나 수료장을 먼저 등록해야 함. 서식문구는 학교마다 다를 수 있으므로 우리 학교 문구로 등록하고 미리보기로 확인한다.

    언제?
    학년말, 졸업 · 수료장 출력에 앞서 미리 등록해 두는 시점.
    누가?
    학적 업무담당자
    어디서?
    [학적-졸업/수료관리-졸업장/수료장/명예졸업장양식관리]
    무엇을
    어떻게?
    '서식구분' 선택 후 {등록} 함 → '서식명', '서식문구', '수여자명' 입력하고 {저장} 하면 우측에 미리보기로 졸업장 양식이 나타남.
    왜?
    실제 증서 용지에 인쇄될 문구와 글자 위치를 학교 기준에 맞춰 확정해 두어, 졸업식 직전에 출력물을 다시 손보지 않으려고.

    실무 메모

    • '서식구분'에는 '졸업장', '수료장', '명예졸업장'을 선택할 수 있으며, 서식문구는 학교마다 다를 수 있음.
    • {양식편집} 으로 졸업장의 서식을 학교 상황에 맞게 세부적으로 설정할 수 있음.
    • {크게보기} 로 '졸업장/수료장/명예졸업장' 양식을 PDF, 워드, 엑셀, 파워포인트, 한글 문서로 저장하거나 출력할 수 있음.

    양식편집 설정 범위

    • 설정 가능 항목 — 서식번호, 서식명, 학과, 학생성명, 생년월일, 서식문구, 일자, 수여자명.
    • 서식 기능 — 폰트명(궁서체, 굴림체, 돋움체, 맑은 고딕, 바탕체, HY견고딕), 크기, 속성(없음, Bold, StrikeOut, Underline, Italic), 색상(검정, 빨강, 파랑, 노랑), 정렬(왼쪽, 가운데, 오른쪽), 가로 위치(X), 세로 위치(Y), 넓이, 높이.

    02B
    졸업/수료대상자 생성 전조기졸업 대상자가 있는 학교만

    조기졸업자 등록과 진학학교 지정

    조기졸업 대상자가 없는 학교에서는 이 메뉴를 사용하지 않는다. 조기졸업 대상자는 2학년 학생만 등록할 수 있다. 등록한 학생은 현재 3학년 졸업 대상자에 포함되어 졸업 처리가 진행된다.

    언제?
    학년말, 학교생활기록부와 건강기록부 마감이 완료된 뒤 졸업/수료대상자를 생성하기 전
    누가?
    학적 업무담당자
    어디서?
    [학적-졸업/수료관리-조기졸업자관리]
    무엇을
    어떻게?
    '졸업학년도' 확인 후 {조회}하고 {등록}함 → '조기졸업자 등록' 창에서 '졸업학년도' 확인 후 '학년', '반'을 선택하고 {조회}함 → 조기졸업 대상 학생을 선택하고 '진학학교'를 등록하기 위해 {학교찾기}로 진학학교를 등록하고 {저장} 후 {닫기}함.
    왜?
    학칙에 따라 2년만 이수하고 나가는 학생을 3학년 졸업 대상자와 같은 절차로 졸업시키고 진학할 학교까지 학적에 남기려고.

    실무 메모

    • {학교찾기}를 클릭하면 나타나는 '학교찾기' 창에서 '시도교육청구분' 선택, '학교명' 입력 후 {조회}하여 목록에서 진학학교를 클릭하고 {확인}함.
    • {삭제}로 기등록된 조기졸업 대상자를 선택하여 삭제할 수 있음.
    • 조기졸업 대상자는 2학년 학생만 등록할 수 있음.
    • 조기졸업 대상자로 등록된 학생은 현재 3학년 졸업 대상자에 포함되어 졸업 처리를 할 수 있음.

    근거 법령

    • 조기진급 및 조기졸업에 대한 근거는 「초·중등교육법」 제27조(조기진급 및 조기졸업 등), 같은 법 시행령 제9조(학교규칙의 기재사항 등) 제1항제5호, 제53조(조기진급·조기졸업 등), 「조기진급 등에 관한 규정」에 의함.

    03B
    졸업/수료대상자 생성 전수료대상자가 있는 학교만

    수료대상자 등록

    수료대상자가 없는 학교에서는 이 메뉴를 사용하지 않는다. '수료자 등록' 창에서 등록 가능 학년은 2·3학년이다. 수료대상자로 등록된 학생은 현재 3학년 졸업 대상자에서 제외되어 졸업처리를 할 수 없다.

    언제?
    학년말, 학교생활기록부와 건강기록부 마감이 완료된 뒤 졸업/수료대상자를 생성하기 전
    누가?
    학적 업무담당자
    어디서?
    [학적-졸업/수료관리-수료자관리]
    무엇을
    어떻게?
    '졸업학년도' 확인 후 {조회}하여 {등록}함 → '수료자 등록' 창에서 '졸업학년도' 확인 후 '학년', '반'을 선택하고 {조회}함 → 수료대상 학생을 선택 후 {저장}하고 {닫기}함.
    왜?
    졸업 요건을 채우지 못한 학생을 졸업자와 갈라 놓아 졸업대장이 아닌 수료대장으로 관리하려고.

    실무 메모

    • '수료자 등록' 창에서 등록 가능 학년은 2·3학년임.
    • 수료대상자로 등록된 학생은 현재 3학년 졸업 대상자에서 제외되어 졸업처리를 할 수 없음.
    • {삭제}로 기등록된 수료대상자를 선택하여 삭제할 수 있음.
    • 수료대상자가 없는 학교에서는 [학적-졸업/수료관리-수료자관리]를 사용하지 않음.

    04B
    조기졸업자·수료대상자 등록을 끝낸 뒤

    졸업 / 수료대상자 생성

    조기졸업자와 수료대상자 등록을 마친 뒤 한 번 실행하는 업무다. 등록한 두 명단을 목록에서 확인하고 생성하면 조기졸업자, 수료대상자, 정상졸업자가 한꺼번에 만들어진다. 졸업/수료대상자를 생성하면 [조기졸업자관리]와 [수료자관리]에서 더 이상 대상자를 등록할 수 없다.

    언제?
    학년말, 조기졸업자관리와 수료자관리에서 대상자 등록을 완료한 뒤
    누가?
    학적 업무담당자
    어디서?
    [학적-졸업/수료관리-졸업/수료대상자관리]
    무엇을
    어떻게?
    '졸업학년도', '졸업구분' 확인 후 {조회}함 → [학적-졸업/수료관리-조기졸업자관리]와 [학적-졸업/수료관리-수료자관리]에서 등록한 조기졸업자와 수료대상자를 목록에서 확인하고 {생성}함 → '졸업/수료대상자 생성' 창에서 '졸업학년도' 확인 후 {작업실행}하고 {확인}하여 조기졸업자, 수료대상자, 정상졸업자를 생성함.
    왜?
    흩어져 등록된 명단을 하나의 확정 명단으로 굳혀 대장번호 부여와 학적반영이 같은 대상자를 보고 돌아가게 하려고.

    실무 메모

    • '졸업구분'은 '전체', '정상졸업', '조기졸업', '수료' 중에서 선택할 수 있음.
    • [학적-졸업/수료관리-졸업/수료대상자관리]에서 등록한 수료대상자가 없는 경우 [졸업/수료대상자관리]에서 조회 시 목록에는 공란으로 나타남.
    • {작업실행} 시 조기졸업 대상자도 현재 3학년 졸업 대상자에 포함되어 생성됨.

    생성 후 상태 변화

    • 졸업/수료대상자를 생성하면 목록 위에 "☞ 졸업/수료대상자가 생성되었습니다."가 표시되고 {생성}이 {생성취소}로 변경되며, 필요시 {생성취소}할 수 있음.
    • 졸업/수료대상자를 생성하면 [조기졸업자관리]와 [수료자관리]에서 "☞ 졸업대상자가 생성되었습니다."가 표시되고 각각의 메뉴에서 조기졸업 대상자와 수료대상자를 등록할 수 없음.
    • {생성취소}로 기생성된 조기졸업 대상자, 정상졸업 대상자, 수료대상자를 삭제할 수 있음.

    05B
    등록·생성 직후 확인이 필요할 때세 메뉴 절차 동일

    조기졸업자 · 수료대상자 · 졸업/수료대상자 목록 출력

    세 메뉴 모두 절차가 같아 한 카드로 묶었다. 등록하거나 생성한 명단이 맞는지 종이나 파일로 대조할 때 쓴다. 어느 메뉴든 '졸업학년도' 확인 후 조회한 다음 출력하는 흐름이 같다.

    언제?
    학년말, 조기졸업자·수료대상자 등록이나 졸업/수료대상자 생성을 마친 직후
    누가?
    학적 업무담당자
    어디서?
    [학적-졸업/수료관리-조기졸업자관리] [학적-졸업/수료관리-수료자관리] [학적-졸업/수료관리-졸업/수료대상자관리]
    무엇을
    어떻게?
    해당 메뉴에서 '졸업학년도' 확인 후 {조회}하고 {출력}을 클릭하면 나타나는 창에서 내용을 확인하고 저장 또는 출력함.
    왜?
    대장번호를 부여해 되돌리기 어려워지기 전에 명단이 빠지거나 잘못 들어간 곳이 없는지 눈으로 대조하려고.

    어떤 목록을 언제 여는가

    • 조기졸업대상자 목록 — [학적-졸업/수료관리-조기졸업자관리]에서 {출력}. 2학년 조기졸업 대상자와 진학학교를 확인할 때 엶.
    • 수료대상자 목록 — [학적-졸업/수료관리-수료자관리]에서 {출력}. 졸업 대상자에서 빠지는 2·3학년 학생을 확인할 때 엶.
    • 졸업/수료대상자 목록 — [학적-졸업/수료관리-졸업/수료대상자관리]에서 {출력}. 생성 후 조기졸업자·수료대상자·정상졸업자가 모두 들어갔는지 확인할 때 엶.

    실무 메모

    • {출력}으로 목록을 PDF, 워드, 엑셀, 파워포인트, 한글 문서로 저장하거나 출력할 수 있음.
    • 조기졸업자 출력은 {출력}을 클릭하면 나타나는 '조기졸업대상자' 창에서 내용을 확인하고 저장 또는 출력함.

    06C
    졸업 / 수료대상자 생성 후

    졸업 / 수료대장번호 부여

    졸업 / 수료대상자 생성을 마친 모든 학교가 하는 업무입니다. 제공되는 부여 방식이 학교 기준과 맞지 않으면 가장 유사한 방식을 선택해 작업실행한 뒤 수정파일로 보완합니다. '졸업일자'는 [교육과정-학사일정관리-학사일정관리]의 {연간학사일정관리} 탭에 등록된 졸업일자가 자동 반영되고, 졸업식이 등록되어 있지 않으면 '2025.02.28.'로 반영되므로 반드시 확인이 필요함.

    언제?
    학년말, 졸업 / 수료대상자 생성이 끝난 뒤.
    누가?
    학적 업무담당자
    어디서?
    [학적-졸업/수료관리-졸업/수료대장번호부여]
    무엇을
    어떻게?
    [학적-졸업/수료관리-졸업/수료대장번호부여]에서 '졸업학년도', '졸업회차', '졸업대장시작번호', '수료대장시작번호', '졸업일자' 확인 → '졸업대장번호부여'를 학교 실정에 맞게 선택 → {작업실행} 후 {확인}.
    왜?
    졸업생 한 명 한 명에게 학교의 공식 졸업 순번을 확정해 붙여, 졸업장과 졸업대장 그리고 학교생활기록부의 기록이 같은 번호로 맞물리게 하려고.

    번호가 매겨지는 방식

    • '졸업회차', '졸업대장시작번호'는 이전학년도에 나이스로 졸업처리를 한 경우 '졸업회차'는 이전학년도 졸업회차+1로, '졸업대장시작번호'는 이전학년도 마지막 졸업대장번호+1로 부여됨.
    • 졸업대장번호부여 방식에서 '학적편제순(학과포함)'은 계열-학년-학과-반-번호 순, '학적편제순(학과미포함)'은 계열-학년-반-번호 순, '반코드순'은 반-번호 순으로 채번됨.
    • 졸업대장 시작번호는 숫자만으로 이루어진 자료와 ####-####의 형식으로만 부여할 수 있으며, 최대 16자리까지만 부여할 수 있음. 숫자만으로 이루어진 자료는 하이픈(-) 뒤에 위치한 입력창에 졸업대장번호를 입력함(예시: 2025-10001, 10987).
    • 졸업대장번호를 '학년도-연번' 형식의 학년도별로 부여하는 경우 '졸업회차' 옆의 '대장번호형식변경'을 선택하여 부여함.
    • '남여구분'을 선택하면 남학생이 앞번호부터 졸업대장번호가 부여됨.
    • 졸업대장번호를 '학적편제순'으로 부여하면 [학적-졸업/수료관리-졸업생학생부출력]에서 학적편제순으로 학교생활기록부를 출력할 수 있음.

    작업실행과 취소

    • {작업실행}으로 학교생활기록부의 학교정보(학년이력)에 졸업대장번호가, 인적·학적사항의 학적사항에 '2025.01.10. ○○고등학교 제3학년 졸업'이 자동으로 등록되며, 졸업생 학적반영 전에 졸업 관련 항목이 모두 입력된 졸업 대상자의 학교생활기록부를 출력할 수 있음.
    • {작업실행} 시 학교생활기록부의 학교정보(학년이력)에 졸업대장번호가 인적·학적사항의 학적사항에 '2026.01.07. ○○고등학교 제3학년 졸업'이 자동으로 등록됨.
    • {작업실행}을 완료하면 {작업실행}이 {작업취소}로 변경되며, 필요시 {작업취소}할 수 있음.
    • {작업취소}하면 졸업 대상자 학교생활기록부의 학교정보(학년이력)에 반영된 졸업대장번호와 인적·학적사항의 학적사항에서 '2025.01.10. ○○고등학교 제3학년 졸업' 내용이 삭제됨.
    • {작업실행}을 완료하면 '졸업대장번호수정파일올리기'에 {출력}이 나타나며, {출력}으로 졸업/수료대장번호 부여 내역을 PDF, 워드, 엑셀, 파워포인트, 한글 문서로 저장하거나 출력할 수 있음.

    • 이전학년도 졸업장을 조회하려면 '졸업학년도'를 이전학년도로 수정하고 {조회} 함.
    • '성명'을 공란으로 두고 {조회} 하면 졸업학년도에 해당하는 모든 졸업생이 조회됨.
    • 졸업장이나 수료장을 출력하기 위해서는 [학적-졸업/수료관리-졸업장/수료장/명예졸업장양식관리]에서 졸업장이나 수료장을 먼저 등록해야 함.
    • 졸업장을 테두리가 있는 용지로 인쇄하는 경우 테두리 선택을 해제하여 출력함.
    • 일반학과인 경우 학과포함 선택 여부에 관계 없이 학과가 나타나지 않음.
    • {출력} 으로 졸업장·수료장을 PDF, 워드, 엑셀, 파워포인트, 한글 문서로 저장하거나 출력할 수 있음.

    11D
    졸업생 학적반영 이후증명·제출 용도 불가

    졸업생 학교생활기록부 출력

    졸업생 학적반영을 마친 뒤 졸업생의 학교생활기록부를 학생별로 확인·출력하는 업무입니다. 학급별 일괄출력은 지원되지 않으며, 페이지별로 검색된 학생들만 일괄출력이 가능합니다. 출력 시 조회 및 출력 사유를 반드시 등록해야 합니다.

    언제?
    학년말, [학적-졸업/수료관리-졸업/수료생학적반영]에서 {학적반영}을 완료한 뒤.
    누가?
    학적 업무담당자
    어디서?
    [학적-졸업/수료관리-졸업생학생부출력]
    무엇을
    어떻게?
    '졸업학년도' 확인 후 출력할 학생의 '성명'을 입력하고 {조회} 함 → '학생부 선택', '출력옵션' 선택 후 출력하고자 하는 졸업생을 선택하여 {출력} 함 → '졸업생 학생부 조회 및 출력 사유 등록' 창에서 '조회 및 출력 사유'를 입력한 후 {저장} 하고 '확인' 창에서 내용 확인 후 출력함.
    왜?
    졸업 후 기록을 확인해야 할 상황에서 누가 왜 열람했는지 사유를 남기면서 필요한 범위만 안전하게 꺼내 보기 위해서입니다.

    실무 메모

    • 학생 '성명'을 공란으로 두고 {조회} 하면 졸업학년도에 해당하는 모든 졸업생이 조회됨.
    • 졸업생 학교생활기록부는 용도에 따라 '학교생활기록부Ⅰ'과 '학교생활기록부Ⅱ'로 구분하여 조회 및 출력할 수 있음.
    • 졸업생 학적반영 이후에 출력할 수 있으나 학급별 일괄출력은 지원되지 않으며, 페이지별로 검색된 학생들만 일괄출력이 가능함.
    • 졸업대장번호를 '학적편제순'으로 부여하면 [학적-졸업/수료관리-졸업생학생부출력]에서 학적편제순으로 학교생활기록부를 출력할 수 있음.
    • 졸업생 학교생활기록부는 나이스에서 {승인요청} 으로 업무승인과정을 거쳐 결재 완료 후 별도로 출력하여 보관하지 않음.

    증명·제출 용도는 민원 메뉴

    • [학적-졸업/수료관리-졸업생학생부출력]에서 출력한 졸업생 학교생활기록부는 증명, 제출 등의 용도로 사용 불가함.
    • 상급학교 전형자료를 온라인으로 제공하지 않는 학생의 경우 상급학교 전형자료용 학교생활기록부는 [민원] 메뉴의 '생활기록부(대입전형용)'를 이용하여 출력함.
    • [민원]의 출력상세경로는 [민원-민원접수처리관리-제증명민원접수-학생관련민원접수]의 {민원사무명} 에서 '생활기록부(초,중,고)'와 '생활기록부(대입전형용)'임.
