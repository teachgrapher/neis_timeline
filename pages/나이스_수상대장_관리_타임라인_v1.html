    01A
    연중 수시수상자 등록 선행

    상장양식 등록 및 수정·삭제

    교내상을 시상하는 모든 학교가 해당하며, 수상자를 등록하기 전에 상장 종류와 상장 문구를 먼저 만들어 두는 업무입니다. ‘상장명’은 연간 시상 계획의 수상명과 일치하게 입력해야 이후 수상 등록과 학교생활기록부 수상경력이 어긋나지 않습니다.

    언제?
    연중. 수상자를 등록하기 전에 상장양식을 먼저 등록해 두고, 필요에 따라 연중 수정함.
    누가?
    수상 업무담당교사
    어디서?
    [학생생활-수상경력-수상대장관리]
    무엇을
    어떻게?
    [학생생활-수상경력-수상대장관리]의 {수상대장관리} 탭에서 학년도를 확인하고 {상장양식관리} 함 → ‘상장양식관리’ 창에서 {등록} 하여 ‘상장명’, ‘상장분류’, ‘상장제목’, ‘부문명칭’, ‘용지설정’, ‘상장문구’, ‘수여자명’ 등을 선택 또는 입력하여 {저장} 후 {확인} 함.
    왜?
    연간 시상 계획대로 상장을 찍고 학교생활기록부 수상경력에 같은 이름으로 남기려고.

    실무 메모

    • 한 번 등록한 상장 양식은 학년도와 관계없이 계속하여 사용할 수 있으며, ‘상장명(코드:상장분류)’을 선택하여 수정하거나 삭제할 수 있으므로 필요에 따라 ‘상장명’, ‘부문명칭’, ‘상장문구’ 등을 연중으로 수정하여 사용할 수 있음.
    • ‘상장명’ 입력 시 연간 시상 계획의 수상명과 일치하게 입력함.
    • 이미 등록된 상장과 동일한 상장명을 등록할 경우 새로 등록한 상장명에 다른 코드 번호가 부여되어 저장됨.
    • {상장양식관리}에서 ‘수상명’을 선택하여 출력양식을 ‘세로’에서 ‘가로’로 수정할 수 있음.

    03B
    수상 등록 전직접입력 / 자동채번 선택

    상장번호 입력형식과 시작번호 설정

    교내상 수상을 등록하기 전에 상장번호를 어떤 방식으로 매길지 먼저 정해 두는 업무입니다. '상장번호 입력형식 선택'을 '직접입력'으로 두면 수상 등록 시 상장번호를 직접 입력할 수 있고, '자동채번'으로 두면 '상장 시작번호'부터 순서대로 번호가 붙습니다. 잘못 등록한 수상을 삭제한 뒤 그 번호를 다시 쓰려는 경우에도 이 설정을 먼저 확인합니다.

    언제?
    연중, 수상내용을 등록하기 전에 먼저 설정함.
    누가?
    수상 업무담당교사
    어디서?
    [학생생활-수상경력-수상대장관리] 의 {수상대장관리} 탭
    무엇을
    어떻게?
    [학생생활-수상경력-수상대장관리]의 {수상대장관리} 탭에서 '학년도', '교내/교외', '학년', '상태' 확인 후 {조회} → {상장번호설정} 하여 '상장번호 설정' 창에서 '상장번호 입력형식 선택', '상장 시작번호', '수상대장 정렬방식'을 선택 및 입력 후 {저장}.
    왜?
    상장번호가 겹치거나 비지 않게 미리 규칙을 정해 두어 수상대장이 시상 순서대로 정확히 남게 하려고.

    실무 메모

    • '상장시작번호'는 '마지막 상장번호'보다 큰 번호를 입력함.
    • 수상내용을 잘못 등록해 삭제하고 새로 등록하는 경우, {상장번호설정}에서 '상장번호 입력형식 선택'을 '직접입력'으로 설정하면 수상 등록 시 수상번호를 직접 입력할 수 있으며 삭제된 상장번호를 다시 입력할 수 있음.
    • '직접입력'에서 '자동채번'으로 바꿀 때는 '상장번호 입력형식 선택'을 '자동채번'으로 수정한 후 등록했던 상장번호 다음 번호를 '상장시작번호'에 직접 입력하면 해당 번호부터 자동으로 채번됨.

    02A
    상장 인쇄 전학교 로고 등 필요 시

    상장양식 출력 속성·배경이미지 편집

    등록한 상장양식을 실제로 뽑기 전에 글꼴과 배경을 학교 실정에 맞추는 업무이며, 기본 양식대로 출력해도 되는 학교는 건너뛸 수 있습니다. 학교직인을 넣는 것은 불가능하므로 기본 제공 기능 이외는 상장양식 파일을 내려받아 편집해야 합니다.

    언제?
    연중. 상장양식을 등록한 뒤, 상장을 인쇄하기 전에 함.
    누가?
    수상 업무담당교사
    어디서?
    [학생생활-수상경력-수상대장관리]
    무엇을
    어떻게?
    [학생생활-수상경력-수상대장관리]의 {수상대장관리} 탭에서 {상장양식관리} 함 → ‘상장양식관리’ 창에서 {상장양식편집} 하여 ‘상장양식 출력 속성’에서 ‘용지설정’, ‘상장번호’, ‘상장명’, ‘부문명칭’, ‘학년반’, ‘학생성명’, ‘상장문구’, ‘수상일자’, ‘수여자명’의 폰트, 크기, 속성 등을 설정함 → ‘배경이미지’에 학교별 로고 이미지 등을 첨부하고 {미리보기} 하여 확인 후 {저장} 함.
    왜?
    실제 종이에 찍히는 모양을 미리 맞춰 두어 시상 당일 상장을 다시 뽑는 일이 없게 하려고.

    실무 메모

    • ‘상장양식관리’ 창에서 {상장양식편집} 하면, ‘상장양식 출력 속성’에서 ‘용지설정’, ‘상장번호’, ‘상장명’, ‘부문명칭’, ‘학년반’, ‘학생성명’, ‘상장문구’, ‘수상일자’, ‘수여자명’의 폰트, 크기, 속성 등을 설정할 수 있음.
    • ‘배경이미지’에 학교별 로고 이미지 등을 첨부하고 {미리보기}하여 확인 후 {저장}할 수 있음.

    직인·이름 출력이 안 될 때

    • 상장 양식에 학교직인을 넣는 것은 불가능함. 기본적으로 제공하는 것 이외의 기능은 학교에서 상장양식 파일을 다운로드한 후 편집하여 사용함.
    • 외국인 학생의 영어이름이 끝까지 출력되지 않으면 [학생생활-수상경력-수상대장관리]의 {상장출력}에서 해당 학생을 선택하여 {출력}한 후 ‘저장’에서 한글파일(HWP)로 내려받아 성명을 편집하여 출력함.

    04B
    상장 출력 전

    수상대장 정렬 방식 설정

    수상대장에 등록된 목록을 원하는 기준으로 줄 세워 보는 업무입니다. 조회 결과 화면에서 설정에서 '필터'를 클릭하면 각 항목에 삼각형이 나타나며, 그 항목을 기준으로 정렬할 수 있습니다. 상장을 인쇄하기 전에 목록 순서를 확인할 때 사용합니다.

    언제?
    연중, 수상내용이 등록되어 조회되는 상태에서 상장 인쇄 전에 함.
    누가?
    수상 업무담당교사
    어디서?
    [학생생활-수상경력-수상대장관리] 의 {수상대장관리} 탭
    무엇을
    어떻게?
    [학생생활-수상경력-수상대장관리]의 {수상대장관리} 탭에서 학년도 확인 후 조회 조건 확인 및 선택하고 {조회} → 설정에서 '필터'를 클릭하면 각 항목에 삼각형이 나타나며 원하는 항목을 기준으로 선택하여 정렬함.
    왜?
    많은 수상 목록에서 시상 순서나 학년·반 순으로 줄을 맞춰 놓아 상장을 빠뜨리거나 뒤섞어 인쇄하지 않으려고.

    실무 메모

    • '수상대장 정렬방식'은 {상장번호설정}의 '상장번호 설정' 창에서도 선택할 수 있음.

    05C
    시상 직전기본 경로

    수상대장관리 탭에서 상장 인쇄

    등록된 상장양식과 수상자 정보로 실제 상장을 뽑는 단계입니다. 상장양식 등록과 상장번호 설정이 끝나 수상대장에 수상 내용이 들어와 있어야 하며, 출력할 '수상명'을 입력해 조회한 뒤 목록을 선택해야 해당 수상자만 인쇄됩니다. 외국인 학생의 영어이름처럼 이름이 끝까지 나오지 않으면 파일로 내려받아 편집합니다.

    언제?
    연중, 상장양식 등록과 수상 내용 등록이 끝난 시상 직전
    누가?
    수상 업무담당교사
    어디서?
    [학생생활-수상경력-수상대장관리]
    무엇을
    어떻게?
    [학생생활-수상경력-수상대장관리]의 {수상대장관리} 탭에서 학년도 확인 후 조회 조건 확인 및 선택하고 출력할 '수상명' 입력 → {조회} → 출력할 목록 선택 → {출력} → '상장출력미리보기' 창에서 내용 확인 후 출력함.
    왜?
    연간 시상 계획대로 확정된 수상 내용을 학생에게 전달할 상장 실물로 만들려고.

    실무 메모

    • 외국인 학생의 영어이름 등으로 학생 이름이 끝까지 출력되지 않는 경우, [학생생활-수상경력-수상대장관리]의 {상장출력}에서 해당 학생을 선택하여 {출력}한 후 '저장'에서 한글파일(HWP)로 내려받아 성명을 편집하여 출력함.
    • 상장 양식에 학교직인을 넣는 것은 불가능함. 기본적으로 제공하는 것 이외의 기능은 학교에서 상장양식 파일을 다운로드한 후 편집하여 사용함.

    06C
    시상 직전참가 부문·단체상 있는 경우

    상장출력 탭에서 양식 선택 및 단체상장 출력

    참가 부문이 있는 대회이거나 단체 수상이 있는 학교만 해당합니다. 참가 부문이 있는 대회는 수상명의 ( ) 안에 참가 부문을 입력해 두어야 상장출력 조건에서 그에 맞는 상장양식을 고를 수 있습니다. 단체건은 단체상장과 개인별단체상장을 함께 뽑을 수 있습니다.

    언제?
    연중, 수상명에 참가 부문까지 입력된 상태의 시상 직전
    누가?
    수상 업무담당교사
    어디서?
    [학생생활-수상경력-수상대장관리]의 {상장출력} 탭
    무엇을
    어떻게?
    참가 부문이 있는 대회의 경우 수상명의 ( ) 안에 참가 부문을 입력 → [학생생활-수상경력-수상대장관리]의 {상장출력} 탭에서 상장출력 조건을 선택하여 상장양식을 선택 → 단체건은 “체크되면 단체건일 경우 단체상장과 개인별단체상장까지 출력됩니다.”를 선택 → {출력}함.
    왜?
    부문별·단체별로 문구가 다른 상장을 한 번의 출력으로 각각 맞게 받아 학생에게 나눠 주려고.

    실무 메모

    • 참가 부문이 있는 대회의 경우 수상명의 ( ) 안에 참가 부문을 입력하고 [학생생활-수상경력-수상대장관리]의 {상장출력} 탭에서 상장출력 조건을 선택하여 상장양식을 선택할 수 있음.

    수상 담당자 부재 시 정정 발생 시점결재 완료된 수상문서에 한정

    결재문서 삭제 후 수상내용 수정

    수상내용을 잘못 등록해 고쳐야 하는데 수상 담당자가 현재 본교에 재직 중이 아닌 경우에 해당하는 업무입니다. 학교업무분장관리자가 해당 수상문서의 결재문서를 먼저 삭제해야 수상업무담당교사가 수상내용을 수정할 수 있습니다.

    언제?
    연중, 수상내용 정정 사유가 발생한 뒤
    누가?
    학교업무분장관리자, 수상 업무담당교사
    어디서?
    [업무승인관리-업무승인-결재현황관리-결재현황판관리], [학생생활-수상경력-수상대장관리]
    무엇을
    어떻게?
    학교업무분장관리자 아이디로 로그인 → [업무승인관리-업무승인-결재현황관리-결재현황판관리]에서 해당 수상문서에 대해 '기안자' 찾기 → '상신기간'을 설정하여 {조회} → 수정해야 할 '결재문서명'을 선택하고 {삭제} → '결재문서삭제' 창에서 '삭제사유'를 등록해 {삭제} → 이후 수상업무담당자가 [학생생활-수상경력-수상대장관리]에서 해당 수상을 수정함.
    왜?
    학교생활기록부 수상경력에 잘못된 내용이 그대로 남지 않도록, 담당자가 바뀐 뒤에도 수상 기록을 바로잡을 길을 열어 두려고.

    실무 메모

    • 수상 담당자가 현재 본교에 재직 중이 아닌데 수정할 부분이 발생했을 때는 학교업무분장관리자 아이디로 로그인하여 처리함.
    • [업무승인관리-업무승인-결재현황관리-결재현황판관리]에서 해당 수상문서에 대해 '기안자' 찾기 후 '상신기간'을 설정하여 {조회}함.
    • '결재문서삭제' 창에서는 '삭제사유'를 등록해야 {삭제}가 가능함.
    • 결재문서를 삭제한 이후에 수상업무담당자가 [학생생활-수상경력-수상대장관리]에서 해당 수상을 수정할 수 있음.

    삭제한 상장번호를 다시 쓰려면

    • 등록된 내용을 삭제하고 새로 등록할 때 전에 사용했던 수상대장번호를 다시 쓰려면, [학생생활-수상경력-수상대장관리]의 {상장번호설정}에서 '상장번호 입력형식 선택'을 '직접입력'으로 설정함. 그러면 수상 등록 시 수상번호를 직접 입력할 수 있고 삭제된 상장번호를 입력할 수 있음.
    • '직접입력'에서 '자동채번'으로 되돌릴 때는 '상장번호 입력형식 선택'을 '자동채번'으로 수정한 후 등록했던 상장번호 다음 번호를 '상장시작번호'에 직접 입력하면 해당 번호부터 자동으로 채번됨.
