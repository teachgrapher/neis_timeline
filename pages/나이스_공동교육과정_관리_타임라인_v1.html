    01A
    거점교 확인요청 직후승인요청·결재 필요

    공동교육과정 학생 확인요청 접수 및 전송

    거점교(거점센터·중심교)에서 개설한 공동교육과정을 수강하는 학생이 우리 학교 소속으로 있을 때 하는 업무입니다. 거점교에서 타교수강생을 등록하고 {확인요청}을 보낸 뒤에야 목록에 나타납니다. 소속교는 거점교가 등록한 수강생 정보의 오류 유무를 확인하고 이상없음을 거점교로 전송합니다.

    언제?
    학기초, 거점교에서 공동교육과정 타교수강생을 등록하고 소속교로 {확인요청}한 뒤
    누가?
    공동교육과정 업무담당자
    어디서?
    [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생확인요청접수및전송]
    무엇을
    어떻게?
    ‘학년도’, ‘기간’, ‘기관명(개설학교)’ 확인 후 {조회} → 해당 학생의 ‘성명’을 클릭해 나타나는 ‘공동교육과정학생 상세정보’ 창에서 거점교에서 등록한 공동교육과정 수강생 정보의 오류 유무를 확인 후 {닫기} → 해당 학생을 선택하고 {승인요청}으로 업무승인과정을 거쳐 결재권자의 결재가 완료되면 해당 학생을 선택하고 {요청확인}하여 거점교에 공동교육과정 수강생 정보가 이상없음을 전송함.
    왜?
    거점교가 등록한 학생이 실제 우리 학교 학생인지 소속교가 직접 확인해 준 뒤에야 성적·세특·학생생활 자료가 우리 학생 기록으로 넘어오게 하려고.

    승인요청 절차

    • {승인요청} 시 ‘기안문서상신’ 창에서 ‘내용’ 입력 후 {결재자지정}으로 결재권자를 등록하고 공동교육과정 수강생을 선택하여 {상신}하여 결재권자의 결재가 완료되면 ‘상태’가 ‘확인요청접수’에서 ‘상신완결’로 변경됨.
    • 타 메뉴에서 {승인요청}은 이와 동일한 과정을 거쳐 수행함.

    ‘상태’ 값과 이후 처리

    • 확인요청접수 — 거점교에서 공동교육과정 타교수강생 등록 후 {확인요청}을 한 경우.
    • 상신완결 — {승인요청}으로 업무승인과정을 거쳐 결재권자의 결재가 완료된 경우.
    • 확인요청완료 — {요청확인}으로 거점교에 확인요청을 완료한 경우.
    • ‘상태’가 ‘확인요청완료’이고 ‘전송상태’가 ‘전송완료’인 경우 [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생타학교자료전송확인]에서 자동으로 공동교육과정 수강생으로 등록됨.
    • 이후 거점교에서 전송한 성적, 세특, 학생생활(수상, 독서활동) 자료는 자동 반영되고, 출결, 나머지 학생생활 자료는 공동교육과정 수강생 소속교 나이스 관련 메뉴에서 확인 후 반영함.

    성적처리 방식 참고

    • 거점교에서 공동교육과정 과목 개설 시 해당 과목을 수강한 학생 모두를 ‘수강자 수’로 하여 성적을 산출함(일반고등학교, 특수목적고등학교, 특성화고등학교, 산업수요 맞춤형 고등학교 등 모두 포함).
    • 일반고등학교와 특수목적고등학교(또는 특성화고등학교) 간 전문 교과 과목을 공동교육과정으로 개설한 경우에는 보통교과 중 ‘진로 선택 과목’으로 편성하고 진로선택과목의 성적산출 방식에 따라 처리함.
    • 산업수요 맞춤형 고등학교, 특성화고등학교, 일반고등학교 직업계열 학과 간 전문 교과 Ⅱ 과목을 공동교육과정으로 운영하는 경우에는 ‘전문 교과 Ⅱ 과목’으로 편성하고 전문 교과 Ⅱ 과목의 성적산출 방식에 따라 처리함.
    • 2022 개정 교육과정(2026학년도 1·2학년) 거점교가 일반고등학교인 경우 일반고등학교와 특수목적고등학교, 일반고등학교와 특성화고등학교 간 공동교육과정의 경우 전문 교과 선택 시 보통 교과의 진로선택과목으로 편성함.
    • 2022 개정 교육과정(2026학년도 1·2학년) 거점교가 특수목적고등학교·특성화고등학교인 경우 특수목적고등학교 보통교과는 과목 구분을 그대로 따르고, 전문교과는 특성화고등학교에서 개설하는 경우에는 전문교과 교과(군)으로 편성함.
    • 공동교육과정 과목 수강생 확정 후에는 수강 대상자를 변경하지 않음. 2015 개정 교육과정을 적용받는 2026학년도 3학년 미이수 학생(과목당 출석률 3분의 2 미만)은 성적을 산출하지 않고 학교생활기록부에도 반영하지 않으며, 과목 수강 학생에서 삭제하지 않고 [성적-성적처리선행작업-성적산출선행작업관리-성적산출학생관리]에서 ‘대상자포함 여부’를 ‘포함안함’으로 선택함.
    • 2022 개정 교육과정을 적용받는 2026학년도 1·2학년은 공동교육과정을 포함해 과목 이수기준(학업성취율 40%, 과목출석률 3분의 2 이상) 이상 미도달 대상자가 최소 성취수준 보장지도 및 추가학습 미이수 시 교과학습발달상황 내 ‘비고’에 ‘미이수’를 기재함.

    거점교 재확인요청 직후수강생 정보 변경 시에만

    수강생 정보가 변경된 경우 재확인요청 처리

    거점교에서 이미 확인이 끝난 공동교육과정 수강생의 정보를 고쳐 {재확인요청}을 보낸 경우에만 하는 업무입니다. 거점교에서 {재확인요청}한 경우 소속교에서는 추가적인 {승인요청} 없이 {요청확인}만 하면 됩니다. 학생부 자료 전송 학기를 잘못 잡아 고칠 때도 이 절차를 거칩니다.

    언제?
    학기중·학기말, 거점교에서 수강생 정보를 수정하고 {재확인요청}한 뒤
    누가?
    공동교육과정 업무담당자
    어디서?
    [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생확인요청접수및전송], (거점교) [학적-타교수강생관리(공동교육과정)-타교수강생관리(공동교육과정)-등록]
    무엇을
    어떻게?
    (거점교) [학적-타교수강생관리(공동교육과정)-타교수강생관리(공동교육과정)-등록]에서 ‘성명’을 클릭 → (거점교) ‘타교수강생(공동교육과정) 수정’ 창에서 수강생 정보를 수정하고 {재확인요청} → (소속교) [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생확인요청접수및전송]에서 ‘성명’을 클릭 → (소속교) ‘공동교육과정학생 상세정보’ 창에서 거점교에서 수정한 공동교육과정 수강생 정보를 확인하고 이상없을 시 {요청확인}함.
    왜?
    거점교가 고친 수강 정보를 소속교가 다시 확인해 학기·과목이 뒤바뀐 자료가 우리 학생 기록에 들어가지 않게 하려고.

    실무 메모

    • 거점교에서 {재확인요청}한 경우 소속교에서는 추가적인 {승인요청} 없이 {요청확인}함.
    • 학생부 자료 전송 학기를 잘못 전송한 경우 (거점교) ‘티교수강생 수정’ 창의 ‘원적교 학생정보’에서 ‘학생부 자료 전송 학기’를 ‘2학기’로 변경하여 {저장}하고 참여학교로 {재확인요청}함.
    • (참여교) ‘공동교육과정학생 상세정보’ 창에서 ‘학기’가 ‘2’로 변경되었는지 확인하고 {닫기}한 뒤 해당 학생을 선택한 후 거점교(거점센터)로 {요청확인}하여 학기가 정상적으로 변경되었음을 알림.

    미이수자 삭제 시 주의

    • 거점교의 [학적-타교수강생관리(공동교육과정)-타교수강생관리(공동교육과정)-등록]에서 미이수자 삭제 시 소속교의 [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생확인요청점수및전송]에서는 해당 수강생이 자동으로 삭제가 되도록 기능개선이 되었음.
    • 다만 [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생타학교자료전송확인]에서는 학기중 학적변동인 경우라도 자료는 거점교에서 전송될 수 있으므로 목록에 그대로 남아 있음.

    공동교육과정 수업일 출결자료 확인

    거점교에 공동교육과정 수강생을 보낸 소속교(참여교)에 해당하는 업무입니다. 거점교에서 교과담당교사가 출결자료를 등록(결과 시 '/' 표기) 후 {출결마감}하면 공동교육과정 타교수강생 참여교로 자동 전송됩니다. 담임교사가 일일출결에 반영하기 전에 어느 수업일에 무슨 출결자료가 왔는지 먼저 확인합니다.

    언제?
    학기중, 거점교에서 공동교육과정 수업일 출결을 등록하고 {출결마감}한 뒤
    누가?
    공동교육과정 업무담당자
    어디서?
    [학적-공동교육과정관리-출결관리]
    무엇을
    어떻게?
    '학년도', '일자', '기관명(개설학교)', '성명(공란)' 확인 또는 선택 후 '성명'을 입력하고 {조회}함 → 거점교에서 전송한 공동교육과정 수강생의 출결자료를 확인함.
    왜?
    거점교에서 넘어온 출결이 참여교 일일출결에 제대로 반영될 수 있도록, 반영 대상 수업일과 출결 내용을 미리 확인해 두려고.

    실무 메모

    • '성명'을 클릭하면 나타나는 '공동교육과정 출결내역' 창에서도 거점교에서 전송한 공동교육과정 수강생의 출결자료를 확인할 수 있음.
    • 참여교 공동교육과정 수강생의 거점교 공동교육과정 수업일은 [학적-공동교육과정관리-출결관리]에서 확인함.
    • '일과 내'는 교과 총 이수학점 174학점 이내로 공동교육과정을 운영하는 경우이고, '일과 외'는 교과 총 이수학점 174학점 초과로 공동교육과정을 운영하는 경우를 말함.

    출결자료 확인 직후학급담임교사 업무

    공동교육과정 수강생 수업일 출결자료 등록 및 출결마감

    공동교육과정 수강생이 있는 학급의 담임교사가 하는 업무입니다. 거점교 출결은 자동 반영되지 않으므로 참여교 학급담임교사가 '타학교출결내역' 창에서 해당 교시에 {결시} 또는 {출석}으로 직접 반영한 뒤 {저장}하고 {출결마감}해야 합니다. 학생 목록에서 공동교육과정 수강생은 성명 뒤에 '(공동)'이 붙어 구분됩니다.

    언제?
    학기중, [학적-공동교육과정관리-출결관리]에서 거점교 전송 출결자료를 확인한 뒤
    누가?
    학급담임교사
    어디서?
    [학적-출결관리-출결관리-일일출결관리(담임용)]
    무엇을
    어떻게?
    학급담임교사가 '학년도', '계열/학년/학과', '반' 확인 후 '일자'를 선택하고 {조회}함 → 공동교육과정 수강생 성명(권○○(공동))을 클릭하면 나타나는 '타학교출결내역' 창에서 공동교육과정 과목 교시별 출결자료를 확인하고 해당 교시에 출결자료를 {결시} 또는 {출석}으로 반영(결시 시 '/' 표기) → '마감' 항목을 클릭하면 나타나는 '출결마감구분' 창에서 '종류', '구분' 선택 후 '사유'를 입력하고 {적용}함 → 출결자료의 오류 유무를 확인 후 {저장}하고 {출결마감}함.
    왜?
    거점교 수업에 참여한 시간이 소속교 학생의 하루 출결로 인정되게 해, 출석률로 판단하는 과목 이수 여부와 학교생활기록부 출결상황이 실제와 맞게 남도록 하려고.

    실무 메모 — 자료가 오는 경로

    • 거점교에서 공동교육과정 수업일에 교과담당교사가 출결자료를 등록(결과 시 '/' 표기) 후 {출결마감}하면 공동교육과정 타교수강생 참여교로 자동 전송됨.
    • 참여교 공동교육과정 수강생의 거점교 공동교육과정 수업일은 [학적-공동교육과정관리-출결관리]에서 확인함.

    실무 메모 — 반영 절차 요약

    • 공동교육과정 수강생 참여교에서는 [학적-출결관리-출결관리-일일출결관리(담임용)]에서 공동교육과정 수업일을 선택하고 {조회} 후 공동교육과정 수강생 성명(예: 홍길동(공동))을 클릭하면 나타나는 '타학교출결내역' 창에서 공동교육과정 과목 시간별 출결정보를 확인 후 해당 교시에 {결시} 또는 {출석}으로 반영 후 {저장}하고 {출결마감}함.
    • 출결은 거점교에서 전송한 자료 중 자동 반영되지 않는 항목이므로, 참여교 나이스 관련 메뉴에서 확인 후 반영해야 함.

    학기말, 거점교 자료전송 이후소속교(참여교) 업무

    거점교 전송 자료 확인(학기말성적·수행평가성적·세특·수상내역·독서활동)

    공동교육과정 수강생이 있는 소속교에서 하는 업무입니다. ‘상태’가 ‘확인요청완료’이고 ‘전송상태’가 ‘전송완료’인 경우 [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생타학교자료전송확인]에 공동교육과정 수강생으로 자동 등록되며, 거점교가 전송한 자료를 항목별로 열어 확인합니다.

    언제?
    학기말, 거점교에서 공동교육과정 수강생의 성적(세특 포함)·학생생활 자료를 전송한 뒤
    누가?
    공동교육과정 업무담당자
    어디서?
    [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생타학교자료전송확인]
    무엇을
    어떻게?
    ‘학년도’, ‘학기’, ‘기관명(개설학교)’, ‘상태’ 확인 후 {조회}함 → 공동교육과정 수강생의 ‘성명’을 클릭하면 나타나는 ‘공동교육과정 타학교 자료내역’ 창에서 ‘성적’-‘학기말성적’을 선택하여 거점교에서 전송한 학기말 성적을 확인하고 {닫기}함 → 같은 창에서 ‘성적’-‘수행평가성적’, ‘성적’-‘세부능력및특기사항’, ‘학생생활’-‘수상내역’, ‘학생생활’-‘독서활동’을 확인함.
    왜?
    거점교가 보낸 성적과 학생생활 자료가 우리 학교 학생에게 제대로 도착했는지 학생부에 반영하기 전에 걸러내려고 함.

    실무 메모

    • 거점교에서 전송한 성적, 세특, 학생생활(수상, 독서활동) 자료는 자동 반영되고, 출결, 나머지 학생생활 자료는 공동교육과정 수강생의 참여교 나이스 관련 메뉴에서 확인 후 반영하되, 학교생활기록부 항목별로 자료반영함.
    • {엑셀내려받기}로 ‘엑셀’, ‘한셀’, ‘CSV’ 파일로 다운로드 항목별로 자료를 조회할 수 있음.
    • 수신자료별 자료반영 메뉴는 다음과 같음. 일출결은 [학적-공동교육과정관리-출결관리]에서 공동교육과정 수업일 출결자료를 확인하고 [학적-출결관리-출결관리-일일출결관리(담임용)]에서 확인 후 반영함. 성적과 세부능력및특기사항은 [학생부-학교생활기록부-학교생활기록부-학생부반영]에서 ‘교과학습발달상황’ 선택 후 {개인별반영}함. 수상내역은 [학생생활-수상경력-학급별수상관리]에서 ‘교내/교외’를 ‘교내’로, ‘학생부 반영여부’를 체크 후 {저장}함. 독서활동은 [학생부-학교생활기록부-학교생활기록부-학생부반영]의 ‘학생부 반영 항목’에서 ‘독서활동상황’을 선택 후 {개인별반영}하면 학교생활기록부 독서활동상황에 반영됨.
    • 거점교에서 전송한 지필평가성적과 수행평가성적은 참여교에서만 삭제 가능하며, 학기말 성적과 세부능력 및 특기사항은 거점교와 참여교에서 삭제 가능함(필요시 참여교에 반영된 자료를 거점교에서 {전송취소}로 삭제하는 것이 원칙임).
    • 독서활동(거점교 수업교사가 등록한 독서활동)은 참여교에서 삭제 가능함.

    이런 경우도 정상

    • 타교 거점교 개설 공동교육과정 과목은 소속교 [성적-수행평가-수행평가마감관리]에서 조회되지 않으며, {마감정보저장}과는 관련이 없으므로 소속교에 개설된 모든 과목이 마감된 경우라면 {마감정보저장}함.
    • [성적-성적조회/통계-학기말성적조회-개인별성적일람표]에서 조회한 ‘학기말 개인별 일람표’나 [성적-성적처리-성적통지표(가정통신문)관리]에서 {미리보기}로 조회한 ‘성적 통지표’에 거점교에서 수강한 공동교육과정 과목 ‘점수’, ‘만점/반영비율’ 등은 나타나지 않음. 거점교에서 개설된 교과목이므로 소속교에서 나타나지 않는 것은 정상임.
    • 거점교의 [학적-타교수강생관리(공동교육과정)-타교수강생관리(공동교육과정)-등록]에서 미이수자 삭제 시 소속교의 [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생확인요청접수및전송]에서는 해당 수강생이 자동으로 삭제됨. 다만 [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생타학교자료전송확인]에서는 학기중 학적변동인 경우라도 자료는 거점교에서 전송될 수 있으므로 목록에 그대로 남아 있음.

    잘못 전송된 자료를 확인한 직후오류가 있는 경우만

    잘못 전송된 성적·세특 삭제 및 재전송 자료 처리

    거점교에서 과목 성적을 타교수강생 소속교로 잘못 산출해 전송했거나 학기를 잘못 지정해 전송한 경우에만 하는 업무입니다. 소속교에서는 자동반영되기 때문에 잘못된 자료를 걷어내는 절차가 필요합니다. 거점교에서 기 전송한 성적을 {전송취소}하면 학기말 성적과 세특은 함께 삭제되지만 ‘지필평가성적’과 ‘수행평가성적’은 삭제되지 않으므로 참여교에서 직접 삭제합니다.

    언제?
    학기말, 거점교 전송 자료 확인 과정에서 오류를 발견한 뒤
    누가?
    공동교육과정 업무담당자
    어디서?
    [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생타학교자료전송확인] [학생부-학교생활기록부-학교생활기록부-학생부반영] [학생부-학교생활기록부-학교생활기록부-학생부조회및출력]
    무엇을
    어떻게?
    (거점교) [학적-타교수강생관리(공동교육과정)-타교수강생관리(공동교육과정)-자료전송]에서 해당 학생 성명을 클릭하면 나타나는 ‘타교 수강생 자료전송’ 창에서 기 전송한 ‘성적’을 {전송취소}함 → (참여교) [학적-공동교육과정관리-공동교육과정학생관리-공동교육과정학생타학교자료전송확인]에서 해당 학생 성명을 클릭하면 나타나는 ‘공동교육과정학생 자료내역’ 창에서 ‘학기말성적’과 ‘세부능력및특기사항’이 정상적으로 삭제되었는지 확인하고 ‘지필평가성적’, ‘수행평가성적’을 삭제함 → (참여교) [학생부-학교생활기록부-학교생활기록부-학생부반영]에서 해당 학생의 교과학습발달상황을 선택하고 반영한 후 [학생부-학교생활기록부-학교생활기록부-학생부조회및출력]에서 해당 학생의 학기말 성적과 세부능력 및 특기사항이 삭제되었는지 확인함 → 거점교에서 정상 산출한 자료를 다시 전송받은 뒤 [학생부-학교생활기록부-학교생활기록부-학생부반영]에서 해당 공동교육과정 수강생을 선택 후 ‘학생부 반영 항목’에서 ‘교과학습발달상황’을 선택하여 {개인별반영}함.
    왜?
    잘못된 성적과 세특이 학생의 학교생활기록부에 그대로 남는 것을 막고 올바른 자료로 되돌려 놓으려고 함.

    실무 메모

    • 거점교의 [학적-타교수강생관리(공동교육과정)-타교수강생관리(공동교육과정)-자료전송]에서 ‘성적’을 {전송취소}하면 기존에 전송한 학기말 성적과 세특이 참여교에서 삭제됨. ‘지필평가성적’과 ‘수행평가성적’은 삭제되지 않으므로 참여교에서 직접 삭제함.
    • 거점교에서 기 전송한 성적과 세특에 대해 {전송취소} 후 다시 정상 산출하여 소속교로 전송함. 이때 세특도 다시 전송해야 함.
    • 소속교 학기말 성적 산출이 마감된 상태에서도 거점교에서 학기말 성적을 다시 전송할 수 있으며, [학생부-학교생활기록부-학교생활기록부-학생부반영]에서 해당 공동교육과정 수강생을 선택 후 ‘학생부 반영 항목’에서 ‘교과학습발달상황’을 선택하여 {개인별반영}함.
    • ‘비고’에 ‘공동, 타기관’이 나타나지 않는 경우에는 거점교에서 참여교에 학기말 성적 전송취소부터 역과정으로 교육과정 편제 삭제까지 수행한 후 다시 교육과정 편제(공동교육과정 체크)부터 학기말 성적 산출과 참여교로 자료전송까지 수행해야 함.

    거점교 자료 전송 확인 후학생부 반영
