    02A
    학기초, 고사 전기존 프로그램으로 대체 가능

    OMR 카드 리딩 프로그램 설치와 환경설정

    나이스의 OMR 카드 리딩 프로그램을 쓰거나 기존에 사용하던 OMR 카드 리딩 프로그램을 그대로 쓸 수 있습니다. 스캔 방식의 OCR 카드 리더기에는 적용되지 않으므로 스캔 방식의 카드 리더기를 사용하는 학교는 기존과 동일하게 파일업로드 방식을 사용합니다. 설치와 실행·환경설정은 한 번에 끝내는 한 덩어리 작업입니다.

    언제?
    학기초, 지필·수행평가 답안카드 리딩 전
    누가?
    성적처리 업무담당자
    어디서?
    [성적-지필/수행선행작업-OMR카드리딩프로그램관리]
    무엇을
    어떻게?
    [성적-지필/수행선행작업-OMR카드리딩프로그램관리]에서 {OMR카드리딩프로그램내려받기} → {확인} → 내려받은 프로그램을 설치 → 같은 메뉴에서 {OMR카드리딩프로그램실행} → {확인} → '나이스 OMR 카드리딩 프로그램' 창에서 {환경설정} → '환경설정' 창의 {판독기설정}, {학생카드설정}, {정답카드설정}, {점수카드설정}, {카드리더기설정가져오기} 탭에서 설정 → {저장}
    왜?
    학생 답안이 담긴 OMR 카드를 암호화된 상태로 안전하게 읽어 들여 나이스로 그대로 이관하려고.

    설치 단계 메모

    • 파일을 내려받을 때 '보안 경고' 창이 열리면 {실행}함.
    • 내려받은 설치 프로그램의 명칭은 'neis_omr_setup_high'임.
    • 스캔 방식의 OCR 카드 리더기에는 적용되지 않으므로 스캔 방식의 카드 리더기를 사용하는 학교는 기존과 동일하게 파일업로드 방식을 사용함.

    실행·환경설정 메모

    • OMR카드리딩 프로그램을 실행하여 '이 사이트에서 neis_omr.exe 을 열려고 합니다.'라는 '보안 경고' 창이 열리면 {열기}함.
    • '나이스 OMR 카드리딩 프로그램'의 {환경설정}하여 {카드리더기 설정 가져오기(omr.ini)} 탭에서는 학교에서 기존에 사용했던 카드 리딩 프로그램의 환경설정 값을 가져와서 {저장}할 수 있음.
    • '나이스 OMR 카드리딩 프로그램'을 이용해서 학생답안 파일을 리딩하면 학생답안 파일을 암호화된 상태로 저장하고 나이스에 업로드 및 이관하면 암호화된 학생답안 파일을 복호화 함(암호화 된 CSV 파일은 탐색기에서 읽을 수 없음).
    • 나이스의 OMR 카드리딩 프로그램을 사용하지 않고 기존과 같은 방법으로 OMR 카드 리더기 제조사에서 제공한 카드 리딩 프로그램을 사용해서 학생답안 카드 등을 리딩하여 [성적-지필/수행선행작업-성적파일올리기]에서 등록할 수 있음.

    03A
    학기초, 고사 전

    OMR용 학과 코드 등록

    성적처리를 위해 학교에 개설된 과정별·계열별 학과코드를 등록하는 업무입니다. 일반학과와 직업계열 학과가 함께 설치된 일반고등학교에서는 일반학과와 직업계열 학과가 함께 나타납니다. 학과가 설치된 특성화고등학교 등은 학과코드 순서를 조정할 수 있습니다.

    언제?
    학기초, OMR 답안카드 제작과 성적파일 이관 전
    누가?
    성적처리 업무담당자
    어디서?
    [성적-지필/수행선행작업-OMR용코드관리]의 {학과코드관리} 탭
    무엇을
    어떻게?
    [성적-지필/수행선행작업-OMR용코드관리]의 {학과코드관리} 탭에서 '학년도'를 확인 → {조회} → {일괄부여} → {저장}
    왜?
    답안카드에 마킹된 학과 코드로 학생 성적을 정확한 학과에 붙이려고.

    실무 메모

    • 일반학과와 직업계열 학과가 함께 설치된 일반고등학교에서는 일반학과가 직업계열 학과가 함께 나타남.
    • 일괄부여는 순차적으로 학과 코드를 부여하는 기능임.
    • 학과가 설치된 특성화고등학교 등의 경우 학과코드 순서를 조정할 수 있음.
    • 4세대 나이스에서 학과코드는 2자리로 관리되며, 학생의 OMR 시트(카드)에 학과코드를 1자리로 마킹하여도 나이스에서 2자리로 변환하여 파일 이관 가능함.

    04A
    학기초, 과목 개설 완료 후

    OMR용 카드과목코드 등록

    학교에 개설된 과목의 성적처리를 위해 과목코드를 등록하는 업무입니다. [교육과정-편제및과목개설관리-편제및과목개설관리]에서 과목 개설이 완료되어야만 {과목코드관리} 탭에 해당 과목명이 나타납니다. '카드과목코드'는 학년별로 관리합니다.

    언제?
    학기초, [교육과정-편제및과목개설관리-편제및과목개설관리]에서 과목 개설이 완료된 뒤
    누가?
    성적처리 업무담당자
    어디서?
    [성적-지필/수행선행작업-OMR용코드관리]의 {과목코드관리} 탭
    무엇을
    어떻게?
    [성적-지필/수행선행작업-OMR용코드관리]의 {과목코드관리} 탭에서 '학년도', '학기'를 확인하고 '학년'을 선택 → {조회} → {일괄부여} 또는 개별 등록 → '카드과목코드'를 확인 → {저장}
    왜?
    리딩한 답안카드의 과목 마킹을 나이스의 개설 과목과 맞물리게 해 성적파일 이관이 실패하지 않게 하려고.

    실무 메모

    • '카드과목코드'는 학년별로 관리하며, {일괄복사}하여 이전학년도의 '학과코드'와 '카드과목코드'를 그대로 가져올 수 있음.
    • [교육과정-편제및과목개설관리-편제및과목개설관리]에서 과목 개설이 완료되어야만 [성적-지필/수행선행작업-OMR용코드관리]의 {과목코드관리} 탭에서 해당 과목명이 나타남.
    • 100개 이상의 교과목을 개설할 경우 지필평가를 실시하지 않는 과목 또는 실무과목의 능력단위는 과목 코드를 부여하지 않아도 됨(과목코드는 2자리로만 표현 가능).
    • 카드과목코드는 OMR 카드 업로드를 위해 설정하는 코드로 이후 지필/수행 성적 입력 및 학기말 성적처리 등에는 활용되지 않음.
    • 과목이 100개 이상인 경우 OMR 답안카드 또는 학생점수 카드를 사용하지 않는 과목은 과목코드 미부여 가능함.

    01A
    학기초, 과목 개설 후특성화고·마이스터고 한정

    도제학교 그룹 등록

    직업계고에서 학점(단위수)과 과목명이 같은 과목을 도제그룹과 일반그룹으로 나누어 성적을 산출할 때 쓰는 업무입니다. [도제학교그룹관리] 메뉴는 특성화고등학교(마이스터고등학교 포함)에서만 표시되므로 그 밖의 학교는 이 카드를 건너뜁니다.

    언제?
    학기초, [교육과정-편제및과목개설관리]에서 과목 개설과 수강생 편성이 끝난 뒤
    누가?
    성적처리 업무담당자
    어디서?
    [성적-지필/수행선행작업-도제학교그룹관리]
    무엇을
    어떻게?
    [성적-지필/수행선행작업-도제학교그룹관리]에서 '학년도', '학기' 확인 후 '계열/학년/학과'를 선택 → {조회} → {등록} → '도제학교 그룹 등록' 창에서 '과목명'을 선택하고 해당하는 강의실에 '도제여부'를 선택 → {저장}
    왜?
    같은 과목명·같은 학점으로 묶여 버릴 도제 학생과 일반 학생의 성적을 서로 다른 집단으로 산출하려고.

    실무 메모

    • [도제학교그룹관리]는 직업계고에서 학점(단위수)과 과목명이 같은 과목에 대해 도제와 일반그룹으로 분리하여 성적을 산출하기 위한 기능으로 특성화고등학교(마이스터고등학교 포함)에서만 해당 메뉴가 표시됨.
    • '도제학교 그룹 등록' 창에서 일반그룹과 성적을 분리 산출할 도제그룹 강의실을 선택함.
    • 등록한 도제그룹을 수정하려면 과목명을 선택하여 수정하고 {저장}함.

    타임라인으로 돌아가기

    05B
    학기초, 과목 개설 후국가교육과정 성취기준이 있는 과목

    평가준거 성취기준 관리(국가교육과정 성취기준이 있는 과목)

    교육과정에 편제된 교과목 중 국가교육과정 성취기준이 제공되는 과목이면 국가교육과정 정보센터 자료를 그대로 가져와 등록할 수 있다. 2022 개정 교육과정의 전문교과 중 국가교육과정 성취기준이 있는 교과는 가져오기 기능을 제공함. 교과담당교사가 담당과목에 대해 성취기준을 등록하거나 수정 및 삭제할 수 있다.

    언제?
    학기초, [교육과정-편제및과목개설관리]에서 과목 개설과 수강생 편성이 끝난 뒤
    누가?
    교과담당교사
    어디서?
    [성적-지필/수행선행작업-성취평가기준관리-성취기준관리]
    무엇을
    어떻게?
    '학년도', '학기' 확인 후 '학년', '과목', '영역-전체'를 선택하여 {조회} → {가져오기} 하여 {국가교육과정성취기준} 선택 → '국가 교육과정 정보센터자료 가져오기' 창에서 가져올 성취기준을 선택하고 {가져오기} 함.
    왜?
    평가의 근거가 되는 성취기준을 국가 기준과 어긋나지 않게 맞춰 두어야 뒤이은 문항정보표와 성취기준별 결과 분석이 제대로 이어지기 때문이다.

    실무 메모

    • 성취기준을 수정하여 {저장} 하면 기존에 등록한 성취기준 코드 뒤에 '01'이 추가 등록됨.
    • 2022 개정 교육과정의 전문교과 중 국가교육과정 성취기준이 있는 교과는 가져오기 기능을 제공함.
    • 2015 개정 교육과정을 적용받는 2026학년도 3학년과 2022 개정 교육과정을 적용받는 2026학년도 1학년 과목의 경우 {가져오기} 에서 {이전자료} 를 클릭하여 나타나는 '이전자료 가져오기' 창에서 이전 학년도에 저장된 성취기준을 가져올 수 있음(단, 동일 과목, 동일 학점인 경우에 해당함).

    등록 시점 주의

    • 과목명(학점)에 마우스 포인터를 위치시키면 현재까지 진행된 내용을 확인할 수 있으며, 해당 과목에 정답/배점, 학생답안, 학생점수가 입력되면 과목을 삭제할 수 없으므로 입력된 자료를 먼저 삭제해야 함.
    • 해당 고사에 해당하는 각 과목의 성적이 [지필평가 마감관리]에서 모두 마감되면 응시생수, 총점, 평균, 표준편차가 계산되어 [지필평가과목관리]에서 확인할 수 있음.
    • 일반고등학교에서는 결시생 인정점에 활용되는 과목평균 점수를 [지필평가과목관리]의 '평균'을 통해 확인할 수 있으며, 이때의 과목평균은 소수 셋째 자리에서 반올림하여 소수 둘째 자리까지 표현함(해당 과목 평균은 해당 과목의 개설 학년 기준 평균임).
    • 결시생 인정점에 활용되는 과목평균의 경우 [결시생인정점관리] 내 {평균점수 조회} 기능을 통해 참고 가능.

    타학과 복사 방법

    • [성적-지필/수행선행작업-지필평가과목관리]에서 {등록} 후 '지필평가 과목등록' 창에서 한 학과의 과목을 등록하고 {일괄적용} 하면 타학과에 복사됨. 과목 정보 {저장} 시에는 {일괄적용}이 되지 않음.
    • [성적-지필/수행선행작업-지필평가과목관리]에서 한 학과에 과목을 {등록} 하고 타 학과에서 {타학과복사} 후 '지필평가 과목 관리 - 타학과 복사' 창에서 타 학과의 등록된 과목을 선택하고 {복사} 함.

    10C
    평가계획 수립 시기반영비율/만점관리로 대체 가능

    수행평가 영역 등록과 계열/학과 일괄적용

    수행평가를 실시하는 과목이면 모두 해당하며, 교과담당교사가 담당과목의 영역을 직접 등록한다. 여러 계열/학과를 통합하여 성적을 산출해야 하는 경우 '영역명'과 '영역번호'를 같게 설정해야 한다. 성취기준 입력은 선택사항이다.

    언제?
    평가계획 수립 시기, 과목 개설과 수강생 편성이 끝난 뒤.
    누가?
    교과담당교사
    어디서?
    [성적-지필/수행선행작업-수행평가영역관리]
    무엇을
    어떻게?
    [성적-지필/수행선행작업-수행평가영역관리]에서 '학년도', '학기' 확인 후 '학년', '과목' 선택 후 {조회} → {행추가} 하여 '영역명', '학기말반영여부', '반영비율(%)', '영역만점'을 입력하고 {저장}.
    왜?
    수행평가 결과가 학기말 성적에 환산 합산될 수 있도록 영역과 비율을 미리 갈라 두고, 계열·학과가 달라도 하나의 성적으로 통합 산출되게 하려고.

    실무 메모

    • 이전 학년도 또는 이전학기에 같은 과목과 학점(단위수)으로 개설되어 있으면 {이전자료가져오기}에서 등록할 수 있음.
    • 여러 계열/학과를 통합하여 성적을 산출해야 하는 경우 각 계열/학과별로 수행평가 영역명 입력 시 '영역명', '영역번호'를 같게 설정해야 함. 수행평가 영역명을 다르게 입력하는 경우 성적일람표에 모두 표시되고, 학기말 성적산출 시 통합 산출도 진행되지 않음.
    • 수행평가는 일반적으로 학기말 성적처리 시 반영비율로 환산하여 합산하므로 '학기말 반영여부'는 '○'로 설정하며, '성취기준' 입력 여부는 선택사항으로 '등록'을 클릭하면 [성적-지필/수행 선행작업-성취평가기준관리]에서 입력한 성취기준을 선택하여 반영할 수 있음.
    • 수행평가 영역명에 커서를 올려놓으면 현재 진행된 작업내용을 볼 수 있음.
    • 수행평가 영역 삭제는 [성적-수행평가]에서 정답, 배점, 학생답, 점수 등을 저장하거나 [성적-관찰기록관리-관찰내용관리]에서 등록한 수행평가영역에 관찰내용을 등록하면 해당 자료를 모두 삭제해야 가능함.
    • '기준등록 여부'에 등급과 구간으로 기준을 설정한 영역의 경우 [성적-수행평가-수행평가성적관리]에서 {등급변환}이 생성되며, '영역'별로 등급점수 또는 구간점수 입력 후 {저장} 시 등급 기준값 또는 구간 기준값으로 변환되어 저장됨(입력 여부는 선택사항임).

    일괄적용과 반영비율 확인

    • 수행평가 영역 정보를 모두 입력하고 {일괄적용} 후 '수행평가영역 관리 - 계열/학과 일괄적용' 창에서 적용하고자 하는 계열/학과를 선택 후 {일괄적용} 함. 영역 정보 {저장} 시에는 {일괄적용}이 되지 않음.
    • {전체반영비율보기}는 해당 과목에 등록한 '지필평가'와 '수행평가'의 모든 영역에 대한 '반영비율(%)'과 '과목/영역만점'을 조회할 수 있는 기능으로 지필평가와 수행평가의 반영비율 합계를 확인하는데 유용함.

    12D
    고사 직후OMR 카드 리딩 방식

    성적파일 업로드와 이관

    OMR 카드 리더기로 리딩한 정답/배점 파일과 학생답안 파일을 나이스로 반입하는 업무입니다. 나이스 OMR 카드 리딩 프로그램을 쓰지 않고 카드 리더기 제조사 프로그램이나 스캔 방식 리더기를 쓰는 학교도 이 메뉴에서 등록합니다. 지필평가는 정답/배점, 학생답안 파일을 업로드할 수 있으나 학생점수 파일은 업로드할 수 없음(수행평가는 학생점수 파일도 업로드 가능함).

    언제?
    고사 시행 후 OMR 카드 리딩을 마친 뒤, 지필평가 과목과 수행평가 영역 등록이 끝난 뒤
    누가?
    성적처리 업무담당자, 교과담당교사
    어디서?
    [성적-지필/수행선행작업-성적파일올리기]
    무엇을
    어떻게?
    ‘학년도’, ‘학기’, ‘과정’ 확인 후 ‘학년’, ‘지필/수행’, ‘고사/영역’ 선택 후 {파일추가} → ‘열기’ 창에서 대상 파일을 찾아 선택 후 {열기} → {파일업로드/이관}.
    왜?
    OMR 카드에 마킹된 답안과 점수를 학생별 성적 데이터로 나이스에 옮겨 이후 성적 산출의 원자료로 삼으려고 합니다.

    이관 실패의 네 가지 원인

    • 파일 이관이 실패하는 경우 [성적-지필/수행선행작업-성적파일관리]에서 확인이 가능함.
    • 학과코드가 설정한 값과 불일치하는 경우.
    • 과목코드가 설정한 값과 불일치하는 경우.
    • 수강학생이 아닌 학생의 답안이 있는 경우. 전·편입생 등 학적변동으로 해당 학생이 수강학생으로 편성되어 있지 않은 경우에는 [교육과정-편제및과목개설관리-학생별수강과목편성]에서 해당 학생을 편성해야 함. 2026학년도 1·2학년 학생의 학적변동이 있는 경우에는 [학적-전입관리-전입관리-학적반영]에서 편성함.
    • 지필평가 과목으로 등록되지 않은 경우. [성적-지필/수행선행작업-지필평가과목관리]에서 해당 과목들이 정상적으로 등록되어 있는지 확인함.

    업로드 전후 주의

    • 학생답안 파일을 재업로드 하는 경우, [학생답관리]에서 입력한 서답형 점수는 삭제되며 학생답 정오표는 조회되지 않음.
    • {이력}을 클릭하여 ‘성적파일 올리기 이력’ 창에서 파일업로드 이력을 조회할 수 있음.
    • 카드학과코드 및 카드과목코드는 두 자리이며, 성적파일 데이터가 한 자리인 경우에도 두 자리로 0이 붙어 저장됨.
    • 2026학년도 1학년 기술·가정 과목을 2학년 학생이 수강하는 경우에는 1·2학년 성적파일을 학년별로 별도 파일로 업로드 함.
    • 서답형 문항 출제 교과담당교사는 서답형 문항에 대한 채점을 한 후, 그 점수를 OMR 시트(카드)에 마킹하여 성적처리담당교사에게 제출하거나 [성적-지필평가-지필평가성적관리]에서 서답형 점수를 직접 입력할 수 있음.

    13D
    파일 이관 실패 시이관 실패한 경우만

    이관 실패 파일 수정과 재이관

    성적파일 올리기에서 이관이 실패했을 때만 하는 업무입니다. 학과코드·과목코드 불일치나 학생번호 오류 같은 사유를 이 메뉴에서 확인해 고칩니다. {카드일괄수정} 또는 {카드수정}을 이용하면 OMR 시트(카드)를 재리딩하지 않고 수정된 성적파일로 이관할 수 있음.

    언제?
    성적파일 업로드/이관을 실행한 뒤 이관에 실패한 파일이 확인된 시점
    누가?
    성적처리 업무담당자
    어디서?
    [성적-지필/수행선행작업-성적파일관리]
    무엇을
    어떻게?
    ‘학년도’, ‘학기’ 확인 후 ‘올린일자’, 업로드파일 종류 선택 후 수정할 이관완료 파일을 선택함 → {카드일괄수정} → ‘카드일괄 수정’ 창에서 수정할 항목을 선택하고 {조회} → 변경 내용을 입력하고 {저장} → {닫기} → {파일이관}.
    왜?
    학생들을 다시 불러 OMR 카드를 재리딩하는 일 없이 잘못된 코드 몇 자리만 고쳐 성적을 정상 반입하려고 합니다.

    수정할 수 있는 것과 못 하는 것

    • ‘카드순번’의 ‘순번’을 클릭하면 해당 학생의 OMR 시트(카드)가 표시되며 이때 ‘학생번호’나 ‘결시코드’, ‘서답형 점수’, ‘기타점수’는 수정이 가능하나 학생의 OMR 시트(카드) 마킹 정보는 수정할 수 없음.

    수정 기능 네 가지

    • {카드일괄수정}은 ‘과목코드’, ‘학과코드’, ‘학년’, ‘반코드’를 일괄로 수정할 수 있음.
    • {카드수정}은 학생별 ‘학생번호’, ‘결시코드’, ‘서답형 점수’, ‘기타점수’를 수정할 수 있음.
    • {카드삭제}는 학생별 카드를 삭제할 수 있음. 삭제한 파일은 복구가 불가능함.
    • {파일수정}은 ‘반코드’, ‘학생번호’, ‘결시코드’, ‘서답형 점수’ 등 항목별 수정사항을 반영할 때 사용함. {파일수정}하고 {파일이관}하는 경우에 사용함.
