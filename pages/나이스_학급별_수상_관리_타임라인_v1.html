      01A
      연중 수시등록 전 확인용

      학급별 수상경력 조회로 누락 여부 확인

      학급담임이나 수상 업무담당교사가 맡은 학급의 수상경력 현황을 먼저 확인하는 업무입니다. 전입생이나 위탁학생이 있는 학급이라면 이전학교에서 누락된 수상자료나 위탁기관 수상내역이 빠져 있는지를 이 화면에서 먼저 확인한 뒤 등록으로 넘어갑니다.

      언제?
      연중, 전입생·위탁학생 발생 시 및 수상자료 등록 전.
      누가?
      수상 업무담당교사, 학급담임교사
      어디서?
      [학급담임-학생생활-수상경력-학급별수상관리]의 {학급별수상조회} 탭
      무엇을
      어떻게?
      [학생생활-수상경력-학급별수상관리]의 {학급별수상조회} 탭에서 '학년도', '계열/학년/학과', '반' 확인 → {조회}함.
      왜?
      전입생과 위탁학생의 수상경력이 실제로 빠져 있는지 눈으로 확인해, 중복 등록이나 누락 없이 학교생활기록부에 반영하려고.

      실무 메모

      • [학생생활-수상경력-학급별수상관리]의 {학급별수상조회} 탭에서 {엑셀다운로드} 또는 {출력}하여 '학급별 수상대장'을 확인할 수 있음.
      • [학급별수상관리]에서 등록하는 내용은 해당 학교의 수상기록이 아니므로 수상대장에 반영되지 않으며, 결재를 상신할 수 없으므로 결재상태가 '결재대상아님'으로 표기됨.
      • 본교 수상대장에 등록된 수상 내역은 수정할 수 없음.

      타임라인으로 돌아가기

      02B
      전입 직후전입생 있는 학급만

      전입생의 이전학교 누락 수상자료 등록

      전입생이 있는 학급에만 해당하는 업무입니다. 전출교에서 수상대상자로 선정되었으나 시상일자 이전에 전입해 이전학교 수상자료가 누락된 경우 이 메뉴에서 입력합니다. 전출교에서 송부한 수상관련 공문을 근거로 입력하되 수상연월일은 전출교 기준으로 입력합니다.

      언제?
      연중, 전입생의 이전학교 수상자료 누락이 확인된 뒤.
      누가?
      학급담임교사
      어디서?
      [학급담임-학생생활-수상경력-학급별수상관리]
      무엇을
      어떻게?
      [학생생활-수상경력-학급별수상관리]의 {학급별수상관리} 탭에서 '학년도', '계열/학년/학과', '반' 확인 후 {조회} → 해당 학생을 클릭하고 {등록} → '학급별 수상 등록' 창에서 전입생의 전출교에서 누락된 수상내역을 입력 → {저장} → {닫기}.
      왜?
      전학 시점 때문에 어느 학교에도 남지 않게 된 수상경력을 학생의 학교생활기록부에 되살려 주기 위해서입니다.

      실무 메모

      • {등록}은 전입생의 누락된 이전학교 수상자료 등록 및 위탁학생의 타기관 수상내역 등록 시에만 활용합니다. 본교 수상대장에 등록된 수상 내역은 수정할 수 없습니다.
      • 전출교에서 송부한 수상관련 공문을 근거로 입력하되, 수상연월일은 전출교 기준으로 입력합니다.
      • [학급별수상관리]에서 등록하는 내용은 해당 학교의 수상기록이 아니므로 수상대장에 반영되지 않으며, 결재를 상신할 수 없으므로 결재상태가 '결재대상아님'으로 표기됩니다.

      타임라인으로 돌아가기

      03B
      위탁기관 수상 접수 후위탁·공동교육과정·교환학생 한정

      위탁학생의 타기관 수상내역 등록

      대안교육기관 위탁교육·직업과정 위탁교육 위탁학생, 공동교육과정 수강학생, 국내학교간 교환학생이 있는 학급에만 해당하는 업무입니다. 이들이 위탁기관 및 교환학교에서 받은 상은 교내상으로 입력할 수 있습니다. 학생미혼모의 경우 수상경력의 '수여기관'에 위탁교육 기관명이 드러나지 않도록 재적교로 입력합니다.

      언제?
      연중, 위탁기관이나 교환학교에서 받은 상장을 학생이 제출한 뒤.
      누가?
      학급담임교사
      어디서?
      [학급담임-학생생활-수상경력-학급별수상관리]
      무엇을
      어떻게?
      [학생생활-수상경력-학급별수상관리]의 {학급별수상관리} 탭에서 '학년도', '계열/학년/학과', '반' 확인 후 {조회} → 해당 학생을 클릭하고 {등록} → '학급별 수상 등록' 창에서 위탁학생이 위탁기관에서 받은 수상내역을 입력 → {저장} → {닫기}.
      왜?
      본교 밖에서 배운 기간에 받은 상도 학생의 수상경력으로 남겨 위탁·교환 학생이 불이익을 받지 않게 하려는 것입니다.

      등록 대상과 수여기관 표기

      • 대안교육기관 위탁교육·직업과정 위탁교육 위탁학생, 공동교육과정 수강학생과 국내학교간 교환학생이 위탁기관 및 교환학교에서 받은 상은 교내상으로 입력할 수 있습니다.
      • 당해학교의 상장번호 자동체번 설정과 관계없이 입력할 수 있는 [학생생활-수상경력-학급별수상관리]에서 등록합니다.
      • '수여기관'에는 위탁기관을 입력하되, 학생미혼모의 위탁교육 기관명이 드러나지 않도록 봉사활동 실적의 '장소 또는 주관기관명'과 수상경력의 '수여기관'에는 위탁교육 기관명을 재적교로 입력합니다.

      등록 시 유의사항

      • {등록}은 전입생의 누락된 이전학교 수상자료 등록 및 위탁학생의 타기관 수상내역 등록 시에만 활용합니다. 본교 수상대장에 등록된 수상 내역은 수정할 수 없습니다.
      • [학급별수상관리]에서 등록하는 내용은 해당 학교의 수상기록이 아니므로 수상대장에 반영되지 않으며, 결재를 상신할 수 없으므로 결재상태가 '결재대상아님'으로 표기됩니다.

      04C
      등록 완료 후엑셀·출력

      학급별 수상대장 엑셀다운로드·출력

      학급 학생의 수상 내역을 문서로 남기거나 대외 확인용으로 써야 할 때 하는 업무입니다. 앞서 전입생의 누락 수상과 위탁학생의 타기관 수상을 모두 등록한 뒤에 열어야 최종 상태가 반영됩니다. {학급별수상조회} 탭에서 {엑셀다운로드} 또는 {출력}으로 '학급별수상대장'을 활용합니다.

      언제?
      연중, 전입생·위탁학생의 누락 수상자료 등록을 마친 뒤.
      누가?
      수상 업무담당교사, 학급담임교사
      어디서?
      [학급담임-학생생활-수상경력-학급별수상관리] 의 {학급별수상조회} 탭
      무엇을
      어떻게?
      [학생생활-수상경력-학급별수상관리]의 {학급별수상조회} 탭에서 '학년도', '계열/학년/학과', '반' 확인 → {조회} → {엑셀다운로드} 또는 {출력} 하여 '학급별수상대장'을 활용함.
      왜?
      학급 학생의 수상 내역을 한 장의 대장으로 확보해 누락과 오기를 눈으로 대조하고 근거 자료로 남기려고 합니다.

      실무 메모

      • [학생생활-수상경력-학급별수상관리]의 {학급별수상조회} 탭에서 {엑셀다운로드} 또는 {출력} 하여 '학급별 수상대장'을 확인할 수 있음.
      • [학급별수상관리]에서 등록하는 내용은 해당 학교의 수상기록이 아니므로 수상대장에 반영되지 않으며, 결재를 상신할 수 없으므로 결재상태가 '결재대상아님'으로 표기됨.
