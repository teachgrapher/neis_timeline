    01A
    연계기관 자료요청 전연 1회 등록

    대외기관 자료제공 사전승인 관리

    경찰청･통일부･병무청･한국장학재단･한국대학교육협의회가 졸업생 자료를 요청하는 학교에 해당한다. 학교에서는 연 1회 사전 승인 등록이 가능하며, 사전 승인 이후 연계기관에서 온라인으로 요청 시 해당자료가 제공됨. 승인 등록을 해 두지 않으면 요청이 들어와도 자료가 나가지 않는다.

    언제?
    대외기관(경찰청･통일부･병무청･한국장학재단･한국대학교육협의회) 자료요청 시. 연계기관의 온라인 요청보다 앞서 등록해 둠.
    누가?
    학적 업무담당자
    어디서?
    [학적-대외기관자료제공관리-대외기관자료제공사전승인관리]
    무엇을
    어떻게?
    ‘대외기관’, ‘자료종류’ 선택 후 {조회}함 → {추가}하여 ‘수신기관명’, ‘자료종류명’ 선택 후 {승인}함.
    왜?
    졸업생 자료를 요청받을 때마다 개별로 처리하지 않고, 미리 승인해 둔 기관과 자료에 한해서만 자료가 나가도록 범위를 정해 두려고.

    실무 메모

    • 연계기관 자료제공 사전 승인 이후 연계기관에서 온라인으로 요청 시 해당자료가 제공됨.
    • 학교에서는 연 1회 사전 승인 등록이 가능함.
    • 학교별 자료 제공 내역은 [학적-대외기관자료제공관리-대외기관자료제공현황] 또는 [학적-대외기관자료제공관리-대외기관자료제공상세조회내역]에서 수시로 확인 가능함.
    • 한국대학교육협의회도 대외연계 사전승인을 할 수 있으며, 승인이 된 경우 졸업정보가 한국대학교육협의회로 전송이 됨.

    후행처리

    • [학적-졸업/수료관리]에서 졸업 및 수료처리를 완료하고 졸업/수료생 학적 반영함.

    02B
    연계기관 자료요청 시조회 전용

    대외기관 자료제공 현황 조회

    경찰청･통일부･병무청･한국장학재단･한국대학교육협의회 등 나이스와 연계된 기관이 우리 학교 졸업생 자료를 요청했을 때 확인하는 업무입니다. 연계기관 자료제공 사전승인이 등록되어 있어야 해당 자료가 제공되므로, 사전승인 이후 수신 현황을 이 화면에서 확인합니다. 조회만 하는 화면이므로 입력이나 저장 작업은 없습니다.

    언제?
    대외기관(경찰청･통일부･병무청･한국장학재단･한국대학교육협의회) 자료요청 시. 연계기관 자료제공 사전 승인 이후 연계기관에서 온라인으로 요청한 뒤
    누가?
    학적 업무담당자
    어디서?
    [학적-대외기관자료제공관리-대외기관자료제공현황]
    무엇을
    어떻게?
    ‘연계기관’, ‘수신일자’ 선택 및 입력 → {조회}함.
    왜?
    연계기관이 우리 학교 졸업생의 어떤 자료를 언제 받아 갔는지 학교가 직접 확인해, 자료가 요청한 기관에 제대로 전달되었는지 확인해 두려고.

    실무 메모

    • ‘연계기관’은 ‘경찰청’, ‘통일부’, ‘병무청’, ‘한국장학재단’, ‘한국대학교육협의회’ 중에서 선택할 수 있음.
    • 제공자료 종류에는 ‘학교생활기록부(성적포함)’, ‘학적자료’, ‘졸업정보 대학제공’이 있음.
    • 연계기관별로 ‘경찰청-졸업내역’, ‘통일부-학적자료’, ‘병무청-학교생활기록부(성적포함)’, ‘한국장학재단’-장학금심사(학교생활기록부), 장학생 월별 관리(학적, 학폭), ‘대학교육협의회-졸업내역’의 자료를 제공할 수 있음.

    더 자세히 보려면

    • 연계기관이 요청한 문서는 ‘제공자료종류’에서 확인할 수 있음.
    • 자세한 정보는 [학적-대외기관자료제공관리-대외기관자료제공 상세조회내역]에서 추가로 확인할 수 있음.
    • 학교별 자료 제공 내역은 이 화면 또는 [학적-대외기관자료제공관리-대외기관자료제공상세조회내역]에서 수시로 확인 가능함.

    03C
    자료 제공 후 확인 시통일부 자료에 한정

    대외기관 자료제공 상세 조회 내역 확인 및 출력

    대외기관 자료제공 현황보다 자세한 정보를 확인해야 할 때 여는 화면입니다. '수신기관'은 '통일부'만 선택할 수 있으므로 통일부로 제공된 자료의 상세 내역을 확인할 때 사용합니다. '구분'을 '제공자료 현황 통계'로 바꾸면 인원수 통계도 볼 수 있습니다.

    언제?
    대외기관(경찰청･통일부･병무청･한국장학재단･한국대학교육협의회) 자료요청 시, 자료가 제공된 뒤 내역을 확인할 때. 사전승인 등록 이후 수시로 확인 가능합니다.
    누가?
    학적 업무담당자
    어디서?
    [학적-대외기관자료제공관리-대외기관자료제공상세조회내역]
    무엇을
    어떻게?
    [학적-대외기관자료제공관리-대외기관자료제공상세조회내역]에서 '수신기관', '제공일자', '구분' 선택 → {조회} → 해당 내역 클릭 → {출력}함.
    왜?
    졸업생의 학교생활기록부가 어느 기관에 언제 무엇이 나갔는지 근거 자료로 남겨, 자료 제공 사실을 학교가 증빙할 수 있게 하려고 합니다.

    실무 메모

    • '수신기관'은 '통일부'만 선택할 수 있음.
    • '구분'에서 '제공자료 현황 통계'를 선택하여 {조회}하면 '송신일자', '출생연도', '학년별 남･여 인원수'를 확인할 수 있음.
    • 연계기관이 요청한 문서는 '제공자료종류'에서 확인할 수 있으며, 이 화면에서 자세한 정보를 추가로 확인할 수 있음.

    함께 보는 화면

    • 학교별 자료 제공 내역은 [학적-대외기관자료제공관리-대외기관자료제공현황] 또는 [학적-대외기관자료제공관리-대외기관자료제공상세조회내역]에서 수시로 확인 가능함.
    • 후행처리로 [학적-졸업/수료관리]에서 졸업 및 수료처리를 완료하고 졸업/수료생 학적을 반영함.
