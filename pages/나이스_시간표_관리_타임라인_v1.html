    외부 프로그램 시간표를 파일로 가져오기

    별도의 시간표 프로그램으로 시간표를 짜는 학교에 해당합니다. 나이스에서 처음부터 편성하지 않고 작성해 둔 파일을 올려 기초시간표를 만듭니다. 나이스에 등록된 과목명과 파일의 과목명이 띄어쓰기·로마자까지 일치해야 정상적으로 올라갑니다.

    언제?
    학년초, 편제및시간배당관리와 과목개설·수강생편성이 끝난 뒤.

    학년초, 기초시간표 편성 기간일반고등학교에서만 활용 가능

    시간표작성정보 설정으로 시간표도우미 활용하기

    일반고등학교에서만 활용 가능한 기능입니다. 초기설정과 엄수조건을 미리 정해 두고 시간표도우미에 보내면 조건이 반영된 시간표가 자동으로 작성됩니다. 교육과정 편제된 학년별 시수보다 요일별 최대 교시의 합이 많으면 공강이 발생할 수 있으므로 '요일별 최대교시' 설정에 주의합니다.

    언제?
    학년초, 과목개설과 수강생편성이 끝나 기초시간표를 짜기 시작할 때.

    시간표 업무담당교사
    어디서?
    [교육과정-시간표관리-기초시간표관리]

    어떻게?

    왜?
    교사 사정과 블록수업·창체 고정 같은 조건을 미리 걸어 두고, 손으로 맞추기 어려운 배정을 시스템이 풀게 하려고.

    초기설정 용어

    • 일별 동일과목 최대 수업교시는 일 기준 동일 과목을 1~3교시 등으로 연속되게 진행하는 최대 교시수.
    • 수업교시 공정배정은 특정 교사의 수업이 1교시 또는 7교시에 몰리지 않게 고려할지 여부.
    • 연속 수업사용은 블록수업 사용 여부.
    • 요일별 최대교시는 월요일~금요일까지 각 요일별 최대 교시 설정으로, 교육과정 편제된 학년별 시수보다 요일별 최대 교시의 합이 많으면 공강 발생 가능.

    엄수조건 용어와 전송 후

    • 학급별 수업 우선배정은 특정 수업을 지정된 요일, 교시에 우선적으로 배정하는 기능(특정 요일에 수업이 진행되는 순회교사 운영 과목, 실무과목 수업과 같은 일반적인 수업 배치와는 다른 2교시 이상의 블록수업 배정 등).
    • 학년별 창체수업우선배정은 학년별로 창체 수업을 고정하여 운영할 때 해당 시간을 지정하는 기능.
    • 교사별 배정제외교시는 개인사정 등으로 교과담당교사가 수업을 진행하지 못하는 요일과 교시를 지정하는 기능.
    • 점심시간연속수업허용은 4교시-점심-5교시 등 점심시간 이후에도 연속해서 동일한 수업을 진행할지 여부.
    • 여러 과목을 동시 수업 그룹으로 설정하여 기초시간표 작성에 활용할 수 있으며, 설정하는 순서에 따라 그룹 번호는 자동으로 생성됨.
    • 시간표작성정보 설정 후 {시간표도우미전송}하면 '시간표작성결과'에 {시간표보기}, '시간표적용'에 {시간표적용}이 활성화되어 작성된 시간표를 확인하고 기초시간표에 적용할 수 있음.

    04A
    검증 및 반영 전기초시간표를 2개 이상 작성한 경우 필수

    전체시간표에 반영할 기본시간표 지정하기

    기초시간표를 강의실마다 여러 개 만들어 비교하는 학교에 해당합니다. 여러 안 중 실제로 쓸 시간표를 하나 골라 표시해 두는 작업입니다. 기초시간표는 강의실마다 2개 이상 작성 가능하므로 검증 및 반영 전에 어느 것이 (기본)인지 확인해야 합니다.

    언제?
    학년초, 기초시간표 작성을 마치고 기초시간표검증및반영에 들어가기 전.

    어디서?

    왜?
    여러 개 만들어 둔 안 가운데 학교가 실제로 운영할 시간표 하나만 전체시간표로 넘어가게 하려고.

    • '기본시간표'로 지정된 기초시간표는 [교육과정-시간표관리-기초시간표검증및반영]에서 활용되어 전체시간표에 반영됨.

    기초시간표 작성 완료 후기본시간표 지정 필요

    언제?

    전체시간표 반영 후 수시

    강의실별 수업일수 조회 및 출력하기

    강의실 단위로 수업일수를 확인해야 할 때 여는 조회 메뉴입니다. 시간표 조회와 달리 강의실별로 누적된 수업일수가 집계되어 나오므로 조회 조건에 '강의실'을 지정해야 합니다.

    언제?
    학기중, 기초시간표 반영으로 전체시간표가 구성된 뒤 필요할 때마다
    누가?
    시간표 업무담당교사
    어디서?
    [교육과정-시간표관리-강의실별수업일수조회(시간표)]
    무엇을
    어떻게?
    [교육과정-시간표관리-강의실별수업일수조회(시간표)]에서 '학년도' 확인 후 '학기', '계열/학년/학과', '강의실' 선택 후 {조회}함 → 강의실별 수업일수를 확인하고 저장 또는 출력함.
    왜?
    강의실 단위로 실제 진행된 수업일수를 확인해 수업일수 관련 자료의 근거로 삼으려고.

    타임라인으로 돌아가기

    17E
    교사 담당 수업 확인이 필요할 때

    교사찾기로 교사별 수업 조회 및 출력하기

    특정 교사가 지정한 일자에 어떤 수업을 하는지 확인할 때 여는 메뉴입니다. 다른 조회 메뉴와 달리 '교사' 입력 후 {교사찾기}로 대상 교사를 먼저 확정해야 조회가 진행됩니다.

    언제?
    학기중, 전체시간표가 구성된 뒤 특정 교사의 수업 확인이 필요할 때
    누가?
    시간표 업무담당교사
    어디서?
    [교육과정-시간표관리-교사별수업조회]
    무엇을
    어떻게?
    [교육과정-시간표관리-교사별수업조회]에서 '학년도' 확인 후 '일자' 선택, '교사' 입력 후 {교사찾기}함 → '교사검색' 창에서 {조회}하여 해당교사를 더블클릭하고 {조회}하여 수업시간을 확인하고 저장 또는 출력함.
    왜?
    결·보강이나 출장 처리를 앞두고 그 교사가 그날 비어 있는 교시를 먼저 확인하려고.

    실무 메모

    • '교사 검색' 창에서 교사명을 직접 입력하여 {조회}하면 해당 교사명이 즉시 반영됨(해당 교사가 1인인 경우에 한함).
