      01A
      위탁기관 확인요청 접수 직후나이스 활용 위탁교육 개설교 한정

      위탁학생 확인요청 접수 및 요청확인 전송

      나이스를 활용하는 위탁교육 개설교(위탁기관)에서 위탁학생을 등록하고 {확인요청}한 경우에만 접수 목록에 나타난다. {승인요청}으로 업무승인과정을 거쳐 결재권자의 결재가 완료된 뒤에야 {요청확인}이 가능하다. 위탁기관이 위탁학생 정보를 수정하고 {재확인요청}한 경우에도 같은 메뉴에서 다시 확인한다.

      언제?
      학기초, 반 편성 등 위탁학생의 학적을 구성하고 위탁교육 개설교에서 {확인요청}한 뒤
      누가?
      위탁교육 업무담당자
      어디서?
      [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-확인요청접수및전송]
      무엇을
      어떻게?
      '학년도', '기간', '기관명(타학교)' 확인 후 {조회} → 위탁학생의 '성명'을 클릭하면 나타나는 '위탁학생 상세정보' 창에서 위탁교육 개설교에서 등록한 위탁학생 정보의 오류 유무를 확인 후 {닫기} → 위탁학생을 선택하고 {승인요청}으로 업무승인과정을 거쳐 결재권자의 결재가 완료되면 {요청확인}하여 위탁교육 개설교에 위탁학생 정보가 이상 없음을 확인 요청함.
      왜?
      위탁기관이 등록한 학생 정보가 재적교의 학적과 어긋나지 않음을 재적교가 책임지고 확인한 뒤에 출결·성적 자료를 주고받게 하려고.

      '상태' 값의 뜻

      • 확인요청 접수 — 거점교(개설교)에서 위탁학생 등록 후 {확인요청}을 한 경우.
      • 상신 완결 — {승인요청}으로 업무승인과정을 거쳐 결재권자의 결재가 완료된 경우.
      • 확인요청완료 — {요청확인}으로 거점교에 확인요청을 완료한 경우로 '전송상태'는 '전송완료'로 나타남.
      • '상태'가 '확인요청완료'이고 '전송완료'인 경우 [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-위탁･현장실습학생등록]에서 자동으로 위탁학생으로 등록됨. 이후 위탁기관이 [학적-타교수강생관리(위탁)-출결관리]에서 월별 출결자료를, [학적-타교수강생관리(위탁)-타교수강생관리(위탁)-자료전송]에서 성적·세특·학생생활 자료를 전송하면 [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-타학교자료전송확인]에서 전송자료 현황을 확인할 수 있고, [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-자료관리]에서 {타학교자료가져오기}로 반영함.

      정보 변경과 등록 단위

      • 위탁학생의 정보가 변경된 경우 위탁기관의 [학적-타교수강생관리(위탁)-타교수강생관리(위탁)-등록]에서 '성명'을 클릭해 나타나는 '타교수강생 수정' 창에서 수정하고 {재확인요청}하면, 소속교의 '위탁학생 상세정보' 창에서 수정 내용의 오류 유무를 확인하고 이상 없을 시 {요청확인}함.
      • 위탁학생은 나이스에서 학기 단위로 등록하여 관리함.

      02A
      요청확인 전송 완료 후나이스 활용 위탁기관 학생만'등록구분'이 '타학교'

      위탁기관이 등록한 위탁학생 정보 확인

      나이스를 활용하는 위탁교육 개설교(위탁기관)에서 등록한 위탁학생의 정보를 확인하는 과정이다. 확인요청접수및전송에서 {요청확인}이 완료되면 이 메뉴에 자동으로 위탁학생이 등록되므로 별도 등록 없이 내용만 확인한다. 이때 '등록구분'은 '타학교'로 표기된다.

      언제?

      무엇을
      어떻게?
      '학년도', '학기', '과정' 확인 후 '계열/학년/학과', '반'을 선택하고 '기관명(타학교)' 확인 후 {조회} → 위탁학생을 클릭하여 하단에 위탁교육 개설교에서 등록한 '시작일자', '종료일자', '교육구분', '위탁기관구분', '기관명', '전공', '위탁상태', '비고'를 확인함.

      03A
      위탁 시작 시점나이스 미활용·NEIS+·대안교육 위탁기관'등록구분'이 '본교'

      나이스 미활용·나이스플러스(NEIS+)·대안교육 위탁기관 위탁학생 직접 등록

      나이스를 활용하지 않거나 나이스플러스(NEIS+)를 활용하는 위탁기관, 그리고 대안교육 위탁교육기관의 위탁학생은 재적교가 직접 등록해야 한다. 위탁학생은 재적학교의 학기 단위로 등록하며, 같은 학기에 기간을 달리하여 2회 이상 위탁한 경우도 등록 가능하다. 이 메뉴에서 직접 등록한 학생은 '등록구분'이 '본교'로 표기된다.

      언제?
      학기초 및 위탁이 시작되는 시점, 반 편성 등 위탁학생의 학적 구성이 끝난 뒤
      누가?
      위탁교육 업무담당자
      어디서?
      [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-위탁･현장실습학생등록]
      무엇을
      어떻게?
      {등록} → '위탁학생등록' 창에서 '학년도', '학기' 확인 후 '학년', '반'을 선택하고 {조회} 후 해당 학생을 클릭 → '시작일자', '종료일자', '교육구분' 선택 후 '기관명'을 {기관찾기}로 위탁기관을 검색하여 반영하고 필요시 '전공', '비고'를 입력하고 {저장}함.
      왜?
      자료가 자동으로 넘어오지 않는 기관의 위탁 사실을 재적교 학적에 남겨 출결·성적·학교생활기록부 '전공･과정' 관리의 근거를 만들려고.

      기관 검색과 교육구분

      • 위탁기관은 시도교육청에서 사전 등록하면 조회할 수 있으며, '위탁기관찾기' 창에서 위탁기관이 검색이 안 되는 경우 {수기입력}으로 등록함.
      • '교육구분' 설정은 대안교육 위탁기관은 '대안교육위탁기관', 직업교육 위탁기관은 '직업과정위탁교육', 병원학교･원격수업기관은 '병원학교' 또는 '원격수업', 방송･정보통신매체는 '원격수업', 학교밖교육은 '학교밖교육', 나머지는 '기타'로 등록함.
      • 학교 밖 교육 수강학생은 '교육구분'을 '학교 밖 교육'으로, '위탁기관구분'을 '학교 밖 교육기관'으로 등록함.
      • 위탁기관, 병원학교･원격수업기관의 활동 내용이 있는 경우 해당 기관의 자료를 그대로 입력하되, 학교생활기록부 기재요령의 각종 유의 사항을 준수하여 입력함.

      기관명 노출 방지와 후속 반영

      • 학생미혼모 및 청소년 한부모의 대안교육 위탁교육기관은 위탁기관명이 드러나지 않도록 '교육구분'을 '기타'로 하여 등록함. 2024학년도 이전의 내용은 '교육부 교육복지정책과-6434(2023. 10. 10.)' 공문을 근거로 정정할 수 있음.

      • [학생부-학교생활기록부-학교생활기록부-학생부조회및출력]에서 위탁학생을 선택하여 조회 시 학교생활기록부 '전공･과정'에 위탁교육기관 위탁관련 내용이 표기됨.

      04B
      매월 말, 반별월출결마감 후재적교+위탁기관 합산

      위탁학생 재적교 월별 출결 등록

      위탁학생이 있는 학급은 매월 말 위탁교육기관이 공문으로 송부한 월 출결자료를 재적교 출결자료와 합산해 등록해야 한다. 위탁학생의 출결자료 최종 수정은 [학적-위탁･현장실습학생관리-출결관리]에서만 가능하다. 여기서 등록한 월별 출결자료가 학교생활기록부 출결상황에 반영된다.

      언제?
