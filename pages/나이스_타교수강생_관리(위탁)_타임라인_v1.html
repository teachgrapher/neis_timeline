    01A
    학기초, 위탁학생 등록 전거점교(개설교) 한정

    타교수강생 반정보 등록

    직업교육 위탁과정, 한국어학급, 공동실습소 등을 운영하는 거점교(개설교)에서 위탁학생을 담을 반을 먼저 만드는 업무입니다. 타교수강생 반정보 관리는 학년 단위로 관리함. 여기서 등록한 '계열', '학과', '학년', '반' 정보만 이후 위탁학생 등록 시 '위탁학교 학생정보'로 설정할 수 있습니다.

    언제?
    학기초, 타교수강생 소속교에서 학적이 구성된 뒤 위탁학생 타교수강생 등록에 앞서.
    누가?
    위탁과정 업무담당자
    어디서?
    [학적-타교수강생관리(위탁)-타교수강생반정보관리]
    무엇을
    어떻게?
    '학년도', '학년' 확인 후 {조회} 함 → {행추가} 후 '반 정보'에서 '학년도', '계열', '학과', '학년', '반코드' 확인 및 선택하고 '반명', '정렬순서', '성적반코드' 입력 후 {저장} 함.
    왜?
    위탁학생을 거점교의 계열·학과·학년·반 체계에 앉혀, 이후 등록·출결·성적·자료전송이 모두 이 반을 기준으로 굴러가게 하려고.

    실무 메모

    • 타교수강생 반정보 관리는 학년 단위로 관리함.
    • '반 정보'에서 '계열'을 '일반계'로 선택하는 경우 '학과'는 공란으로 선택할 수 없으며, 공업계, 상업계 등 이외의 계열을 선택하면 거점교에 개설된 '학과'를 선택할 수 있음.
    • '성적반코드'는 OMR 시트(카드) 등록 시 사용하는 코드이며, 21부터 등록할 수 있음.

    운영기관 범위

    • 운영기관은 직업교육 위탁과정, 한국어학급, 공동실습소 등을 운영하는 「초･중등교육법」 제2조에 따른 고등학교(급)임.
    • 「초･중등교육법」 제2조에 따른 고등학교가 아닌 기관에서 직업교육 위탁과정, 대안교육 위탁기관, 다문화 위탁교육기관 등은 나이스플러스(NEIS+, https://neisplus.kr)를 활용할 수 있으며, 위탁학생을 관리하고 교과･비교과 관련 자료를 나이스로 전송함.

    타임라인으로 돌아가기

    02B
    학기초, 위탁학생 반정보 등록 후소속교가 나이스 사용교인 경우

    타교수강생 등록 — 소속교가 나이스를 사용하는 경우

    위탁학생 소속교가 나이스를 사용하는 학교라면 원적교 학적을 불러와 등록한다. 타교수강생 소속교에서 학적이 구성되어 있어야 학생찾기로 불러올 수 있다. 위탁학교 학생정보의 '계열', '학과', '학년', '반'은 앞서 등록한 반정보 범위 안에서만 지정된다.

    언제?
    학기초, 타교수강생 소속교에서 학적이 구성되고 타교수강생 반정보관리가 끝난 뒤.
    누가?
    위탁과정 업무담당자
    어디서?
    [학적-타교수강생관리(위탁)-타교수강생관리(위탁)-등록]
    무엇을
    어떻게?
    '학년도', '학기', '원적교', '성명' 확인 후 {조회} 함 → {등록} 을 클릭하면 나타나는 '타교수강생(위탁)등록' 창에서 {학생찾기} 하고, '시작일자', '종료일자', '교육구분', '위탁기관구분'을 선택 후 거점교인 '기관명', '위탁상태'를 확인하고 필요시 '전공'과 '비고' 입력 후 {저장} 함 → '원적교 학생정보'에서 '나이스 사용여부(예)'를 선택하고 위탁학생의 '학교명', '학기', '과정', '학년', '반', '번호' 선택 및 확인 후 '위탁학교 학생정보'에서 '학년', '반' 선택하고 '번호' 입력 후 {저장} 하고 목록에서 확인함.
    왜?
    위탁학생을 거점교 학생으로 붙잡아 두어야 이후 출결·성적·학생생활 자료를 소속교로 되돌려 보낼 수 있다.

    교육구분과 위탁기관구분

    • 교육구분 — 직업과정 위탁교육, 현장실습, 공동실습소, 대안교육위탁기관, 병원학교, 원격수업, 학교 밖 교육, 기타.
    • '직업과정 위탁교육' 선택 시 위탁기관구분 — 산업정보학교, 직업교육거점학교, 공공직업훈련시설, 지정직업훈련시설, 전문대학, 교육부지정 위탁기관.
    • '학교 밖 교육' 선택 시 위탁기관구분 — 학교 밖 교육기관.

    실무 메모

    • '위탁학교 학생정보'는 [타교수강생 반정보관리]에서 등록한 '계열', '학과', '학년', '반' 정보만 설정할 수 있음.
    • '위탁학교 학생정보'에서 '계열'을 '일반계'로 선택하는 경우 '학과'는 입력하지 않으며, 공업계, 상업계 등 이외의 계열을 선택하면 거점교에 개설된 '학과'를 선택할 수 있음.
    • 위탁학생 타교수강생 등록 시 '확인미요청'과 '미반영'이 '0'에서 '1'로 변경됨.

    03B
    학기초, 위탁학생 반정보 등록 후소속교가 나이스 미사용 기관인 경우

    타교수강생 직접등록 — 소속교가 나이스를 사용하지 않는 경우

    위탁학생 소속교가 나이스를 사용하지 않는 학교(기관)일 때만 해당한다. 원적교 학적을 불러올 수 없으므로 '나이스 사용여부'를 '아니오'로 선택하고 위탁교육 정보, 원적교 학생정보, 위탁학교 학생정보를 직접 등록해야 한다. 학과는 {학과조회} 로 검색해 넣는다.

    언제?
    학기초, 소속교가 나이스 미사용 기관임을 확인하고 타교수강생 반정보관리가 끝난 뒤.
    누가?
    위탁과정 업무담당자
    어디서?
    [학적-타교수강생관리(위탁)-타교수강생관리(위탁)-등록]
    무엇을
    어떻게?
    '학년도', '학기', '원적교', '성명' 확인 후 {조회} 함 → {등록} 을 클릭하면 나타나는 '타교수강생(위탁)등록' 창에서 '시작일자', '종료일자', '교육구분', '위탁기관구분'을 선택 후 거점교인 '기관명', '위탁상태'를 확인하고 필요시 '전공'과 '비고' 입력 후 {저장} 함 → '원적교 학생정보'에서 '나이스 사용여부'를 '아니오'로 선택하고 위탁교육 정보, 원적교 학생정보, 위탁학교 학생정보를 직접 등록한 후 {저장} 하고 목록에서 확인함.
    왜?
    나이스에 학적이 없는 기관 소속 학생도 거점교에서 관리 대상으로 잡아 자료가 빠지지 않게 하려고.

    실무 메모

    • 위탁학생 소속교가 나이스를 사용하지 않는 학교(기관)인 경우 '원적교 학생정보'에서 '나이스 사용여부'를 '아니오'로 선택하고 위탁교육 정보, 원적교 학생정보, 위탁학교 학생정보를 직접 등록해야 함.
    • {학과조회} 시 현재 나이스에 등록된 학과를 검색하여 등록할 수 있음('학과찾기' 창).
    • '위탁학교 학생정보'는 [타교수강생 반정보관리]에서 등록한 '계열', '학과', '학년', '반' 정보만 설정할 수 있음.
    • ｢초･중등교육법｣ 제2조에 따른 고등학교가 아닌 기관에서 직업교육 위탁과정, 대안교육 위탁기관, 다문화 위탁교육기관 등은 나이스플러스(NEIS+, https://neisplus.kr)를 활용할 수 있으며, 위탁학생을 관리하고 교과･비교과 관련 자료를 나이스로 전송함.

    04B
    교무학기가 2학기로 넘어간 직후1학기 등록 학생을 이어서 받는 경우만

    1학기 타교수강생 2학기 재등록(가져오기)

    1학기에 등록한 위탁학생을 2학기에도 계속 받는 경우에만 쓴다. 교무학기가 2학기이면 {가져오기} 가 활성화된다. 학생을 하나씩 다시 등록하지 않고 목록에서 골라 옮긴다.

    언제?
    학기초, 교무학기가 2학기로 넘어가고 1학기에 타교수강생이 등록되어 있는 상태.
    누가?
    위탁과정 업무담당자
    어디서?
    [학적-타교수강생관리(위탁)-타교수강생관리(위탁)-등록]
    무엇을
    어떻게?
    '학년도', '학기', '원적교', '성명' 확인 후 {조회} 함 → {가져오기} 를 클릭하면 나타나는 '타교수강생가져오기' 창에서 해당 학생을 선택하고 {가져오기} 함 → 목록에서 등록된 위탁학생을 확인함.
    왜?
    학기가 바뀌어도 같은 학생을 다시 입력하는 수고를 줄이고 입력 착오를 막으려고.

    실무 메모

    • 교무학기가 2학기이면 {가져오기} 가 활성화되며, 1학기에 기 등록된 타교수강생을 2학기에 재등록이 필요한 경우에 '타교수강생가져오기' 창에서 해당 학생을 선택하고 {가져오기} 함.
    • 가져온 뒤에도 확인요청과 학적반영 절차는 새로 진행함.

    타임라인으로 돌아가기

    05B
    타교수강생 등록을 마친 직후

    타교수강생 확인요청과 소속교 요청확인

    등록만 해 두면 소속교는 우리 학교가 그 학생을 받았다는 사실을 모른다. 등록한 학생을 골라 {확인요청} 하면 소속교 담당자에게 요청이 넘어간다. 소속교가 업무승인과정을 거쳐 {요청확인} 해야 '전송상태'가 '전송대기'에서 '전송완료'로 바뀐다.

    언제?
    학기초, 타교수강생 등록이 끝난 뒤.
    누가?
    위탁과정 업무담당자, 위탁학생 소속교 위탁학생 업무담당자
    어디서?
    [학적-타교수강생관리(위탁)-타교수강생관리(위탁)-확인요청] · [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-확인요청접수및전송]
    무엇을
    어떻게?
    '학년도', '학기', '계열/학년/학과', '성명' 확인 후 {조회} 함 → 등록한 위탁학생 타교수강생 선택 후 {확인요청} 함 → 위탁학생 소속교에서 학생 '성명'을 클릭하면 나타나는 '위탁학생 상세정보' 창에서 정보 확인 후 위탁학생을 선택하고 {승인요청} 함 → '기안문서상신' 창에서 '내용' 입력 후 {결재자지정} 으로 결재권자를 등록하고 위탁학생 타교수강생을 선택하여 {상신} 함 → 결재가 완료되면 {요청확인} 함.
    왜?
    위탁 사실을 소속교와 서로 맞춰 두어야 이후 자료가 엉뚱한 학생에게 붙지 않는다.

    상태값 변화

    • 위탁학생 {확인요청} 시 '확인미요청'은 '1'에서 '0'으로, '확인요청'은 '0'에서 '1'로 변경됨.
    • {승인요청} 시 결재권자의 결재가 완료되면 '상태'가 '확인요청접수'에서 '상신완결'로 변경됨.
    • {요청확인} 시 '전송상태'가 '전송대기'에서 '전송완료'로 변경됨.

    소속교에서 확인할 것

    • 위탁학생 소속교에서 위탁학생 업무담당자가 나이스 로그인 시 '업무요청내역'에 공동교육과정 수강생에 대한 확인요청 안내가 표시됨.
    • 위탁학생 소속교의 [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-위탁･현장실습학생등록] 에서 자동으로 등록된 내용을 확인함.

    06B
    소속교가 요청확인을 완료한 뒤

    타교수강생 학적반영

    소속교가 {요청확인} 하면 거점교의 '승인상태'가 '확인요청'에서 '확인요청완료'로 바뀌고, 이때부터 학적반영이 가능하다. '승인상태'가 '확인요청완료'임을 확인하고 {승인요청} 으로 결재를 마쳐야 {학적반영} 할 수 있다. 반영 후에는 명렬표로 확인한다.

    언제?

    무엇을
    어떻게?

    학적반영 후 변경 발생 시변경 있는 학생만

    위탁학생 정보 수정·위탁중도해제와 재확인요청

    이미 학적반영이 끝난 위탁학생의 교육기간이나 기본정보가 바뀌었거나, 전출 등의 학적변동으로 위탁을 중간에 끊어야 할 때만 해당한다. 거점교에서 {재확인요청}을 하면 위탁교에서는 추가적인 {승인요청} 없이 {요청확인}만 한다. 개명한 학생은 수정 대신 원적교 정보를 다시 끌어와 현행화한다.

    언제?
    학기중, 학적반영된 위탁학생의 교육기간·기본정보가 변경되거나 학적변동이 생긴 뒤
    누가?
    위탁과정 업무담당자, 위탁학생 소속교 업무담당자
    어디서?
    [학적-타교수강생관리(위탁)-타교수강생관리(위탁)], [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-확인요청접수및전송]
    무엇을
    어떻게?
    '성명'을 클릭하면 나타나는 '타교수강생 수정' 창에서 변경된 위탁학생 정보를 수정하여 {저장}함 → {재확인요청}함 → 위탁학생 소속교에서 [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-확인요청접수및전송]에서 수정된 위탁학생 정보를 확인 후 {요청확인}함.

    거점교에서 바뀐 교육기간·학적 상태를 소속교 학교생활기록부와 어긋나지 않게 맞추려고.

    재확인요청 대상

    • 학적반영된 위탁학생의 교육기간 및 기본정보가 변경된 경우.

    08C
    매월 말, 월 단위학기말 자료전송에서 제외

    월출결 입력·마감·전송

    위탁학생의 출결은 거점교가 입력해 소속교로 보낸다. 출결자료는 월 단위로 위탁학생의 소속교로 전송하므로 학기말 자료전송에서는 별도로 전송하지 않는다. 전체 학생의 '수업일수'가 같으면 일괄 적용으로 처리한다.

    언제?
    학기중, 학적반영이 끝난 뒤 매월 출결 집계가 확정된 시점
    누가?
    위탁과정 업무담당자, 위탁학생 소속교 업무담당자
    어디서?
    [학적-타교수강생관리(위탁)-출결관리], [학적-위탁･현장실습학생관리-출결관리]
    무엇을
    어떻게?
    '학년도', '학기' 확인 후 '계열/학년/학과', '반'을 선택하고 '마감' 확인 후 {조회}함 → '월목록'에서 '월'을 선택하고 '학생별 월출결목록'에서 출결자료('수업일수', 유형별 '결석일수', 유형별 '지각', 유형별 '조퇴', 유형별 '결과') 입력 후 {저장}하고 위탁학생을 선택 후 {마감}함 → '학생별 월출결목록'에서 위탁학생을 선택 후 {승인요청}으로 업무승인과정을 거쳐 결재권자의 결재가 완료되면 위탁학생을 선택하고 {전송}함.
    왜?
    거점교에서 수업받은 실제 출결을 매달 소속교로 넘겨 학생의 출결이 소속교 기록에 빠짐없이 남게 하려고.

    실무 메모

    • 전체 위탁학생 대상으로 '수업일수'를 일괄 입력하기 위해서는 순번 앞에 체크박스를 선택하고 '수업일수'를 입력하고 {적용}함.
    • {마감}하면 '마감여부'가 'N'에서 'Y'로 변경됨.
    • {승인요청}하면 '승인상태'가 '미상신'에서 '상신(진행중)'으로 변경되며, 결재권자의 결재가 완료되면 '완결'로 변경됨.
    • {자료전송}하면 '전송상태'가 '미전송'에서 '전송완료'로 변경됨.
    • 출결자료는 월 단위로 위탁학생의 소속교로 전송함.

    소속교 후속 처리

    • 위탁학생 소속교에서는 [학적-위탁･현장실습학생관리-출결관리]에서 전송한 월을 클릭 후 위탁학생 성명을 클릭하면 나타나는 '타학교 출결내역' 창에서 반영할 '월' 확인 후 체크박스 선택하고 {반영} 클릭 후 {닫기}하고 {저장}함.

    학기말성적 전송 후 세특 전송

    [학적-타교수강생관리(위탁)-타교수강생관리(위탁)-자료전송]
    무엇을
    어떻게?
    '학년도', '학기' 확인 후 '계열/학년/학과', '반'을 선택하고 '마감', '승인', '전송'을 확인 후 {조회} → '타교수강생 목록'에서 위탁학생 성명을 클릭하면 나타나는 '타교 수강생 자료전송' 창에서 '학생생활'의 '독서활동'을 선택 후 전송자료를 확인하고 {닫기} → '전송항목선택'에서 전송자료를 선택하고 '타교수강생목록'에서 위탁학생을 선택 후 {마감} → '타교수강생목록'에서 위탁학생 선택 후 {승인요청}으로 업무승인과정을 거쳐 결재권자의 결재가 완료되면 위탁학생을 선택하고 {자료전송}
    왜?
    거점교에서 이수한 위탁학생의 성적과 학교생활 기록이 소속교 학교생활기록부에 빠짐없이 남게 하려고.

    전송자료별 관련 내용

    • 월출결 — [출결] 월출결.
    • 성적 — [성적] 학기말성적, 지필평가성적, 수행평가성적, 관찰내용.
    • 세부능력및특기사항 — [성적] 세부능력 및 특기사항.
    • 학생생활 — [학생생활] 수상내역, NCS 이수상황, 창의적체험활동(자율･자치활동(자율활동)･동아리활동･진로활동･진로희망), 봉사활동실적, 독서활동, 행동특성및종합의견.
    • '성적'과 '세특'은 분리해서 전송할 수 있으며, '성적'을 먼저 전송하고 이후 '세특'을 전송해야 함(소속교에서는 성적과 세특은 자동 반영되며, [학생부-학교생활기록부-학교생활기록부-학생부반영]에서 교과학습발달상황에 성적과 세부능력 및 특기사항을 반영함).
    • '출결'은 [학적-타교수강생관리(위탁)-출결관리]에서 월별로 소속교에 출결자료를 전송하므로 학기말에는 별도로 전송하지 않음.

    상태 변화와 소속교 확인

    • {마감}하면 '마감상태'가 '미마감'에서 '마감'으로 변경됨.
    • {승인요청}하면 '승인상태'가 '미상신'에서 '상신(진행중)'으로 변경되며, 결재권자의 결재가 완료되면 '완결'로 변경됨.
    • {자료전송}하면 '전송상태'가 '미전송'에서 '전송'으로 변경됨.
    • 거점교에서 위탁학생의 소속교로 성적, 세특, 학생생활을 {자료전송}하면 위탁학생의 소속교에서는 나이스 관련 메뉴에서 확인 후 반영함.
    • 소속교의 [학적-위탁･현장실습학생관리-위탁･현장실습학생관리-타학교자료전송확인]에서 위탁학생 성명을 클릭하면 나타나는 '위탁학생 타학교 자료내역' 창에서 성적, 세부능력 및 특기사항, 학생생활 전송자료별로 관련 내용을 확인할 수 있음.
